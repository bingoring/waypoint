# [Stage 3-6] 운영 피드백 3 — 관리자 대신 신청 표시 · 휴가 종류 표시 · 검진 오전/오후 · 휴가 승인 취소 · 개인별 주말 통 OFF · 내 설정 KTAS

## 요구사항 (사용자 2026-10-18)

1. 관리자 계정으로 다른 간호사의 근무 신청을 넣으면 파란색 표시가 안 된다.
2. 휴가를 신청하면 「휴」가 아니라 종류(연차·검진·개원·병가 …)로 보이게.
3. 검진은 오전 근무/오후 근무를 고르거나 코멘트 예시로.
4. 관리자 화면에서 휴가 승인과 승인 취소.
5. 주말 통 OFF를 원하지 않는 사람이 있다 — 각자 규칙 안내에서 켜고 끈다(처음엔 자동 신청, 원하지 않으면 끔). 관리자는 규칙 설정에서 끈 사람을 본다.
6. 내 설정에서 KTAS 취득일·갱신일·만료 예정일.

## 결정 (사용자 답변 2026-10-18)

- 1: **근무 신청 화면 + 근무표 모두 파란색**(관리자 수정과 같은 색). 관리자가 대신 넣은 근무 신청(OFF·D·E·N·교육)이 대상.
- 2: **전체 이름** — 연차 · 검진 · 개원 · 병가 · 경조 · 공가 · 특휴 (근무 신청 화면·근무표).
- 3: **오전·오후 선택 버튼**(검진을 고르면 「오전 검진 / 오후 검진」), 칸·승인 패널·툴팁에 표시.
- 6: **취득일·갱신일 입력, 만료 예정일 자동** = (갱신일 또는 취득일) + 3년 − 1일. 내 설정에서 바꾸면 바로 반영 + 관리자 확인 요청(연차 수정과 같은 방식).
- 4 (AI 해석): 휴가 승인 패널의 처리 이력에서 승인된 휴가를 취소(확정 전 달은 상태만, 확정된 달은 근무 조정의 승인 취소와 같은 칸 복원).
- 5 (AI 해석): 사람마다 「주말 통 OFF 받기」(기본 켜짐). 끈 사람은 검사기·솔버가 주말 통 OFF를 요구하지 않고 미달 개월 수도 쌓지 않는다. 규칙 설정의 주말 통 OFF 토글 옆에 끈 사람 목록.

## 구현 결과 (2026-10-18, 브랜치 `feature/3-6-feedback-3` — `feature/3-5-night-min` 위에 쌓음, 운영 미반영)

1. `shift_requests.by_admin`(마이그레이션 0010). 관리자가 남의 신청을 넣으면 신청 화면 칩이 파란 외곽선(범례 「관리자 입력」), 생성 때 그 신청이 반영된 칸의 출처는 `admin` → 근무표 파란 외곽선. 본인이 다시 고치면 본인 신청으로.
2. 휴가 칸 이름: 연차·검진·개원·병가·경조·공가·특휴(신청 화면·근무표·근무 조정·바뀐 근무 안내·툴팁). 특휴·개원 OFF 칸도 휴가 색. 근무표의 검진 반차 칸은 근무 코드 + 「검」(예: D검, 사용자 2026-10-18 — 1안), 툴팁에 오전·오후 검진(모두에게).
3. 검진은 「오전 검진 · 오후 근무 / 오후 검진 · 오전 근무」 중 하나를 골라야 저장(`reasonCode` am/pm), 승인 패널·툴팁에 「오전 검진」.
4. 휴가 승인 패널의 처리 이력에 「승인 취소」(확인 창). 근무 조정의 휴가 취소와 같은 경로 — 확정된 달은 승인 전 칸으로, 그사이 바뀐 날은 알림.
5. `users.weekend_pair_wanted`(기본 true, 0011). 규칙 안내 맨 위 「나는 매달 주말 이틀 통 OFF를 받겠습니다」(교대 근무자 본인). 끄면 검사기·솔버가 요구하지 않고 미달 개월 수·이월도 쌓지 않음. 규칙 설정 주말 통 OFF 토글 아래 「본인이 끈 사람 N명: …」.
6. `users.ktas_renewed_on`(0011). 유효기간 = 취득일·갱신일 중 늦은 날 + 3년 − 1일(검사기·솔버·간호사 관리 공통). 내 설정 「KTAS」 — 자격·취득일·갱신일, 만료 예정일 자동 표시, 저장하면 바로 반영 + 관리자 확인 요청(종류 「KTAS 수정」). 간호사 관리 수정 창에도 갱신일.
