# [Stage 3-9] 운영 피드백 5 — 검진 S 고정·연차 승인 생략·확정 달 휴가 부분 리롤·생성 결과 묶음·최대 인원·누적 OFF 범위·표시 정리

## 요구사항 (사용자 2026-10-19, 간호사 쪽 14건)

1. 오프 신청 날이 검진이면 「검진」으로 보이게.
2. 근무 신청을 휴가로 바꿀 때 삭제 → 다시 신청해야 함(예: D 신청 → 연차). 바로 바뀌게.
3. 연차는 관리자 승인 없이.
4. 근무 조정에서도 휴가(병가·연차·경조 등)를 기간으로 넣고, 나머지 듀티를 리롤.
5. 생성 결과의 권고 미충족을 항목별로 묶어 보기 쉽게(예: 「나이트 7개 — 이름, 이름, …」).
6. 생성안 칸에서 정하는 신청에 S·연차·휴가도, D·E처럼 복수 선택도.
7. 검진 반차는 S 근무 — 그날 듀티(D·E·N)를 하지 못한다.
8. 생성 화면의 「바꿀 수 없다」 안내가 페이지 맨 위에만 떠서 안 보인다 → 그 자리에서 안내.
9. 관리자는 OFF를 검진·개원·연차 등으로 바꿀 수 있고, OFF → D·E·N은 막는다.
10. 듀티당 최대 인원 설정(응급실은 듀티당 2명).
11. 휴가 칸은 OFF와 같은 색. 신청한 듀티는 글자도 빨간색. 관리자가 바꾼 칸은 파란 테두리만.
12. 생성안 격자의 주황 점(권고 미충족 칸) 없앰.
13. 누적 OFF 범위를 규칙 설정에(예: −3 ~ +3, 필수).
14. 관리자가 근무 신청 화면에서 넣거나 바꾼 신청은 신청 화면에서도 파란 테두리. 관리자는 간호사 신청을 만들 수는 있지만 **지울 수는 없다**. OFF 신청을 휴가로 바꾸는 것은 된다.

## 결정 (사용자 답변 2026-10-19)

- **1·7 검진:** 승인된 검진 날은 생성 때 **S로 고정**(D·E·N 인원에 세지 않음), 칸에는 **「검진」**(오전·오후는 툴팁). 검진 잔여 0.5 차감은 그대로. 3-6의 「반나절은 근무(D검)」를 뒤집는다.
- **4 부분 리롤:** 확정된 달에 휴가 기간을 넣으면 **휴가 시작일부터 월말까지** 다시 생성(그 전 칸은 고정). 사라질 교환·관리자 수정을 먼저 보여 주고 확인, 결과는 생성안처럼 보고 적용.
- **9·14 OFF → 휴가:** 관리자가 **바로 바꾼다**(간호사 수락 없음, 3-5 「휴가 변경 요청」 흐름 대체). 관리자는 OFF를 D·E·N으로 바꾸지 못하고 간호사 신청을 지우지 못한다.
- **3 승인 생략:** **연차만** 저장(제출)하면 바로 승인. 나머지 휴가는 지금처럼 관리자 승인.

## AI 해석 (승인 때 확인)

- **2:** 근무 신청이 있는 날에 휴가를 저장하면 「이 날 신청(D)을 지우고 연차로 바꿉니다」 확인 → 한 번에 바꾼다(간호사 본인 신청). 반대로 휴가가 있는 날에 근무를 신청하면 「휴가를 취소하고」 확인(승인 전 휴가만).
- **5:** 「모든 듀티 인원 충족」「신청 N건 반영」은 그대로 두고, 권고 미충족은 **규칙별 한 줄**(「나이트 목표 초과 — 이름 4명」, 「N-OFF-E — 이름 2명」). 줄을 누르면 날짜별 상세. 필수 위반은 빨간 점으로 맨 위.
- **6:** 생성안 칸 더블클릭 창 = 근무 신청 팝오버와 같은 선택지: OFF·D·E·N **복수 선택**, S(수간호사 아님 — 교육 등 S 일정), 휴가 종류(연차·검진·개원·특휴·병가 등, 관리자 입력이면 연차처럼 바로 승인 대상은 위 3과 같은 규칙).
- **8:** 생성안 칸 선택 창(격자 바로 위 줄) 안에 빨간 문구로 사유를 띄운다(페이지 맨 위 박스는 생성 자체 실패만).
- **9:** 대상 화면은 **근무 신청**(관리자)과 **근무 조정 도크**(확정된 달) 둘 다. 근무 조정 도크의 OFF 칸에도 휴가 종류 버튼이 생긴다(휴가 기간 → 4 부분 리롤로 이어짐). 근무 조정에서 근무끼리(D↔E 등) 옮기는 기존 편집은 그대로 — 막는 것은 「간호사가 **신청한** OFF」를 D·E·N으로 바꾸는 것.
- **10:** 규칙 설정 「듀티당 최대 인원」(기본 2, 필수/권고 전환 가능, 기본 필수). 트레이닝 3인 기간의 신규·수간호사 S는 세지 않는다(최소 인원과 같은 셈법). 넘는 사람은 OFF가 되므로 누적 OFF가 늘 수 있다(13과 함께 동작).
- **11:** 휴가 칸 배경 = OFF색, 글자는 종류 이름. 신청 반영 칸 = **빨간 글자 + 빨간 테두리**(지금 테두리 유지), 교환 = 빨간 점선 그대로, 관리자 수정·대신 신청 = 파란 테두리(글자 기본색).
- **12:** 생성안 격자 주황 점과 범례 문구 삭제(권고 목록은 5로 대신).
- **13:** 규칙 설정 「누적 OFF 범위」 최소·최대(기본 −3 ~ +3, 필수/권고 전환, 기본 필수). 생성 결과의 월말 누적 OFF가 범위를 벗어나면 위반. 솔버는 필수면 제약, 권고면 큰 벌점.
- **14:** 관리자가 넣거나 바꾼 신청은 신청 화면에서 파란 테두리(3-6에 있음 — 확인·보강), 관리자 팝오버에서 남의 신청 「삭제」 버튼을 없애고 서버도 거부.
