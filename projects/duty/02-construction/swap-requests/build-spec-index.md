## §3. 미해결 질문

없음. 2026-09-30 답변으로 해소했다(DECISIONS).
- Q1 반영 방식 → **모든 당사자가 수락하면 즉시 반영**(핸드오프). 관리자는 수정 이력·근무표 안내로 안다(관리자 승인 단계 없음).
- Q2 교환 범위 → **하루 단위**(핸드오프). 한 요청 = 한 날짜, 그날 선택한 사람들끼리 근무를 바꾸고 D/E/N 개수는 그대로.

AI가 정한 사항(READY 승인으로 확정, 설명은 각 아티팩트):
- 요청할 수 있는 달·때: 확정(CONFIRMED)된 달, 오늘이 그 달의 협의 기간 안. 기본 달 = 협의 기간이 열린 달이 있으면 그 달, 아니면 이번 달.
- 바꿀 수 있는 칸: 교대 근무자의 D·E·N·OFF(일반)만. 휴가·교육·슬리핑오프·S 칸과 수간호사는 제외.
- 재배정 조작: 변경 후 칩을 하나 누르고 다른 칩을 누르면 둘이 맞바뀐다(드래그 대신 두 번 클릭, 키보드로도 가능). 개수가 달라지는 조합은 처음부터 만들 수 없다.
- 수락 시점 재검사: 마지막 수락 때 칸이 요청 당시와 다르거나 새 필수 위반이 생기면 반영하지 않고 "무효"로 닫는다.
- 겹치는 요청: 같은 사람·날짜에 대기 중인 요청이 있으면 경고만 하고 보낼 수 있다. 하나가 반영되면 겹치는 나머지는 무효. 관리자 편집·휴가 승인으로 칸이 바뀌어도 무효.
- 철회: 보낸 사람은 대기 중인 요청을 철회할 수 있다. 협의 기간이 끝나면 대기 요청은 만료.
- 알림: 받은 요청 수를 근무 조정 메뉴 배지·우측 패널 배지·근무표 띠 한 줄로 보여 준다(2-7 Q3 결정대로 "처리할 일 = 근무 조정"). 반영되면 당사자 근무표에 2-7 "바뀐 근무" 안내가 뜬다.
- 관리자 화면(2-7 도크)은 바꾸지 않는다. 관리자도 근무 조정 우측 패널에서 이 달의 교환 요청 현황(읽기 전용)을 본다.
