# Business Rules — 2-3 근무표 조회

## 1. 규칙 표

| ID | 규칙 | 근거 |
|---|---|---|
| R-VIEW-1 | 격자는 MonthPlan 상태가 `CONFIRMED` 또는 `CLOSED`일 때만 보인다. 그 외(없음·신청 중·생성 중)는 빈 상태. 관리자에게는 `DRAFTING`일 때 "듀티 생성에서 생성안 보기" 링크를 더한다 | 1-2 §8 생성안은 관리자만 |
| R-VIEW-2 | 행 순서: ① fixed_weekday(수간호사) — `seniorityRank` 순 ② 로그인 사용자(교대 근무자일 때) ③ 나머지 교대 근무자 `seniorityRank` 순 | 핸드오프 S3 |
| R-VIEW-3 | 행 대상 = 보는 달에 칸이 있는 사용자 ∪ 활성이고 그달에 재직일이 있는 사용자. 비활성이고 칸이 없으면 뺀다 | 1-2 §2 소프트 삭제·과거 보존 |
| R-VIEW-4 | 로그인 사용자의 행을 강조한다(bg `primary-soft`, 이름 800, 왼쪽 3px `primary` 바). 수간호사 이름은 `admin` 파랑 | 핸드오프 S3 |
| R-VIEW-5 | 칸 표시: D/E/N/S는 코드, OFF(모든 종류)는 "off", AL은 "연", LEAVE는 "휴". 칸 없음은 빈 칸 | 1-2 §2, AI 결정 |
| R-VIEW-6 | 외곽선: `source = admin` → 파랑 inset 2px, `requested` → 빨강 inset 1.5px(관리자 수정이 우선). AL·LEAVE 칸은 외곽선을 그리지 않는다 | 핸드오프 확정 5, 1-2 §5 |
| R-VIEW-7 | 툴팁(`title`): "10/13 (화) · off · 슬리핑오프 · 신청 반영"처럼 날짜·표시·종류·검진 반차·출처. 종류는 모든 사용자에게 보인다 | Q2 모두 공개 |
| R-VIEW-8 | 일자 헤더: 빨간 날(토·일 ∪ 개원기념일 아닌 공휴일)은 bg `weekend-head`·날짜 700, 그 열의 칸 bg `weekend-cell`. 요일 색: 일요일·공휴일 `danger`, 토요일 `admin`, 그 외 `ink-2` | 핸드오프 S3, 2-2 R-BASE-1 |
| R-VIEW-9 | 이월 off = 월초 누적 OFF, 이월 N = 월초 잔여 N, 누적 off = 월말 누적 OFF, ⓝN = 월말 잔여 N, 특휴/개원·검진 = 월말 잔여, 보 = 올해 보수교육 이수 횟수. 개원오프 대상이 아니면 "-" | 1-2 §4 매핑, D4 |
| R-VIEW-10 | 누적 OFF는 색 없이 부호로 표시한다(양수 "+4", 음수 "−2", 0은 "0"). 카드 설명: 양수 "다음 달 반납 {n}", 음수 "다음 달 {n}일 더 받음", 0 "기준과 같음" | Q1 |
| R-VIEW-11 | "이번달 OFF" = 정산 기준 OFF(일반·보수교육·노조교육) / 기준 OFF | Q3 |
| R-VIEW-12 | 월초 잔여 = 마감된 달이면 `month_settlements` 스냅샷, 아니면 원장 현재 합계 + 보는 달보다 앞선 **확정·미마감** 달들을 차례로 `settleMonth`한 증감. 월말 = 월초 + 보는 달 `settleMonth` 증감 | 1-2 §4 원장, 2-2 이월 |
| R-VIEW-13 | 마감된 달의 특휴·개원·검진·보는 `closedAt` 시점까지의 원장 합계로 계산한다 | 과거 달 조회 |
| R-VIEW-14 | 오늘 카드 = 오늘이 속한 달의 확정·마감본에서 로그인 사용자의 오늘 칸. 보는 달과 무관하다. 없으면 "—" | 핸드오프 S3 카드 1 |
| R-VIEW-15 | 기본 달 = 서울 기준 오늘의 달. `?ym`이 `YYYY-MM` 형식이 아니거나 1~12월이 아니면 기본 달 | Q4 |
| R-VIEW-16 | 이번 달을 보고 있고 다음 달이 확정·마감이면 헤더에 "{M+1}월 근무표 확정됨" 링크 | Q4 |
| R-VIEW-17 | 하단 문구: "근무 신청 마감 매월 {requestDeadlineDay}일 · 협의 수정 기간 {다음 달 계획의 negotiationStart}–{End} (관리자 설정) · 누적 off·잔여 N은 연말 정산 없이 계속 이월". 다음 달 계획이 없으면 `defaultPlanDates(M+1)` | 핸드오프 S3, S11 수치 하드코딩 금지 |

## 2. 검증 규칙

| 입력 | 규칙 | 실패 |
|---|---|---|
| `?ym` | `^\d{4}-(0[1-9]\|1[0-2])$`, 2000~2100년 | 기본 달로 표시(오류 화면 없음) |

## 3. 권한

| 동작 | 허용 | 비고 |
|---|---|---|
| S3 조회 | 로그인 사용자 전원(간호사·관리자) | `requireUser`. 확정·마감본만(R-VIEW-1) |
| 휴가 종류·검진 반차·잔여 컬럼 | 전원 | Q2 모두 공개 |
| 코멘트·휴가 사유 | S3에 포함하지 않음 | 1-2 §8 |

## 4. 불변식

- INV1: 화면의 누적 off = 이월 off + (이번달 OFF − 기준 OFF). 수간호사는 이월 off = 누적 off.
- INV2: ⓝN = 이월 N + 이번 달 N − 6 × 슬리핑오프.
- INV3: 종이 10월(가명 시드)에서 10명의 누적 off가 종이 값과 같다.

## 5. 엣지케이스

| 케이스 | 기대 동작 |
|---|---|
| 월 중간 입사 | 입사 전 칸은 빈 칸, 기준 OFF는 재직일만 |
| 수간호사의 빨간 날 | 칸 없음 → 빈 칸 |
| 로그인 사용자가 그달 행에 없음(입사 전) | 요약 카드 대신 안내 "이 달에는 근무 기록이 없습니다" |
| 앞선 달이 생성 중(미확정) | 투영에서 건너뜀 |
| 원장이 비어 있음 | 0으로 계산 |
| 28·30일 달 | 열 수가 날짜 수와 같다 |
