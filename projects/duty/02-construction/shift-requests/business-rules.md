# Business Rules — 2-5 근무 신청·휴가

## 1. 규칙 표

### 1.1 신청 기간·달 계획

| ID | 규칙 | 근거 |
|---|---|---|
| R-REQ-PERIOD-1 | 대상 월 M의 신청 기간 = M−1월 1일 ~ `requestDeadline`(기본 M−1월 15일). 기본 대상 월 = 오늘의 다음 달 | 1-2 §3 |
| R-REQ-PLAN-1 | 신청 화면을 열 때 M의 계획이 없고 오늘이 신청 기간 안이면 `REQUESTING`으로 만든다(`defaultPlanDates`). 신청 기간 전이면 만들지 않고 "신청 기간 전"을 보여 준다 | 1-2 §2 |
| R-REQ-PLAN-2 | 오늘 > 마감일이고 `REQUESTING`이면 `REQUEST_CLOSED`로 바꾼다(`nextPlanStatus` CLOSE_REQUESTS) | 1-2 §3 |
| R-REQ-EDIT-1 | 간호사는 자기 줄만, `canNurseEditRequests`(REQUESTING·마감 당일까지)일 때만 편집·제출 | 1-2 §8 |
| R-REQ-EDIT-2 | 관리자는 누구의 줄이든 계획이 `REQUESTING`·`REQUEST_CLOSED`일 때 편집한다(생성 뒤는 잠금). 관리자 편집은 곧바로 제출 상태 | 1-2 §8, 핸드오프 S4 |

### 1.2 근무 신청

| ID | 규칙 | 근거 |
|---|---|---|
| R-REQ-SHIFT-1 | 한 사람·한 날짜 1건. `options`(OFF·D·E·N 1~4개, or) 또는 `special`(EDU_CONT·EDU_UNION) 중 하나. 코멘트 500자 | 1-2 §2·§6-3, 2-1 스키마 |
| R-REQ-SHIFT-2 | 같은 날에 휴가(임시·대기·승인)가 있으면 근무 신청을 저장하지 않는다("이 날은 휴가 신청이 있습니다") | 3b 팝오버 배타 |
| R-REQ-SHIFT-3 | 노조교육은 노조원·평일(빨간 날 아님)만, 올해 이수 + 올해 신청(보수 1·노조 2 한도) 이내 | 응급실 §8·§9, 2-2 H-EDU-* |
| R-REQ-DRAFT-1 | 팝오버 저장 = 임시(`submitted_at = null`). 제출 = 그달 내 임시 신청 전부 `submitted_at = now`, 임시 휴가 `DRAFT → SUBMITTED` | Q2 |
| R-REQ-DRAFT-2 | 제출된 근무 신청을 고치면 다시 임시가 된다(다른 사람에게는 제출 전 값이 아니라 **안 보임**). 삭제는 즉시 | Q2, 단순성 |
| R-REQ-DRAFT-3 | 마감까지 제출하지 않은 임시 신청은 생성(2-6)에 쓰지 않는다. 하단 바에 "제출하지 않은 신청 {n}건" | Q2 |

### 1.3 휴가 신청

| ID | 규칙 | 근거 |
|---|---|---|
| R-LEAVE-1 | 종류: 연차·경조사(사유 11종 필수)·병가·공가(사유 4종 필수)·특별휴가·검진. 시작일 = 누른 날 | 핸드오프 S5 |
| R-LEAVE-2 | 종료일: 경조사는 사유 일수로 자동(`leaveEndDate`), 검진은 시작일(0.5일), 그 외는 입력(≥ 시작일, 최대 31일). 월을 넘어도 된다 | 핸드오프 S5, 원문 §7 |
| R-LEAVE-3 | 일수: 경조사 = 사유 일수, 검진 = 0.5, 그 외 = 달력 일수 | 원문 §6-8·§7 |
| R-LEAVE-4 | 기간 안에 같은 사람의 다른 휴가(임시·대기·승인)나 근무 신청이 있으면 저장하지 않는다 | 겹침 방지 |
| R-LEAVE-5 | 연차·특별휴가·검진·병가는 **예정 잔여**를 넘으면 저장하지 않는다. 예정 잔여 = 2-3 월말 예정 잔여 − 이 휴가를 뺀 대기·승인 휴가 중 아직 확정 안 된 달의 일수 | 1-2 §6-6, 핸드오프 S5 |
| R-LEAVE-6 | 전이: `DRAFT → SUBMITTED`(제출) → `APPROVED`·`REJECTED`(관리자, 반려 사유 필수) / 본인은 `DRAFT` 삭제, `SUBMITTED → CANCELLED`(신청 기간 안) / 관리자는 `APPROVED → CANCELLED`(생성 전) | 1-2 §3 |
| R-LEAVE-7 | 증빙 첨부 없음. 안내 "증빙 서류는 병원 공문으로 별도 제출" | 핸드오프 v2 |

### 1.4 화면 계산

| ID | 규칙 | 근거 |
|---|---|---|
| R-REQ-VIEW-1 | 격자: 수간호사 제외, 나 먼저("나" pill) → 순위. 우측 "신청" = 제출된 근무 신청 + 휴가 수 | 핸드오프 S4 |
| R-REQ-VIEW-2 | 칸: 단일 옵션은 그 칩 색, 복수는 흰 배경 `O/D`, 교육 `교`(OFF 색), 모두 빨간 인셋 1.5px. 휴가는 `휴`(#D8E6C3, 외곽선 없음) — 승인 채움, 대기·임시 점선. 내 임시 신청은 흐리게(opacity .6) + 툴팁 "제출 전". 코멘트 있으면 점선 밑줄 | 핸드오프 S4·S5, Q4 |
| R-REQ-VIEW-3 | 하단 "OFF 신청 인원" = 날짜별 OFF 단일(제출) 신청 수. 3명 이상이면 빨강 + "3+ 주의" | 핸드오프 S4 |
| R-REQ-VIEW-4 | 카드: ① 내 신청 n건 · OFF a · OFF/D b … · 휴가 c ② "{M}월 기준 OFF x · 누적 ±y · 슬리핑오프 z → 목표 t"(OFF 단일 신청 > t면 경고 배지) ③ 주말 연휴 통 OFF — 전달 정산에서 미배정이면 "우선 대상 ({M−1}월 미배정)" ④ 병동 신청 n건 · 3명 이상 겹친 날 | 핸드오프 S4, Q3 |
| R-REQ-VIEW-5 | 팝오버 안내 "같은 날 신청: {이름} {라벨} …"(제출분) | 핸드오프 S4 |
| R-REQ-VIEW-6 | 관리자 패널 "휴가 승인 대기 {n}건": 이름 · 종류(사유) · 기간 · 일수 · 코멘트 · 승인 / 반려(사유 입력) | Q1 |
| R-REQ-VIEW-7 | 30초마다·창 포커스 때 `router.refresh()`(팝오버가 열려 있으면 미룸) | 1-3 §2 |

## 2. 권한

| 동작 | 허용 |
|---|---|
| 조회 | 전원. 남의 코멘트 본문은 관리자만, 남의 임시 신청은 아무에게도 보이지 않음 |
| 내 신청 저장·삭제·제출 | 본인, R-REQ-EDIT-1 |
| 남의 신청 편집 | 관리자, R-REQ-EDIT-2 |
| 휴가 승인·반려·승인 취소 | 관리자 |

## 3. 엣지케이스

| 케이스 | 기대 동작 |
|---|---|
| 신청 기간 전 달로 이동 | 읽기 전용 "신청 기간 전 ({M−1}/1부터)" |
| 이미 생성·확정된 달 | 읽기 전용 "근무표가 생성되어 신청을 바꿀 수 없습니다" |
| 휴가가 대상 월 밖으로 이어짐 | 저장 허용, 격자에는 대상 월 안의 날짜만 |
| 반려된 휴가 | 본인에게만 칸 툴팁·목록에 반려 사유, 칸은 비어 보임 |
