# Business Rules — 2-10 동료 현황·규칙 안내

## 1. S6 동료 현황

| ID | 규칙 | 근거 |
|---|---|---|
| R-PEER-1 | 모든 로그인 사용자(간호사·관리자)가 본다. 코멘트·휴가 사유는 나오지 않는다(이 화면에 해당 값이 없다) | 원문 §13, 2-3 Q2 |
| R-PEER-2 | 기본 달 = 오늘의 달(`requestToday`). `?ym`이 틀리면 기본 달(R-VIEW-15와 같음). 제목 "동료 현황 · {Y}년 {M}월" 양옆 ‹ › 로 한 달씩 이동 | Q3 |
| R-PEER-3 | 값은 그 달 계획이 `CONFIRMED`·`CLOSED`일 때만 보인다. 아니면 빈 상태 "{M}월 근무표가 아직 확정되지 않았습니다." | R-VIEW-1과 같은 공개 시점 |
| R-PEER-4 | 행 = 그 달 근무표(S3)의 행 대상(R-VIEW-3) 중 **교대 근무자만**(`rotation ≠ fixed_weekday`). 수간호사는 기준 OFF = 실제 OFF라 비교 의미가 없다 | 핸드오프 S6 "수간호사 제외" |
| R-PEER-5 | 열과 값(근무표 R-VIEW-9~13과 **같은 계산**, `loadMonthView`의 balances): 이번달 OFF = `actualOff` · 누적 OFF = `offCarryAfter`(월말) · 이번달 N = `nightCount` · 잔여 N = `nightBankAfter`(월말) · 슬리핑오프 = `sleepingOff` · 주말 연휴 OFF = R-PEER-7 | 핸드오프 S6, 2-3 |
| R-PEER-6 | 누적 OFF는 색 없이 부호(`signed`: "+4", "−2", "0"), 굵게. 핸드오프의 양수 초록·음수 빨강은 쓰지 않는다 | 2-3 Q1 (D1 부호와 색이 맞지 않음) |
| R-PEER-7 | 주말 연휴 OFF: 그 달의 토요일 중 토·일이 모두 쉬는 칸(REST)인 첫 쌍을 "10/24–25"로. 쌍이 여럿이면 첫 쌍 + " 외 {n}". 월말 토요일 쉬고 다음 달 1일(일)이 아직 없으면 "10/31–11/1 예정". 쌍이 없으면 규칙 `weekendPairOffMonthly`가 켜져 있을 때 "미배정 → {M+1}월 우선", 꺼져 있으면 "미배정". 판정은 2-2 `hasWeekendPair`와 같은 쉬는 칸 정의 | 핸드오프 S6, 원문 응급실 §4 |
| R-PEER-8 | 정렬: 누적 OFF 오름차순(가장 많이 받아야 할 사람 위), 같으면 잔여 N 내림차순, 같으면 근무표 행 순서. 우측 "정렬: 누적 OFF ↑" | 핸드오프 S6 설명 문구 |
| R-PEER-9 | 내 행(로그인 사용자) bg `primary-soft` + 이름 뒤 "나" pill. 관리자(교대 근무자 아님)는 내 행이 없다 | 핸드오프 S6 |

## 2. S7 규칙 안내

| ID | 규칙 | 근거 |
|---|---|---|
| R-GUIDE-1 | 모든 로그인 사용자가 본다. 규칙은 **현재 규칙 버전**(`getCurrentRules`)에서 렌더링하고 수치를 하드코딩하지 않는다. 우측 상단 "규칙 버전 v{n} · {저장일}"(버전이 없으면 "기본값") | 핸드오프 S7·S11 |
| R-GUIDE-2 | 목차 7개 = 섹션 7개(§3 표). 목차를 누르면 그 섹션으로 스크롤, 스크롤 위치에 따라 목차 활성 표시가 바뀐다 | Q2 |
| R-GUIDE-3 | 태그 3종: **자동 적용**(#DDEFEB/#0F6E63, 생성·검사가 강제) · **권고**(#FBE7B5/#6B4300, 생성 때 최대한 반영·위반 시 경고) · **안내**(#EEECE6/#6B7270, 시스템이 강제하지 않는 지침). 켜고 끄는 규칙이 꺼져 있으면 태그 대신 **사용 안 함**(안내 색) | 핸드오프 태그 2종 + 강제하지 않는 지침을 "자동 적용"으로 쓰지 않기 위해 |
| R-GUIDE-4 | 금지 패턴은 규칙의 `forbiddenPatterns`를 핸드오프 표기(OFF → "off")로 쉼표 나열 | 2-4 패턴 표기 |
| R-GUIDE-5 | 근무 카드 4장(D·E·N·S)의 시간은 `SHIFT_TIMES`, N은 "익일" 표기와 "휴게 1시간 포함", S는 "K-tass 교육" | 원문 §1, 응급실 §7 |

## 3. S7 섹션·항목 (렌더링 원천)

`{}`는 현재 규칙 값. 문구는 원문 지침을 바탕으로 하되 수치는 규칙에서 넣는다.

| 섹션 | 항목 | 태그 |
|---|---|---|
| 근무 형태 · 순환 | 근무 카드 4장 (R-GUIDE-5) | — |
|  | 근무는 D, E, N 3교대이며 D → E → N 순환을 기본으로 편성합니다. | 안내 |
|  | 주 {workDaysPerWeek}일 근무를 기준으로, 달마다 기준 OFF 수를 정합니다. | 자동 적용 |
|  | K-tass 교육은 S 근무(09:00–18:00)로 배정합니다. | 안내 |
| 휴식 · 금지 패턴 | 서로 다른 근무 사이에는 최소 {minRestHours}시간의 휴식을 보장합니다. | 자동 적용 |
|  | {forbiddenPatterns} 패턴은 편성하지 않습니다. | 자동 적용 |
|  | 연속 OFF(연차 포함)는 최대 {maxConsecutiveOff}일까지 배정합니다. 경조·병가·공가는 세지 않되 연속은 이어집니다. | 자동 적용 |
|  | N 근무 후에는 가능한 한 OFF {offAfterNight}개를 줍니다. 불가피하면 N-off-E를 허용합니다. | 권고 |
| 유급휴일 · 특별휴가 | 유급휴일: 주휴일, 법정 공휴일, 노동절, 개원기념일 1일, 병원 지정일, 노사 협의로 정한 날. | 안내 |
|  | 특별휴가는 해마다 5 × 근무일수 ÷ 365일(0.5 이상 올림, 최대 5일)을 1월 1일에 부여합니다. | 자동 적용 |
|  | 검진 반차 0.5일을 해마다 부여합니다. | 자동 적용 |
|  | 개원기념일에 재직 중이면 개원기념 OFF 1일을 부여합니다. | 자동 적용 |
| 경조 · 병가 · 공가 | 경조휴가(유급) 11종과 일수 표(`FAMILY_LEAVE_DAYS` × `FAMILY_REASON_LABEL`). 신청하면 종료일을 자동으로 계산합니다. | 자동 적용 |
|  | 병가는 업무 외 상병 요양에 연 60일 이내로 줍니다. | 자동 적용 |
|  | 공가: {OFFICIAL_LEAVE_REASONS 4종}에 필요한 기간. | 안내 |
| 오프 정산 · 슬리핑오프 | 기준 OFF보다 적게 쉬면 누적 OFF가 −, 많이 쉬면 +가 되어 다음 달에 더 받거나 반납합니다. 연말 정산 없이 계속 이월됩니다. | 자동 적용 |
|  | 누적 N {sleepingOffPerN}개마다 슬리핑오프 1일을 줍니다. 남은 N은 연말 정산 없이 이월됩니다. | 자동 적용 |
|  | 근무 신청은 매월 {requestDeadlineDay}일까지, 협의 수정은 {negotiationStartDay}–{negotiationEndDay}일에 합니다. | 자동 적용 |
|  | 보수교육 연 {eduContPerYear}회·노조교육 연 {eduUnionPerYear}회(평일, 노조원)는 OFF로 배정합니다. | 자동 적용 |
| 응급실 야간 운영 | 나이트는 월 {targetNightPerMonth}개 이하를 목표로, 최대 {maxNightPerMonth}개로 제한합니다. | 자동 적용 |
|  | 연속 나이트는 {maxConsecutiveNight}일 이내로 제한합니다. | 자동 적용 |
|  | 야간 전담: `nightDedicated` 꺼짐 → "응급실은 야간 전담이 없습니다." / 켜짐 → "야간 전담은 월 {nightDedicatedMaxPerMonth}일(31일 달 {…31}일) 이내, {min}~{max}개월 연속." | 꺼짐: 사용 안 함 · 켜짐: 자동 적용 |
| 응급실 지침 | 듀티(D·E·N)마다 최소 {minStaffPerShift}명, K-tass 권한자 {minKTass}명 이상을 배정합니다. | 자동 적용 |
|  | 저연차만으로 근무를 짜지 않도록 합니다. (`avoidJuniorOnly`) | 권고 / 사용 안 함 |
|  | 한 달에 한 번 주말 이틀(토·일)을 통으로 OFF 배정합니다. 불가능하면 다음 달 최우선. (`weekendPairOffMonthly`) | 권고 / 사용 안 함 |
|  | 신규 간호사는 {trainingMonths}개월 트레이닝 동안 프리셉터와 같은 근무를 하고, 처음 {newbieTripleWeeks}주(경력자 {experiencedTripleWeeks}주)는 3인으로 배정합니다. | 자동 적용 |
|  | 특정 근무자와 계속 겹치지 않도록 합니다(트레이닝 기간 제외). (`minimizeRepeatPairs`) | 권고 / 사용 안 함 |
|  | 한 사람의 D·E·N 개수 차이가 {shiftBalanceTolerance}개를 넘지 않게 합니다(최근 {shiftBalanceWindowMonths}개월). (`balanceShiftTypes`) | 권고 / 사용 안 함 |
|  | 근무표에서 신청 반영 칸은 빨간 외곽선, 관리자 수정 칸은 파란 외곽선으로 표시합니다. | 안내 |
