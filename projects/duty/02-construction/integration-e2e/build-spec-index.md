# Build Spec — 2-9 통합·E2E

## §0. 개요 & 범위
- **목표(한 줄):** 11월 한 달 운영 흐름을 "오늘"을 옮기며 끝까지 따라가는 연속 E2E 1개 + 화면 × 역할 커버리지 점검과 보강.
- **SoT:** 1-3 §10 「신청 → 생성 → 조정 → 마감 → 다음 달 이월」 + 2-5 휴가·2-8 교환(Q2). 각 단계의 기대값은 해당 스테이지 Build Spec을 따른다(재정의하지 않는다).
- **규모/제약:** E2E는 `workers: 1`, 오늘 기본값 2026-10-13(`DUTY_FAKE_TODAY`). 개발 시드: 10월 확정(종이 근무표), 11월 신청 중(마감 10/15), 9월 끝난 달. 기본 규칙: 신청 마감 15일, 협의 기간 16~20일.
- **깊이 티어 & 사유:** `minimal` — 새 도메인·화면이 없고 테스트와 시계 주입만 더한다(1-3 §10).

### §1.1 한 달 흐름 (11월, 오늘을 쿠키로 이동)

| # | 오늘 | 누가 | 하는 일 | 확인 |
|---|---|---|---|---|
| 1 | 10/13 | 간호사 A | 11월 근무 신청(OFF 복수 옵션) 제출 | 신청 화면 제출됨, 관리자 화면에 보임 |
| 2 | 10/13 | 간호사 B | 11월 연차 휴가 신청 | 관리자 4a 패널에 대기 |
| 3 | 10/14 | 관리자 | 휴가 승인 | 신청 격자에 채운 휴 |
| 4 | 10/16 | 관리자 | 11월 생성 → 위반 0 → 확정 | 신청 마감 상태, 근무표 공개, A의 신청·B의 휴가가 반영 |
| 5 | 10/17 | 간호사 A→C | 협의 기간 교환 요청 → C 수락 | 근무표 즉시 반영, "바뀐 근무" 안내 |
| 6 | 10/18 | 관리자 | 근무 조정에서 칸 편집·저장 | 파란 외곽선, 당사자 안내 |
| 7 | 10/21 | 간호사 | 협의 기간 끝 | 「근무 조정」 비활성 |
| 8 | 12/01 | 관리자 | 11월 월 마감 | 마감 배지, 읽기 전용 |
| 9 | 12/01 | 간호사 A | 12월 근무표·신청 화면 | 이월 off·이월 N = 11월 마감 누적 off·잔여 N |

- 사람 A·B·C는 E2E 다른 스펙이 11월에 쓰지 않는 가명 간호사로 고른다(구현 시 `fixtures.ts`에 상수).
- 각 단계는 화면 조작으로 한다. DB 직접 쓰기는 하지 않는다(2-6 E2E처럼 계획 날짜를 미리 만드는 일도 없다 — 시계가 대신한다).
- 시간 예산: 생성 1회 ≈ 20초 → 스펙 전체 2분 이내, 테스트 timeout 180초.

### §1.2 커버리지 표

화면(S1·S3·S4·S5 팝오버·S8·S9 관리자·S9 간호사·S10·S11·내 설정) × 역할(간호사·관리자) × 주요 경로를 표로 만들고, 각 칸에 덮는 스펙·테스트를 적는다.
빈 칸 중 핵심 경로만 메운다. 지금 알려진 후보: 교환 요청 거절·철회, 겹치는 교환 경고, 관리자 편집으로 걸린 교환 무효(통합 테스트만 있음).
2차 범위 화면(S2·S6·S7, 현재 자리 표시)은 표에 "2차"로만 적는다.
