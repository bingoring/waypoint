## 2. 검증 규칙

| 입력 | 규칙 | 실패 메시지 |
|---|---|---|
| 로그인 사번 | trim 후 1~20자 | "사번을 입력해 주세요." |
| 로그인 비밀번호 | 1자 이상 | "비밀번호를 입력해 주세요." |
| 새 비밀번호 | 8~72자 | "비밀번호는 8자 이상이어야 합니다." |
| 새 비밀번호 | 사번과 같으면 안 됨 | "사번과 다른 비밀번호를 사용해 주세요." |
| 새 비밀번호 | 현재 비밀번호와 같으면 안 됨 | "현재 비밀번호와 다른 비밀번호를 입력해 주세요." |
| 새 비밀번호 확인 | 새 비밀번호와 같아야 함 | "비밀번호가 서로 다릅니다." |
| 현재 비밀번호(자발적 변경 시) | 검증 통과 | "현재 비밀번호가 올바르지 않습니다." |
| 명단 CSV 헤더 | `employee_no,name,role,rotation,seniority_rank,seniority_tier,hire_date,k_tass,union_member` 정확히 일치 | "헤더가 다릅니다: …" |
| 명단 CSV 값 | role·rotation·tier는 allowed-set, rank는 양의 정수, hire_date는 빈 값 또는 `YYYY-MM-DD`, k_tass·union_member는 `true`/`false`, 사번 중복 금지 | "{n}행: {필드} {사유}" |

- 모든 검증은 서버에서 한다. 클라이언트의 `required` 속성은 편의용이다.
- 사번 셀은 CSV에서 **문자열 그대로** 읽는다(스프레드시트가 앞자리 0을 지우는 문제는 `.local/roster.example.csv` 주석으로 안내).

## 3. 권한 / 접근 규칙

| 액션·경로 | 허용 조건 | 거부 시 |
|---|---|---|
| `/login` | 누구나. 이미 로그인 상태면 `/`로 이동 | — |
| `/password` | 로그인 사용자 | `/login` |
| `(app)` 경로 전체 | 로그인 + `must_change_password = false` | `/login` 또는 `/password` |
| `/admin/*` | 위 조건 + `role = admin` | 403 페이지("관리자만 볼 수 있는 화면입니다.") |
| Server Action 전체 | 액션 첫 줄에서 `requireUser()`/`requireAdmin()` 호출 | 오류 반환(리다이렉트 아님) |

- `proxy.ts`는 **쿠키 유무만** 보고 `/login`으로 보내는 낙관적 검사다. 권한 판정의 SoT는 서버 레이아웃·액션의 DB 조회다.

## 4. 불변식 (테스트로 지킬 대상)

- INV1: `users.employee_no`는 전역 유일하고, 저장·조회 후 앞자리 0이 보존된다(`'00101'` 왕복).
- INV2: `sessions.id`는 원본 토큰과 같지 않다(해시만 저장).
- INV3: 비활성 사용자는 유효한 세션을 가질 수 없다(검증 시 거부).
- INV4: 저장소에 커밋된 파일에 실명 목록(`.local/`의 원본 명단에서 CI 밖 로컬 스크립트로 확인)이 없다. CI는 `seed/dev.ts`의 이름이 가명 허용 목록과 같은지 검사한다.
- INV5: `db:seed`를 두 번 실행해도 모든 테이블 행 수가 같다.
- INV6: `rule_versions` v1의 값은 `DEFAULT_RULES`와 같다.

## 5. 엣지케이스 · 에러 매핑

| 케이스 | 조건 | 기대 동작 |
|---|---|---|
| 잠금 중 올바른 비밀번호 | `locked_until > now` | R-AUTH-4 문구로 거부, 카운트 변화 없음 |
| 잠금 만료 후 첫 시도 실패 | `locked_until < now` | `failed_count = 1`부터 다시 셈 |
| 동시에 두 기기 로그인 | — | 둘 다 유효(세션 여러 개 허용) |
| 로그인 후 관리자가 비활성화 | R-AUTH-14 이전 요청 | 다음 요청의 세션 검증에서 거부 |
| `next` 파라미터가 외부 URL | `next`가 `/`로 시작하지 않거나 `//`로 시작 | 무시하고 `/`로 이동(오픈 리다이렉트 방지) |
| DB 연결 실패 | 로그인 중 | "일시적인 오류입니다. 잠시 후 다시 시도해 주세요." 서버 로그에는 사번·비밀번호를 남기지 않음 |
| 명단 CSV 사번 중복 | 같은 파일 안 | R-ROSTER-3, 두 행 번호 모두 출력 |
| 부트스트랩 환경변수 누락 | `ADMIN_EMPLOYEE_NO` 없음 | 종료 코드 1 + 필요한 변수 안내 |
