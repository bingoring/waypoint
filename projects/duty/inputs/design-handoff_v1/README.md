# Handoff: 벌써 근무표짤 때가 됐어? — 간호사 근무표 웹

## Overview
동부시립병원 응급실 병동 간호사(약 11명)를 위한 3교대(D/E/N) 근무표 시스템. 간호사는 로그인 직후 **병동 전체 근무표를 한눈에** 보고, 다음 달 근무를 격자 위에서 직접 신청하며, 자신의 누적 OFF·잔여 나이트를 확인한다. 수간호사(관리자)는 규칙 기반으로 듀티를 자동 생성·리롤하고, 개별 근무를 조정하고, 간호사와 규칙 수치를 관리한다.

권한은 두 가지: **간호사**(일반) / **관리자**(수간호사). 같은 앱, 같은 좌측 메뉴에 관리자 항목이 추가되는 구조.

## About the Design Files
`벌써 근무표짤 때가 됐어.dc.html`은 **HTML로 만든 디자인 레퍼런스(프로토타입)**이다. 그대로 배포하는 코드가 아니라, 의도한 외형·동작을 보여주는 참고 자료다. 과제는 이 디자인을 **대상 코드베이스의 기존 환경**(React/Next, Vue, Svelte 등)과 관례로 **재구현**하는 것이다. 기존 코드베이스가 없다면 이 프로젝트에 가장 적합한 프레임워크를 선택해 구현한다(권장: Next.js + TypeScript + Tailwind 또는 CSS Modules, 서버 저장이 필요하므로 DB 포함 — 예: Postgres/Supabase).

HTML 파일 내부의 `<sc-for>`/`{{ }}` 문법과 `class Component extends DCLogic` 로직은 프로토타입 렌더러 전용이다. **마크업 구조·인라인 스타일 값·데이터 생성 로직(규칙 계산)**만 참고하라.

## Fidelity
**High-fidelity.** 색상·타이포·간격·컴포넌트 형태는 최종안이다. 아래 토큰과 화면별 사양대로 픽셀 단위로 재현하되, 코드베이스의 컴포넌트 라이브러리가 있으면 그 위에 스타일을 맞춘다. 격자 안의 근무 데이터(D/E/N 배열)는 규칙에 맞게 생성한 **예시 데이터**이며 첨부 사진과 1:1이 아니다.

## 확정된 결정 사항 (대화에서 사용자가 명시한 것)
1. 웹 이름: **「벌써 근무표짤 때가 됐어?」**. 데스크톱 우선(1280px 기준), 업무용 존댓말 카피.
2. **로그인 직후 첫 화면 = 병동 전체 근무표 격자**(종이 근무표 양식 그대로). 컬럼: 성명 | 이월 off | 이월 N | 1~31일(요일 포함) | 누적 off | ⓝN(잔여 나이트) | 특휴/개원 | 검진 | 보.
3. 근무표 표기 방식은 시안 3개 중 **1c「내 줄 강조형」으로 확정**: 로그인한 간호사의 줄을 맨 위에 고정 + 상단에 내 요약 카드 5개.
4. **D/E/N/OFF/S는 배경색으로 구분, 글자색은 모두 검정(#1B1F1E)**.
5. **본인이 신청해서 반영된 근무: 빨간 외곽선**(inset 1.5px #C8321E). **관리자가 수정한 근무: 파란 외곽선**(inset 2px #1F5AA6). 외곽선 없음 = 시스템 자동 배정. (원본형 1a는 종이처럼 글자를 빨강/파랑으로 하지만 1a는 확정안이 아님.)
6. **근무 신청은 별도 캘린더 화면이 아니라 다음 달 근무표 격자 위에서**(화면 2a). 다른 간호사들의 신청도 격자에 그대로 보인다(가독성 중요).
7. 신청 종류를 "OFF or D / OFF or N"으로 고정하지 않는다. **OFF·D·E·N을 각각 복수 선택(or 조건)** 할 수 있다. 예: 오후 3시 약속 → OFF와 D 둘 다 선택 = "OFF 또는 D 중 하나로 배정". 연차·교육(보수/노조)도 신청 가능.
8. 신청할 때 **코멘트**를 함께 작성. 코멘트는 **수간호사(관리자)에게만** 보인다 — 진짜 오프가 필요한 사람을 판단하는 데 사용.
9. **협의 수정 기간(기본 매월 16~20일)을 관리자가 직접 수정** 가능. 신청 마감(기본 15일)도 규칙 설정에서 변경 가능.
10. **관리자가 규칙 안내의 수치를 직접 수정**할 수 있는 「규칙 설정」 페이지(2b). 예: 근무 간 최소 휴식 16시간, 최대 연속 오프 10일 → 11일. 저장하면 규칙 안내 페이지와 듀티 생성 조건에 자동 반영.
11. **한 달에 한 번, 가능한 한 모든 간호사가 주말 이틀(토·일)을 통으로 OFF** 받도록 배정. 불가능하면 다음 달 최우선.

## 업무 규칙 (요구사항 문서 원문 요약 — 시스템이 구현해야 함)
### 근무 형태
- D 07:00–15:30 · E 14:30–23:00 · N 22:30–익일 07:30(휴게 1h 포함) · S 09:00–18:00(K-tass 교육 근무) · OFF
- D→E→N 순환. 주 5일 근무.
- 교대 근무 사이 **최소 16시간 휴식**.
- **금지 패턴**: E-D, N-E, N-off-D, E-S.
- N 근무 후 가능한 한 OFF 2개. 불가피 시 N-OFF-E 허용(권고).
- 야간근무 월 6일 이하 목표, **최대 7개**. 연속 나이트 **3일 이내**. 응급실은 야간 전담 없음(전담 운영 시 월 15일, 31일 달은 16일 상한).
### 응급실 지침
- 듀티(D/E/N)당 **최소 2명**, 그중 **K-tass 권한자 1명 필수**.
- 되도록 저연차만으로 배정하지 않음.
- 특정 근무자와 지속적으로 겹치는 경우 최소화(트레이닝 기간 제외).
- 신규 간호사: 트레이닝 3개월, 프리셉터와 동일 근무. 첫 3주(등록 시 기간 입력, 변경 가능)는 해당 듀티 인원을 3인으로 계산.
- K-tass 교육 = S. 보수교육(오프라인, 연 1회)·노조교육(연 2회 평일) = OFF 배정.
- 근무 신청 마감 매월 **15일**. 듀티 협의 수정 **~20일**(서로 협의로 바꾸기).
### 오프·나이트 정산 (연말 정산 없이 계속 이월)
- 월 기준 OFF 수(주휴+공휴일)보다 적게 쉬면 **+오프**(다음 달 더 받아야 함), 많이 쉬면 **−오프**(반납). 누적됨. 예: 10번 쉬어야 하는데 8번 → +2.
- 나이트 **누적 6개마다 슬리핑오프 1개**. 예: 잔여 5 + 이번달 8 = 13 → 슬리핑오프 2, 잔여 1.
- 모든 간호사는 서로의 누적 OFF·잔여 나이트를 볼 수 있다.
### 휴가
- 유급휴일: 주휴일, 공휴일, 노동절, 개원기념일 1일, 병원 지정일, 노사 협의일, **특별휴가 5일**(연 단위, 5×근무일수/365, 0.5 이상 반올림: 1~36일→0, 37~109→1, 110~182→2, 183~255→3, 256~328→4, 329~365→5), **검진 반차 0.5일**.
- 경조휴가(유급): 본인 결혼 6 · 자녀 결혼 2 · 직계존속 회갑/칠순/팔순 택1 2 · 배우자 출산 10 · 본인·배우자 부모 사망 7 · 부모 외 직계존속 사망 3 · 자녀와 그 배우자 사망 7 · 형제자매 사망 3 · 백숙부모 사망 2 · 배우자 탈상 2 · 직계존속 탈상 1.
- 병가: 연 60일 이내. 공가: 예비군/민방위, 법원 등 출두, 투표, 천재지변.
### 계정·권한
- 첫 로그인 시 본인이 입력: **연차(매년 1/1 리셋), 잔여 나이트, 이월 오프**. 관리자가 수정 가능.
- 관리자: 듀티 생성·리롤, 타 간호사 근무/오프 조정, 간호사 추가·제거(**사번 필수**), 규칙 수치 수정, 협의 기간 수정.
