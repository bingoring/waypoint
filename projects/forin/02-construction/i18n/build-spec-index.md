# Build Spec — 다국어 (UI 언어 설정 + 목적지 언어로 학습)

## §0. 개요 & 범위

- **목표(한 줄):** 프로필 설정에서 **앱 UI 언어**를 바꿀 수 있고, 온보딩에서 고른 **목적지 나라의 언어로
  학습**이 이루어지게 한다. 야매 없이 — 문자열을 하드코딩된 채로 남기지 않고, 없는 번역을 기계로 채워
  품질을 속이지 않는다.
- **SoT:** TestFlight 피드백 #2·#3 및 2026-08-18 사용자 지시 —
  *"퀴즈나 학습뿐 아니라 앱 ui 레벨의 모든 string에 대해 다국어 지원. 프로필 설정을 통해 앱 ui 언어를
  설정할 수 있고, 온보딩시 선택한 나라 언어로 학습도 되고."* / *"나중으로 미루지 말고 지금 다 구현해."*
- **깊이 티어:** `comprehensive` — 클라이언트 전 화면 + 서버 응답 문자열 + 콘텐츠 차원이 동시에 걸린다.

### 조사: 지금 어디까지 되어 있나 (2026-08-18 전수)

| 영역 | 상태 | 근거 |
|---|---|---|
| **AI 대화의 학습 언어** | **이미 됨.** `langContext{Native,Target}`가 프로필에서 오고 프롬프트에 들어간다. ko/en/de/ja/zh/es/fr 7개 매핑 | `conversation/engine.go:46-95` |
| **발음 채점 로케일** | **이미 됨.** `TargetLang → localeFor → en-US/de-DE/…` | `speech/pronunciation.go` |
| **TTS 목소리** | **이미 됨.** `voicesByLocale` 7개 로케일 | `speech/reference.go:25` |
| **앱 UI 언어** | **0%.** i18n 레이어가 존재하지 않는다. 한국어 문자열 1,728개가 코드에 박혀 있다 | `src/`에 i18n 디렉터리·`t()`·라이브러리 전무 |
| **서버가 보내는 콘텐츠 문자열** | **0%.** 커리큘럼 이름·스텝 이름·브리핑이 한국어 단일 | `내부 curriculum/authored_*.go`, `content/nurse/**` |
| **저작된 학습 대상 문장** | **영어 단일.** `tagline`/`keyPhrases`가 목적지와 무관하게 영어 | `depts*.go`의 `Phrases` |
| **온보딩 선택지** | 모국어 4개·목적지 2개를 제공하지만 `nativeLang`/`destination`은 **저장만 되고 읽히는 곳이 없다** | `grep`: 프로필 조회 응답 외 소비처 없음 |

### 사용자에게 보이는 한국어 문자열 전수 (측정값)

| 영역 | 문자열 | 파일 |
|---|---:|---:|
| 클라이언트 UI 크롬 (`app`/`components`/`data`/`lib`) | 513 | 49 |
| 클라이언트 인테리어 픽스처 (`map/fixtures`) | 1,095 | 29 |
| 클라이언트 그 외 (`map`/`engine`) | 120 | 5 |
| 서버 · 주제 뱅크 290개의 한국어 필드 | 1,769 | 3 |
| 서버 · 손저작 시나리오 `title`/`brief` | 605 | 57 |
| 서버 · 커리큘럼/스텝 이름 | 686 | 5 |
| **합계** | **4,788** | |

**이 수치가 계획의 형태를 정한다.** 한 언어를 늘리는 일은 4,788개 번역이다. 그래서 순서는
**인프라 → 추출 → 번역**이고, 번역은 언어별로 독립 파일이라 뒤에 이어 붙일 수 있다.

### 이 스펙이 명시적으로 거부하는 것

- **기계번역으로 카탈로그를 채워 "지원됨"으로 표시하는 것.** 의료 지시문("헤파린 더블 체크",
  "구획증후군 의심 사정")은 오역이 안전 문제로 이어진다. 번역이 없는 키는 **폴백**으로 원문을 보이고,
  화면은 그 언어를 "지원됨"으로 광고하지 않는다.
- **로케일별로 화면을 분기하는 것.** 분기가 아니라 문자열 치환이어야 한다 — 분기는 한 언어에서만
  고쳐지는 버그를 만든다.

## §3. 비기능 요구

- **번들 크기:** 카탈로그는 로케일당 약 25~35KB(문자열 1,728개). 4개 언어를 모두 정적 import하면
  약 120KB — RN 번들에서 무시할 수 없다. 그래서 §business-logic-model §2의 **정적 맵 + 지연 없음**
  결정을 기록한다(측정 후 필요하면 분할).
- **런타임 언어 변경:** 재시작 없이 즉시 반영되어야 한다. 설정에서 바꾸고 앱을 다시 켜야 한다면
  "설정으로 바꿀 수 있다"는 요구를 절반만 만족한다.
- **누락 안전성:** 키가 없으면 **크래시하지 않고** 폴백 사슬(선택 로케일 → ko → 키 문자열)을 탄다.
  개발 빌드에서는 경고를 남긴다.
