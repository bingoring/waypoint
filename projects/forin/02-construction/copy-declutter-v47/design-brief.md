## 2. 공통 키트 — "누르면 무엇이 될지" 신호 (전 화면 공통)
글로 설명하지 않고 이 신호만으로 읽히게 한다. 같은 뜻에는 항상 같은 신호를 쓴다.

| 뜻 | 신호 | 홈에서의 근거 |
|---|---|---|
| 지금 할 것(화면당 하나) | 잉크 바 + 노란 ▶ 원 + 숨 쉬는 후광 | '이어서' 바 |
| 누를 수 있다 | 잉크 테두리 + 하드 그림자, 누르면 아래로 2~3px·-1° | `.nbh3-go:active` |
| 다음 화면으로 간다 | 오른쪽 끝 `›` (작은 것) 또는 노란 ▶ 원 (주 행동) | 달력 ‹ › |
| 이 자리에서 펼쳐진다 | `⌄` 글리프, 펼치면 아래에서 톡(`nbh3-pop`) | 날짜 → 도장 줄 |
| 듣기 / 말하기 | 🔊 / 🎤 아이콘 원(파랑 / 잉크) | — |
| 새로 온 것 | 빨간 점 또는 빨간 숫자 원, 처음 한 번 흔들림 | 호출 배지 |
| 끝냈다 | 초록 이중선 도장 + 체크가 톡 튐 | 그날 도장 ✓ |
| 진행 중 | 노란 링(채운 만큼) | '이어서' 진행 링 |
| 아직 못 한다 | 흐림 + 점선 + 자물쇠 글리프 — **글 없이** | 미래 날짜 흐림 |

**귀엽게:** 아이콘은 원 안에 넣고 ±3~6° 기울인다(홈 도장 줄). 끝냈을 때 도장이 쾅 찍히듯 1.15배 → 1배.
빈 상태는 긴 문장 대신 수첩 캐릭터 얼굴(NbAvatar·faceWorried 등) 하나 + 한 줄.

## 3. 일터 — 배치 유지, 신호만 맞추기
지금 서가·부서 바인더·정거장 배치는 그대로 둔다.
- **내 부서 카드의 '이어서'**: 홈 '이어서' 바와 같은 노란 ▶ 원 + 후광으로. 일터에서 "지금 할 것"이 홈과 같은 모양이면 설명이 필요 없다.
- **다른 바인더**: 누르면 책이 살짝 들리는 눌림(위로 2px·기울기). 표지가 날아오는 연출(I)은 그대로.
- **'목표 바꾸기' 밑줄 링크** → 연필 아이콘 원(작게, 내 부서 카드 오른쪽 위).
- **부서 바인더**: 진행 중 주제 카드는 노란 링 + ▶ 원, '진행중' 태그는 뺀다. 잠긴 주제는 자물쇠 + 흐림. 범례(완료·진행·남음 숫자 문장)는 색 칩 3개로.
- **정거장**: 지금 우표에 노란 후광(숨 쉼), 다음 우표는 점선, 지난 우표는 초록 도장 — 깃발·PASSED 도장은 지금 그대로.

## 4. 리뷰랩 — 배치 유지, 히어로를 홈 바로
견출지 탭 · 자료 선반 · 히어로 · 목록 순서는 그대로.
- **히어로**: '시작' 잉크 버튼 대신 홈 '이어서' 바 모양 — 왼쪽 "오늘 n장" 빨간 도장, 오른쪽 노란 ▶ 원 + 후광. 화면의 주 행동은 이것 하나.
- **MiniStat 3칸**(저장된 카드 · 마스터 · 복습 대기): 알약 칩 한 줄로 줄인다(📒 n · ⭐ n). '저장된 카드'와 '복습 대기'는 지금 같은 값이라 하나만(앱 쪽 수정 필요).
- **카드 맥락**: 출처 줄 끝 `⌄`로 펼친다(지금도 접힘 — 글리프만 키트에 맞춤).
- **등급 버튼 4개**: 글 라벨 위에 표정 글리프(😣 → 🙂 → 😀 → 😎 같은 수첩 얼굴) + 간격(모노). 누르면 카드가 그 방향으로 기울며 넘어감.
- **숙련 점 3개**: 지금 원형 점 — 채워질 때 톡 튀게.
- **자료 선반 타일**: 지금 모양 좋음. 새 쪽지 숫자 배지가 처음 한 번 흔들림.
- **0장일 때**: 히어로 자리에 캐릭터 얼굴 + "오늘은 끝!" 한 줄, 목록 쪽 빈 문구는 없앤다(같은 말 두 번).

## 5. 게임 허브(휴게실) — 귀엽게
- **행 → 아이콘 타일 2×2** 권장: 게임 아이콘 원(크게, 기울기) + 최고점(모노) + 노란 ▶ 원. 타일 전체가 눌림.
  행 목록을 유지한다면: 행 전체 눌림 + 오른쪽 노란 ▶ 원, 부제는 시간·점수만(앱 반영됨).
- **준비 중 게임**: 흐린 타일 + 자물쇠, 시작 버튼 없음(글 없이).
- **오늘 남은 판**: "오늘 n/m판" 대신 작은 동전·하트 점 m개 중 n개 칠함.
- **최고점**: 트로피 글리프 + 숫자로 통일(지금 화면마다 "최고 n"·"최고 n점" 제각각).
- **게임 안 시작 화면**: "탭해서 시작" 한 줄 + 손가락 글리프가 톡톡(농구는 앱 반영됨). 원 그리기 시간 확인 — 앱 5초 / reference extras.jsx L198 10초.

## 6. 프로필(나) — 배치 유지, 홈 상단 줄과 같은 말투
블록 순서는 그대로.
- **사원증**: 아바타는 홈과 같은 원(테두리 2px), 연속 출근은 홈의 불꽃 알약을 그대로 재사용. LV·XP는 게이지 하나(성장 행의 "LV · XP · n일 연속" 보조줄과 중복 — 둘 중 하나).
- **행들**(성장 리포트 · 동료 · 학습 설정 · 언어 등): 왼쪽 아이콘 원 + 제목 + 오른쪽 값 또는 `›`. 보조 설명 줄 없음(앱 반영됨).
- **칭호 격자와 히든 미션**: 둘 다 '???' 점선 칸 → 홈 도장 줄과 같은 **점선 원 + 자물쇠**, 얻은 것은 아이콘 원 + 초록 체크. 두 격자를 같은 모양으로 맞추면 연달아 있어도 덜 복잡하다.
- **소리 토글**: 🔊/🔇 글리프 알약으로(지금 스위치 + 설명).
- **동료 행**: 폴라로이드 + 이름 + 불꽃 알약(연속)만, 응원 버튼은 손바닥 아이콘 원.
