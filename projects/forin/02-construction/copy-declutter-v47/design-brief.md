# 디자인 지시서 — 홈 v47 기준을 나머지 화면에 (2026-10-19)

> 다음 핸드오프(v48)를 위한 요청서입니다. 홈 개편("달력 한 장 + 버튼 하나")의 기준을 일터·학습·리뷰랩·라운지·나·게임·온보딩 화면에 넓힙니다.
> 문구만 지우면 되는 것은 앱에서 이미 정리했습니다(`apply-list.md`). 여기에는 **화면 구성을 바꿔야 하는 것**과 **핸드오프 reference를 앱에 맞춰 달라는 것**을 적습니다.
> 근거는 화면 감사 3건(코드 기준, 파일:행 포함 — 이 폴더 `audit/` 요약)입니다.

## 0. 기준 — 홈 v47에서 가져올 것
1. **누를 곳은 화면당 하나만 강하게.** 홈의 '이어서' 잉크 바처럼, 주 행동 하나에만 잉크 버튼·후광을 준다. 같은 행동으로 가는 두 번째 문은 없앤다.
2. **같은 숫자는 한 번만.** 진행은 막대·도장·n/m 중 하나로. 같은 화면에서 문장·게이지·범례·카운트로 되풀이하지 않는다.
3. **신호는 둘까지.** "진행 중"을 링+테이프+태그+버튼 네 겹으로 말하지 않는다. 링과 버튼이면 충분하다.
4. **글 대신 그림.** 범례·상태는 글리프 칩으로(홈 달력의 해·노을·달). 조작 안내·시스템 설명·출시 예고는 쓰지 않는다(07 문서 "설명 배제").
5. **못 하는 것은 숨긴다.** '준비 중' 행·꺼진 버튼은 누를 곳처럼 보이지만 눌리지 않는다. 흐린 칩 하나로 줄이거나 아예 뺀다.

## 1. 일터(여정)
**서가(G)** — 진행 규모를 세 번 말한다: 머리 요약 "바인더 n권 · 건물 m" → 건물 패널 "바인더 n권 · 주제 d/t" → 내 부서 카드 6칸 막대.
내 부서 카드 한 장에 굵은 링·테이프·'{부서} 바인더'·'내 부서' 태그·'추정' 태그·'이어서' 버튼·'목표 바꾸기' 링크 7가지가 몰린다.
- 요청: 머리 요약과 패널 요약 중 하나만. '내 부서' 태그 삭제(링과 중복). '목표 바꾸기'는 아이콘 하나로. 강조는 '이어서' 하나.

**부서 바인더(E)** — 같은 진행 4겹: "주제 n · 상황 n · 우표 n" 문장 → 3구간 게이지 → 범례(완료 n · 진행 n · 남음 n) → "d/t 주제".
진행 중 주제 카드는 테이프·주황 링·'진행중' 태그·'이어서' 버튼 4신호.
- 요청: 게이지 + d/t만. 범례는 색 칩 3개(숫자 없음)로. 진행 중 카드는 링 + 버튼, 태그 삭제.

**정거장 트랙(H)** — 현재 우표 카드의 제목과 부제가 단계 이름이 없으면 같은 라벨을 두 번 보인다.
- 요청: 부제는 여러 차례 단계일 때 'n/m'만.

## 2. 학습 허브 · STEP
**허브** — 레벨을 세 번 보인다(헤더 태그 '기초', 표지 'Lv.N', "기초 · 4단계 모두" — 마지막은 앱에서 지움). 표지에 태그 3·칩 3(기분·XP·노트 자동저장).
단계 수를 "n단계로 익혀요"·"d/t"·게이지로 세 번. 건너뛴 티켓은 빗금·취소선·안내·'그래도 할래요' 4신호. 하단 고정 CTA와 '지금' 티켓의 '시작' 버튼이 같은 동작.
- 요청: 레벨 표시 하나, 칩은 XP 하나("노트 자동저장" 칩 삭제), "n단계로 익혀요" 삭제, 건너뛴 티켓은 빗금 + 버튼, 티켓 안 '시작' 버튼 삭제(하단 CTA 하나).
- **핸드오프 맞춤 요청(⚑):** lesson.jsx L70 레벨 설명 줄 — 앱에서 지웠습니다. reference에서도 빼 주세요.

**STEP 1·2** — 머리(태그·유형 라벨·n/N) + 큰 제목 + ✎ 단서 + 판정 버튼 보조문("노트에 저장"·"뜯고 다음 장")까지 글자층이 많다.
- 요청: 판정 버튼 보조문을 아이콘(📒·✂)으로 바꿀지 검토. 순서 배열 시트의 단서 자리에 **흐름 한 줄**("공감 → 이유 → 확인 → 감사")을 둘 때, 그 흐름이 콘텐츠 필드인지(order에 `flow` 추가) 정해 주세요.
- 워밍업 릴의 "탭 → 다음 장면"(⚑)은 조작 안내 — 화살표 글리프로 바꿀 수 있는지.

## 3. 대화
상단 도구 탭 3(차트·약물·활력) + 미션 묶음 + 스레드 + 감정 변화 + 선택지(접기 머리) + 입력 레일(보내기·듣기·힌트·노트)이 한 화면에 있다. 입력 영역은 'SPEAK FREELY'·플레이스홀더·녹음 안내 3겹이었다(앱에서 안내 2개 줄임).
- 요청: 녹음 중에는 마이크 상태(파형·색)만 바뀌게 — 글 안내 없이. 도구 탭 3개를 아이콘 하나(차트 시트)로 합칠지 검토.
- **⚑:** dialogue.jsx L173 "단어 칩 탭 → 삽입" — 앱에서 지웠습니다. reference도.

## 4. 결과
카드 10종 이상(도장·아바타·요약 4칸·미션·점수·빨간펜·발음·레벨업·칭호·원장·공유·버튼). XP가 요약 칸과 원장에 두 번, '새 표현' 칸은 '빨간펜 n곳'과 늘 같은 값, 연속 출근이 도장과 글로 두 번.
리뷰랩 가는 길 둘('모두 보기'·'오답노트 보기'), 공유 둘('↗ 공유'·'라운지에 공유').
- 요청: 요약 4칸이 대표 수치 — 원장 XP 줄과 '새 표현' 칸 삭제. 리뷰랩 경로 하나, 공유 하나. 강조는 '다음 시나리오' 하나. 칭호·레벨업은 받았을 때만 한 장.
- **⚑:** session.jsx L149 "빨간펜 3곳 → 복습 노트에 저장됨" — 앱은 "빨간펜 n곳"으로 줄였습니다.

## 5. 리뷰랩
첫 카드 전에 헤더가 7층(제목+"오늘 복습할 것 N" → 견출지 탭 → 자료 선반 → 히어로 → 등급 안내(앱에서 지움) → MiniStat 3칸 → 필터 칩).
같은 숫자(`cards.length`)가 제목 옆·히어로 도장·'저장된 카드'·'복습 대기'·탭 숫자·'전체 N' 칩에 6번 — **'저장된 카드'와 '복습 대기'는 늘 같은 값(버그성).**
카드 한 장에 출처·태그 2·맥락 접이식·원문/교정·🔊🎤·왜?·숙련 점·등급 버튼 4 — 리스트에서 바로 채점해 '복습 시작' 세션과 기능이 겹친다. 0장일 때 히어로와 빈 목록이 같은 말을 두 번.
- 요청: 히어로와 첫 카드가 첫 화면에 보이게(MiniStat 삭제 또는 히어로 안 한 줄). 숫자는 히어로 도장 하나. 리스트 카드는 읽기 전용(채점은 세션에서만) 또는 그 반대 — 한쪽으로.
  0장일 때는 히어로만.

## 6. 라운지 · 글쓰기 · 동료

## 7. 나(사원증)
세로 9블록(사원증 → 성장 리포트 → 동료 → CAREER PATH → 칭호 15칸 → 히든 미션 → 리뷰랩 티저(앱에서 지움) → 설정 4섹션).
LV·XP가 사원증 게이지와 성장 행 보조줄에 두 번. 칭호 '???' 격자와 히든 미션 '???' 격자가 연달아.
- 요청: 성장 행 보조줄 또는 게이지 하나. 히든 미션을 칭호 격자에 합치기. 설정은 한 줄 "설정 ›"로 접어 별도 화면.
- **결정 필요:** '공개 › 라이브 병동에 나 표시' — 라이브 병동이 홈에서 빠져 지금 아무 데도 그려지지 않습니다(토글이 화면을 안 바꿈). 섹션을 숨길지.
- **⚑:** profile.jsx L166·169·175 언어·소리·로그아웃 보조문 — 앱에서 지웠습니다(오른쪽 값·토글이 이미 보임). reference도.

## 8. 성장 리포트
홈이 같은 근무 달력을 쓰게 되면서 달력이 두 곳에 있다. 하단 '오늘의 근무 시작하기'는 홈 '이어서'와 같은 일.
- 요청: 성장 리포트의 역할을 주간 통계(그래프·수치)로 다시 정하고 달력은 홈에만 — 또는 반대. 하단 버튼 삭제.

## 9. 게임(휴게실)
4행 중 2행(종이비행기·펜 뚜껑)이 '준비 중'에 꺼진 시작 버튼. 행마다 이름 + 규칙 2줄(앱에서 시간·점수만으로 줄임) + 최고점 + 작은 시작 버튼(행 전체가 아니라 버튼만 눌림).
들어가는 카드는 '휴게실', 들어가면 제목이 '쉬는 시간'이었다(앱에서 '휴게실'로 통일).
- 요청: 준비 중 게임은 흐린 아이콘 칩으로 한 줄. 행 전체 탭. 최고점 표기 통일("최고 n"). 원 그리기 시간 확인 — 앱 5초 / reference extras.jsx L198 10초.
- 농구: 시작 오버레이는 "탭해서 시작" 한 줄만(앱 반영).

## 10. 발음
헤더 '발음' 배지와 단계 제목 '발음 연습'이 둘 다 '발음'. 약물·용량 주의 메모(RiskNote)가 문장과 상관없이 늘 녹음 버튼 위에.
결과의 드릴 버튼은 자물쇠가 달린 채 꺼져 있음(앱에서 "곧 제공돼요"만 지움).
- 요청: 배지와 제목 중 하나. 주의 메모는 약물·용량이 든 문장에서만(판정 규칙이 필요하면 콘텐츠 태그로). 눌리지 않는 드릴 버튼은 빼거나 열 때까지 숨김.

## 11. 온보딩(여권 발급)
빈칸 깜빡임 + 금색 테두리 + 하단 "직업을 골라요 · 2/4" 메모로 같은 안내 3번. 직업 피커 4개 중 3개 '준비 중'.
- 요청: 하단 메모를 n/4 점 4개로. 준비 중 직업은 흐린 칩 한 줄. 사진 단계 안심 문구·목적지 메타 설명은 앱에서 지웠습니다(⚑ flow2.jsx L219·L253 — reference도).
