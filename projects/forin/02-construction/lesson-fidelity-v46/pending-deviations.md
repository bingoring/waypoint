# v46 미승인 편차 18건 — 승인 여부 정리 (2026-10-09)

Build Spec §7에 "미승인"으로 남은 편차를 다섯 묶음으로 나눴다. 각 항목에는 핸드오프와 다른 점, 그렇게 한 이유, 권고를 적었다.
결정은 §7 표의 상태 칸에 옮겨 적는다.
