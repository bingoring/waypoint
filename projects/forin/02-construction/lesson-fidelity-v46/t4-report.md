## 화면 흐름 (§L)

한 라우트(`scenario/[id]/sentences.tsx`) 안의 단계, 나가기는 어디서든 허브로. 없는 화면은 건너뜀(R3).

1. **C0 릴**(`SentReel`) — 태그 "STEP 2 · 워밍업"·"30초", 장면 수만큼 파란 칸, 제목 "외우지 말고 *세 장면*에서…"(수는 글자로).
   테이프 카드 minHeight 240, 뒷카드 2장(2°·-1.2°), 탭 → swipe-out 380ms → 다음 장면 swipe-in. 끝에 감상 카드(swipe-in):
   칩은 다시 고를 수 있고, 노트 저장은 처음 고른 것 한 번(`api.reelFeel`, 서버도 단어당 1장), 뉘앙스 메모 펼침(reveal).
   CTA "STEP 2 · 문장 학습 시작 ›" 점선 .5 → 잉크.
2. **문장장**(`SentSheets` + `SentPrompt`, `SheetStack` 위) — 태그 "STEP 2 · 문장" + n / N, 장마다 칸(잉크/빨강, .3s), 제목
   "{상황} — 뜻을 보고 *문장을 만들어*보세요". 장 수 = 문장 수(+순서 배열 1), 유형 = listen·build·blank·listen·order·build 주기, 재료가
   없으면 다음 유형(R4). STEP 1에서 틀린 단어의 문장이 먼저. 확인 → 같은 장 아래 해설(reveal, GOOD/RETRY 이중선 nb-ok) → 틀리면
   흔들림 → 아직 헷갈려요(왼쪽 뜯김, 노트) / 외웠어요·이제 알겠어요(오른쪽 뜯김) → 다음 장 rise·stub → DONE 장(파란 도장, 집계).
3. **C5**(`SentContext`) → 4. **C6**(`SentSwap`) — 항목마다 한 화면, 확인 → [따라 말하기][다음 ›].
5. **C'**(`SentPassed`) — PASSED(nbl-pop), 문장별 점수 원 + 스피커, CTA "STEP 3 · 가이드 대화로 ›" → `clearLessonStep(id,'sentences')` →
   `/dialogue/{id}?guide=guided`(v44 그대로).
