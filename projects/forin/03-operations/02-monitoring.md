## 입력 (Inputs)

- 배포: [`01-deployment.md`](01-deployment.md)

> ⚠️ **착수 전에 알아야 할 실측 사실 (3-1 §12.5, 2026-08-15)**: **외부 업타임 체크에 `/healthz`를 쓰면 안 된다.**
> 라우트는 Stage 2-1부터 `/readyz`와 같은 블록에 등록돼 있고 코드는 정상인데, **`/healthz`라는 정확한 경로만
> Cloud Run 앞단에서 가로채져 컨테이너에 닿지 않는다**(공개 URL로 호출하면 `server: Google Frontend` 헤더조차 없는
> 구글 HTML 404가 온다. 후행 슬래시 `/healthz/`를 붙이면 앱에 도달한다). staging·prod 동일.
> **살아 있는 서비스를 404로 "죽음"으로 보고하게 되므로** `/readyz`(postgres·redis 검사 포함)를 쓰거나 라이브니스
> 경로를 가로채지지 않는 이름으로 바꾼다. 컨테이너 포트로 직접 가는 Cloud Run 자체 프로브는 GFE를 거치지 않아
> 영향이 다를 수 있으나 **그건 실측하지 않았다.**
