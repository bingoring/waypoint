# [PRD v0.1 — DRAFT] App Factory

> **상태:** AI 초안. 사람(오너)이 검토·수정 후 확정한다. 이 문서는 모든 스테이지의 최상위 입력이다.
> **작성일:** 2026-10-13

## 1. 목표

간단한 유틸리티·캐주얼 앱을 **앱당 1~3일** 안에 만들어 Android(우선)·iOS에 배포하고, 광고(AdMob)로 수익화한다.
장기 목표는 포트폴리오 합산 **월 광고 매출 1,000만 원**이다.

- 이 목표는 "앱 수 × 평균 매출"이 아니라 **소수의 히트 앱**이 만든다는 전제를 둔다.
- 따라서 핵심 역량은 다음 루프를 빠르고 싸게 돌리는 것이다: **빠른 제작 → 출시 → 지표 판단 → 확장 또는 중단**

## 2. 범위

### 2.1 플랫폼 (App Factory)

| ID | 요구사항 |
|----|---------|
| FR-1 | 공통 코어: 광고(배너·전면·보상형·앱 오프닝), 빈도 제한, 동의 처리(UMP·GDPR, iOS ATT), 분석, 원격 설정, 광고 제거 인앱결제, 리뷰 요청, 설정·다국어·테마 |
| FR-2 | 앱 생성기: 설정 파일(앱 이름, 패키지 ID, 색상, 아이콘, 광고 단위 ID, 지원 언어)로 새 앱 프로젝트를 만든다 |
| FR-3 | 게임 키트: 하이퍼캐주얼 게임 공통 요소(점수, 이어하기용 보상형 광고, 판 종료 시 전면 광고, 최고점 저장) |
| FR-4 | 배포 파이프라인: 빌드, 서명, 스토어 업로드, 스토어 메타데이터 관리를 자동화한다 |
| FR-5 | 포트폴리오 지표 수집: 앱별 DAU, 리텐션(D1·D7), ARPDAU, eCPM, 노출 수를 기존 콘솔(AdMob·Firebase)에서 볼 수 있게 이벤트를 표준화한다 (자체 대시보드는 만들지 않음) |

### 2.2 앱 카테고리 (오너 승인: A~E 전부)

- **A. 하이퍼캐주얼·퍼즐 게임:** 2048, 스도쿠, 블록 퍼즐, 워드·초성 퀴즈, 반응속도·색 구별·기억력 테스트
- **B. 재미·랜덤 도구:** 로또 번호 생성기, 사다리·룰렛·제비뽑기·팀 나누기, 운세·타로, 심리테스트·궁합
- **C. 생활 계산기:** 연봉 실수령액, 퇴직금, 대출 이자, 주휴수당, 부가세, 평수 변환, 더치페이, 팁, 단위 변환, 만나이, 디데이
- **D. 센서·디바이스 도구:** 수평계, 소음 측정기, 나침반, 돋보기, 자·각도기, 손전등, QR, 비밀번호 생성기
- **E. 습관·트래커:** 물 마시기, 금연·금주 카운터, 뽀모도로·공부 타이머, 인터벌 타이머

### 2.3 제외 범위

- 배경화면·벨소리 앱 (저작권 위험)
- 의료·건강 측정을 내세우는 앱 (정책 위험)
- 백엔드 서버가 필요한 앱 (MVP 단계에서는 오프라인 동작 또는 서버리스만 허용)
- 사용자 계정·로그인

## 3. 제약 조건

| 제약 | 내용 |
|------|------|
| 기술 스택 | Flutter + Melos 모노레포 (오너 선호, 1-3에서 확정) |
| 스토어 정책 | Google Play 반복 콘텐츠(Spam) 정책과 Apple 4.3을 위반하지 않는다. 앱마다 핵심 기능이 실제로 달라야 한다 |
| 개발자 계정 | Google Play 신규 개인 계정은 비공개 테스트(테스터 12명, 14일)가 필요하다. 조직 계정은 면제된다 |
| 광고 정책 | AdMob 무효 트래픽·광고 배치 정책을 준수한다. 전면 광고에는 빈도 제한을 적용한다 |
| 운영 비용 | 서버 비용 0원을 목표로 한다 (Firebase 무료 티어 범위) |

## 4. 성공 기준

- 2번째 앱부터 **아이디어 → 스토어 제출까지 3일 이하**
- 공통 코어 변경이 모든 앱에 재빌드만으로 반영됨
- 출시 30일 후 앱별 지표로 확장·유지·중단을 판단할 수 있음
