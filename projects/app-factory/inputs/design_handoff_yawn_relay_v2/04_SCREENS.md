# 04 화면 — 객차 v2 (세로로 긴 판)

시안: `Yawn Handoff v2.dc.html` 섹션 C. 객차 화면 외 화면은 v1 그대로.

## 세로 구성 (위 → 아래)
| 띠 | 높이 | 내용 |
|---|---|---|
| 상태바 | 28 | 시스템 |
| 머리줄 | 56 | 역 표지판(노선 칩 + 역 번호) · (터널 노선만) 터널 알약 · 다시 48 · 멈춤 48 |
| 판 영역 | 남은 높이 | 객차 바닥, 세로·가로 가운데 |
| 툭 표시 | 손 36 + 6 + 숫자 + 위 6 / 아래 10 | 「2 / 3」(Mono 12) — v2는 「툭」 글자 없음 |
| 내비 바 | 20 | 시스템 |
설명 줄 없음. 첫 역만 손가락 안내(v1 범위 밖).

## 칸 크기 규칙
```
가용 폭 = 화면 폭 − 화면 여백×2 − 바닥 좌우 여백×2
가용 높이 = 화면 높이 − (28 + 56 + 툭 70 + 20) − 바닥 위아래 여백×2 − 위아래 최소 16
칸 = min(72, floor(가용 폭 ÷ 열), floor(가용 높이 ÷ 행))
칸 < 64 이면 → 바닥 여백을 줄인다(최소 위아래 14 / 좌우 12), 화면 여백 6까지. 칸은 64 아래로 내리지 않는다.
```
| 화면 | 판 | 칸 | 바닥 여백 (위아래/좌우) | 바닥 크기 | 남는 세로 |
|---|---|---|---|---|---|
| 412×915 | 5×8 | 68 | 18 / 20 | 380×580 | 약 150 (위아래 반씩) |
| 360×780 | 5×8 | 64 | 14 / 12 | 344×540 | 약 70 |
| 360×780 | 3×3 | 72 | 22 / 26 | 268×260 | 가운데 정렬 |
| 412×915 | 3×3~4×4 | 72 | 22 / 26 | v1 그대로 | |

- 좌우 벽 창문 띠(폭 8)는 바닥 여백 안쪽 4dp에 그대로.
- 작은 판: 칸을 72 위로 키우지 않는다. 바닥 그림자(0 20 50 rgba(0,0,0,.35))로 무게를 줘 휑하지 않게.

## 화면 4종 (시안)
1. **412×915 · 5×8 · 20명** — 근시, 까치발, 이어폰, 마스크, 커플, 고양이, 서서 가는, 코골이, 창문 2, 알람 1이 섞인 판. 한 줄 빛남(전파 중).
2. **360×780 · 5×8** — 같은 판, 칸 64.
3. **412×915 · 터널 중** — 판 밝기 35%, 시선선 꺼짐, 벽 띠가 터널 벽 불빛, 머리줄 터널 아이콘 채움 + 0. 툭 하나 사용한 상태.
4. **360×780 · 3×3** — 작은 판 기준.

## 터널 상태 흐름
| 박자 | 화면 |
|---|---|
| 남은 3 · 2 | 알약 숫자만 줄어듦 |
| 남은 1 | 숫자 1 + 판 깜빡임 1회(150ms) |
| 터널 | 150ms에 어두운 막·벽 전환, 시선선 숨김, 알약 아이콘 채움 · 0 |
| 다음 박자 | 150ms에 원래대로, 숫자는 다음 터널까지 남은 박자로 |
