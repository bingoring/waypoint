## SVG 규격 (v1과 다름)
- v1 SVG가 깨진 원인 — 확인할 수 없었다. v2에서는 내보내기 직후 XML 파싱 + 이미지 디코딩을 거쳐 검증했다.
- 그림 좌표는 v1과 같은 **64×64 그리드**. 파일은 팔·z·말풍선이 잘리지 않도록 여백을 둔 **viewBox `-16 -22 96 96`**(192px)로 저장 — 64 그리드의 (0,0)이 파일의 (16,22).
- 범위 효과가 있는 프레임(`*_waves`, `*_wave`, `talker_fly_*`, `standing_step_*`, `earphone_bounce`)은 옆 칸까지 그려지므로 **viewBox `-48 -40 160 160`**(320px) — 64 그리드 한 칸 = 옆 칸 가운데까지 보인다.
- 글자(z, 드르렁, !)는 Gaegu 기준. 글꼴이 없는 뷰어에서는 대체 글꼴로 보인다. 앱에서는 스프라이트로 굽거나 글자로 그린다.
- 파일 이름: `{기믹}_{상태}_{방향|프레임}.svg`. 예: `snorer_yawn_2.svg`, `standing_step_l.svg`, `tile_alarm_ring_1.svg`, `line_icon_13_cat.svg`.

## 렌더러 옮기기 (Dart)
- `P(o)` 입력: `a`(승객 외형 0–5), `kind`, `dir`(d/l/r/u), `st`(awake·yawn·nod·asleep·lean·startle·turn·refuse·glare·drowsy), `f`(정지 프레임 번호 — 주면 애니메이션 없이 그 프레임), `side`(꾸벅·기대는 쪽 ±1), 그리고 기믹별 옵션(아래 03 표).
- 그리는 순서: `under → back → body → head(hd+face) → front → top`. 서서 가는 승객만 사람 전체를 `translate(5,-10) scale(.84)`로 줄여 손잡이·다리 아래에 얹는다.
- 변형은 모두 `transform-origin`이 64 그리드 좌표(몸 `32,63` · 머리 `32,40`)로 정해져 있다.
- `kind` 글자: B 기본 · P 휴대폰 · C 커피 · M 말똥말똥 · S 두리번 · N 코골이 · Y 우는 아기 · T 잠꼬대 · K 마스크 · W 서서 가는 · O 근시 · J 까치발 아이 · E 이어폰 · G 고양이. 커플은 kind가 아니라 `hand: 'l'|'r'` 옵션.

## 오너 답 (2026-10-17) — 반영됨
1. 우는 아기 울음 범위 = 상하좌우 바로 옆 칸만. 아기 칸 파동 범위 그림 추가.
2. 잠꼬대 말풍선을 받은 사람 = 다음 박자에 보통 하품(별도 프레임 없음).
3. 커플 = 대학생 + 학생.
4. 노선 색 = 새 20색 채택(1–5호선 포함).
5. 툭 표시 = 숫자만(「2 / 3」).
