# 핸드오프: 하품 릴레이 (Yawn Relay, 가칭)

Android 세로 화면용 하이퍼캐주얼 퍼즐 게임. 밤 지하철 객차에서 승객을 「툭」 쳐서 하품을 시선 따라 옮겨, 객차 전체를 재우는 게임.

## 대상 스택
- **Flutter** (Android 우선, 한국어·영어)
- 캐릭터: SVG 원본 → 앱에서는 미리 그린 스프라이트 시트(@2x·@3x PNG)로 변환해 사용 (또는 `flutter_svg` / CustomPainter로 부품 조합 렌더)

## 이 파일들의 성격
`reference/` 안의 HTML은 **디자인 레퍼런스(동작하는 시안)** 이지 프로덕션 코드가 아니다. 모양·움직임·규칙을 Flutter로 **다시 구현**한다. HTML/React 코드를 옮겨 쓰지 않는다.

## 충실도
- **하이파이(hifi)**: 색, 글꼴, 크기, 간격, 박자 타이밍, 화면 흐름 모두 최종안 기준. 단위 px = dp로 읽는다.
- 예외: 캐릭터는 **1차 시안**. 부품 구조·비율·표정 체계는 확정, 세부 일러스트는 아트 작업에서 다듬어도 된다.
- 디자인 시스템이 없어 자체 팔레트를 정의했다(→ `01_DESIGN_TOKENS.md`).

## 시안 실행
`reference/prototype/Yawn Relay.dc.html`을 브라우저로 연다(같은 폴더의 `support.js`, `android-frame.jsx` 필요, 인터넷 연결 필요 — 글꼴·React CDN).
- 왼쪽 휴대폰에서 실제로 플레이된다. 노선 5개 · 역 10개.
- Tweaks(편집기 상단): 시작 역, 다크 모드, 글자 130%, 슬로모션 ×3.
- 오른쪽: 캐릭터 시트(6종 × 방향 4 + 하품 + 잠듦), 특수 승객, 후보 승객·타일.

## 시안에서 내린 규칙 해석 — 오너 확인 필요
1. **커피 승객은 승리 조건에서 제외**(영영 안 자므로). 커피를 툭 치면 거절만 하고 툭은 줄지 않는다.
2. **말똥말똥**: 첫 하품은 「중간 졸음」으로만 바뀌고 남에게 퍼뜨리지 않는다. 두 번째에 하품하며 잠든다. 같은 사람을 두 번 툭 쳐도 된다.
3. **두리번**: 하품이 번지는 박자마다만 시계 방향(위→오른쪽→아래→왼쪽)으로 회전. 가만히 있을 땐 고정.
4. **잠든 사람도 시선을 가린다**(시선은 처음 마주치는 한 사람에서 멈춤).
5. **노선 열림**: 노선 N의 마지막 역(환승역)을 깨면 노선 N+1이 열린다. 열린 노선은 언제든 골라 그 노선의 「다음 역」을 할 수 있다.
6. 후보 6종(코골이, 우는 아기, 잠꼬대, 마스크, 기둥, 출입문)은 **그림만 있고 시안 로직엔 없다.**

## 하지 않은 것
- 로고(앱 이름 가칭), 다른 장소(버스·교실 등) 노선도, 실제 광고 SDK 연동(광고는 3초 카운트다운 시뮬레이션).
