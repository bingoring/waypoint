# 06 움직임

규칙이 박자에 묶여 있으므로 **길이는 고정**. 슬로모션 테스트는 모든 값 ×3.

## 박자 (0.65초)
```
t=0     툭 → 승객 눌림(120ms)
t=120   하품 시작 (520ms) + 말풍선(900ms)
t=570   박자 판정: 하품 중인 사람을 보던 사람 찾기 → 시선선 점선→실선(200ms)
        두리번 승객 회전
t=640   하품 끝 → 꾸벅 → 잠듦
t=770   다음 사람 하품 시작  (= 이전 하품 시작 + 650ms)
...     더 옮길 사람이 없으면 +250ms 뒤 결과 판정
```
결과: 전원 잠듦 → 조명 어둡게 500ms → 도착 카드. 툭 없음 + 깨어 있는 사람 있음 → 부릅뜸 → 600ms 뒤 패배 카드. 툭 남음 → 다시 대기.
연쇄 중엔 입력을 막는다(커피 거절 탭 포함).

## 움직임 표

| 순간 | 움직임 | 길이 | 이징 / 키프레임 |
|---|---|---|---|
| 툭 | 승객이 눌렸다 튀어 오름, 기준점 발밑(32,63) | 120ms | 0% 1,1 → 45% scale(1.1,.84) → 100% 1,1 |
| 하품 | 4프레임 + 스쿼시·스트레치, 몸 -4 들림 | 520ms | 0% 1,1 → 30% (.88,1.3) 스트레치 → 62% (1.1,.86) 스쿼시 → 82% (.97,1.04) → 100% 1,1 |
| 하품 눈물 | 양쪽으로 튀어 사라짐 | 520ms | 25%까지 숨김 → 45% 보임 → 100% (±8,-6) 이동하며 사라짐 |
| 말풍선 | 튀어나와 떠오르며 사라짐 | 900ms | 0% scale .3 +8 → 22% scale 1.18 → 35% 1 → 80% 유지 → 100% -10 사라짐 |

## 허용되는 반복 움직임
상태를 알려 주는 것만: 깜빡임(깨어 있음), 숨·z·잠버릇(잠듦), 지금 역 표시, 힌트 원, 커피 김. **깨어 있는 승객은 그 밖엔 가만히** — 하품·꾸벅의 요란함이 돋보이도록 무대는 조용하게.

## 소리·진동 (제안)
툭 = 짧은 진동 + 「툭」. 하품 = 사람마다 다른 「하아암」 음정(연쇄될수록 반음씩 올라감). 꾸벅 = 「픽」. 승리 = 안내 방송 차임(가상).
