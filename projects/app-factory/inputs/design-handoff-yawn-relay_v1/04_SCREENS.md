# 04 화면

기준 화면 412×892dp(시안 Android 프레임). 상태바·내비 바 제외한 영역 기준.

## 1. 노선도 (홈)
배경 `paper`. 세로 3단.

1. **머리줄** (패딩 8/8/4/20)
   - 왼쪽: 「노선도」 22/700 + 「고른 노선 · 3호선 · 새벽선」 13 `muted`.
   - 오른쪽: 설정 아이콘 버튼 48.
2. **노선도 스크롤 영역** (flex 1, 좌우 16, 세로 스크롤만, 스크롤바 숨김) → `05_LINE_MAP.md`.
3. **아래 고정 영역** (위 테두리 1 `hair`, 패딩 8/16/12, 간격 12)
   - 대표 버튼 「다음 역 [06 새벽]」 (고른 노선의 다음 역).
   - 배너 광고 자리 56.

상태:
- **첫 실행**: 1호선만 열림 + 흐린 「다음 노선」 예고. 지금 역 = 01 첫차.
- **노선 고른 상태**(기본 예시): 1·2·3호선 열림, 3호선 선택, 4번째는 흐린 예고.
- **노선 개통 직후**: 개통 알림 + 새 노선이 그려지는 연출.
- **노선에 남은 역 없음**: 버튼 「다음 역 공사 중」(비활성). 실제 앱에선 역이 계속 생성되므로 드묾.

## 2. 객차 (판)
배경 `car.bg`, 상태바 어둡게. 진입 = 노선도 역에서 확대(350ms).

1. **머리줄** (패딩 8/8/8/14): 역 표지판 + 오른쪽 「다시」·「일시정지」 아이콘 버튼.
2. **힌트 줄** (새 요소 처음 나오는 역만).
3. **판** (가운데, 남은 높이에서 세로 중앙)
   - 객차 바닥(줄무늬, 모서리 22, 패딩 22/26) + 좌우 벽 창문 띠.
   - 칸: 좌석(칸 안쪽 5/8 여백, 모서리 12) 위에 승객. 빈칸은 바닥만. 창문 타일.
   - 시선선 레이어(승객 아래), 승객, 하품 말풍선(최상단).
4. **툭 표시** (아래 패딩 22).
5. **배너 없음.**

상태: 대기 → 하품 연쇄 중(입력 막음) → 승리 / 패배 / 다시 대기(툭 남음).
일시정지: 반투명 배경(rgba(8,10,14,.55)) + 바텀시트 「잠깐 멈춤」, 대표 「계속」, 보조 「노선도」.

## 3. 도착 카드 (승리)
1. 마지막 승객 잠듦 → 객차 조명 어두워짐(500ms).
2. **0.5초 뒤** 위에서 안내 방송 띠 내려옴, 동시에 카드 올라옴(150ms 늦게).
3. 카드 구성:
   - 「도착」 13/600 `muted`
   - 번호 동그라미 32 + 역 이름 28/700
   - 「다음 · 안개」 14 `muted` (환승이면 「다음 · 졸음쉼터 · 4호선 환승」)
   - 대표 「다음 역」 56
   - 보조 「노선도」 48
- 점수·별 없음.
- **고른 노선의 마지막 역**: 「다음 역」이 새로 열린 노선의 첫 역으로 이어짐. 이어질 역이 없으면 대표 = 「노선도」, 부제 「이 노선 다음 역은 곧 개통해요」.

## 4. 패배 카드
패배 순간: 깨어 있는 승객 전원이 **부릅뜸** 표정으로 바뀜 → 0.6초 뒤 카드.

구성:
- 맨 위 줄: 왼쪽 「‹ 노선도」(보조, 높이 40), 오른쪽 「실패 2회」 Mono 12 `muted`.
- 얼굴 + 문구 줄: 왼쪽 어두운 상자(`#1B1F28`, 모서리 20, 패딩 10) 안 부릅뜬 얼굴.
  - **한 명(니어미스)**: 얼굴 96. 제목 「딱 한 명이 안 자요」, 부제 「툭 한 번이면 될 것 같은데…」.
  - **여러 명**: 최대 3명(2명 60, 3명 이상 44). 제목 「N명이 아직 말똥말똥해요」, 부제 「누구부터 건드릴지 다시 골라 봐요」.
- 버튼:
  - 니어미스: 대표 = 보상형 「광고 보고 한 번 더 툭 [+1 툭]」, 보조 「다시」.
  - 아니면: 대표 「다시」.
  - **같은 역 3번 실패 뒤**: 보조 보상형 「광고 보고 힌트 · 첫 툭 자리 표시」 추가.
- 보상: +1 툭 = 판 상태 유지, 부릅뜸 → 원래 표정, 툭 1개. 힌트 = 판 초기화 + 정답 첫 칸에 노란 점선 원(맥동).

## 5. 설정
배경 `paper`. 머리줄: 뒤로 + 「설정」 22/700. Material 3 목록.

| 묶음 | 항목 |
|---|---|
| 구매 | 광고 제거 (부제 「₩3,300 · 배너와 전면 광고를 끕니다」), 구매 복원 |
| 소리와 진동 | 효과음 (스위치), 진동 (스위치) |
