# 03 캐릭터

SVG 원본: `reference/characters/*.svg` (모두 **64×64 그리드**, 128px로 저장, `overflow` 밖으로 팔·말풍선·z가 나감 → 스프라이트 셀은 여유 있게 96×96 그리드 권장).
코드 원본: `reference/prototype/Yawn Relay.dc.html` 안 `function P(o)` — 부품 조합 렌더러.

## 크기
- 판 위 한 칸 **72dp**(열 ≤4) / **58dp**(열 5–6). 승객은 칸 크기 그대로.
- 굵은 외곽선(`#17151D` 2 / 머리 2.2 @64), 큰 눈·입 — 58dp에서도 방향과 표정이 읽혀야 함.

## 부품 체계 (합으로 늘어남)
그리는 순서(뒤 → 앞):
1. `back` — 기지개 팔(하품 때만), 후드
2. `body` — 몸(옷 색 `outfit`) + 옷 장식(`acc`: 넥타이, 칼라, 브로치, 지퍼, 후드끈, 가방끈)
3. `head` — 얼굴형(원 r14 @ 32,25) + 헤어(머리 원으로 클립) + 헤어 장식(올림머리, 삐친머리, 포니테일, 모자 챙)
4. `face` — 눈·눈썹·입·코·안경 (상태와 방향으로 결정)
5. `front` — 소품(휴대폰, 커피 컵, 아기, 거절 손)
6. `top` — 상태 표시(z, 배지, 말풍선, 효과선)

| 부품 | 값 |
|---|---|
| 헤어스타일 `hs` | side(옆가르마), bob(단발), bun(올림머리), cap(모자), messy(삐침), pony(포니테일) |
| 옷 장식 `acc` | tie, collar, brooch, zip, hood, strap |
| 소품 | 휴대폰(P), 커피(C), 아기(Y), 마스크(K) |
| 잠버릇 `quirk` | drool(침), bubble(코 풍선), glasses(안경 미끄러짐), open(입 벌림), snore(코골이) |

## 방향 4종 (시선 = 얼굴 방향, 색으로 구분하지 않음)
| 방향 | 표현 |
|---|---|
| 아래 `d` | 정면. 눈 (26,26)(38,26), 입 (32,33) |
| 왼쪽 `l` | 얼굴 요소가 왼쪽으로 쏠림. 눈 (20.5,25.5)(28.5,25.5), 입 (21,32.5), 코 왼쪽 돌출. 헤어는 오른쪽 뒤로 |
| 오른쪽 `r` | 위의 좌우 반전 |
| 위 `u` | **뒤통수**: 머리 전체가 헤어 색, 양쪽 귀만 보임 |

시선선(점선)이 함께 있어 이중으로 읽힌다.

## 파일 이름 규칙
`{id}_awake_{d|l|r|u}.svg`, `{id}_yawn.svg`(최대 프레임), `{id}_asleep.svg`, `{id}_glare.svg`, `kind_*.svg`, `cand_*.svg`, `tile_*.svg`.
SVG에는 움직임이 빠진 정지 프레임만 있다(움직임은 `06_MOTION.md`). 글자(z, 드르렁)는 Gaegu 글꼴 기준 — 스프라이트로 굽거나 앱에서 글자로 그린다.
