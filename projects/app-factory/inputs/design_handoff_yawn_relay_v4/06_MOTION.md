## 움직임 줄이기 (`prefers-reduced-motion`)
효과 레이어는 **정지 그림 한 장만** 켜 둔다(음표 하나·김 한 줄·파동 정지, 깜빡임 없음). 규칙이 정지 상태로도 읽힌다. 고개 까딱·걷기 사이 프레임·말풍선 튀어나옴 생략(바로 최종 모습).

## 짐수레 흐트러짐 (v4.3, v3 06의 「잠듦 → 수레 넘어감」을 대체)
한 바퀴 3.4초 시안 기준. 주인이 잠드는 순간 = 39%. 모든 조각이 **수레 칸 안에서만** 움직인다.

| 때 | 조각 | 움직임 |
|---|---|---|
| 39–44% | `strap` | 끈이 팽팽해졌다가(scale 1.12×0.9) 「툭」 끊기며 사라짐 + 가운데 노란 튐 선 5개와 「툭」 글씨(0.6 → 1 → 1.3배, 사라짐) |
| 40–56% | `b2` | 살짝 들썩(−5°) → 오른쪽 바닥으로 미끄러져 떨어짐(+16°) → 한 번 통 튀고 멈춤 |
| 42–58% | `b1` | 오른쪽으로 살짝 밀렸다가(+3°) 왼쪽으로 기울어 주저앉음(−7°) → 통 튐 |
| 43–57% | `frame` · `tag` | 틀이 뒤로 누움(scaleY 1 → 0.25, 아래 기준) → 통 튐. 짐표는 손잡이에 매달린 채 같이 누움 |
| 44–50% | `loose` | 바닥에 풀린 끈이 나타남 |
| 52% → | 시선선 | 가로막대가 사라지고 선이 이어지며 빛 |
| 86–100% | 모두 | (깸) 거꾸로 다시 쌓이며 섬 — 살짝 위로 튀었다가 제자리, 끈이 다시 묶임 |

앱 길이: 끈 풀림 100ms → 상자·틀 흐트러짐 300ms(조각마다 30ms 차이, 마지막에 통 튐 80ms) — 잠드는 박자 안. 다시 섬 250ms. 움직임 줄이기: 바로 흐트러진 정지 그림.
