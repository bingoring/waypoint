## v4.4 (2026-10-18) — 쩍벌 몸·팔 다듬기
몸 아래 끝을 각진 일자에서 **둥근 엉덩이선**으로 바꾸고, 다리를 엉덩이 아래에서 나오게 안쪽으로 옮겼다. 팔은 좌우 칸 끝까지 뻗지 않고 어깨 옆 등받이에 가볍게 걸친다. 바뀐 그림: `spread_*` 16장, `line_icon_23_spread`(+ 작은 칸). 다른 그림 그대로.

## v4.3 (2026-10-18) — 짐수레: 「넘어짐」 → 「끈이 풀려 흐트러짐」
v3의 넘어짐(오른쪽 바퀴를 축으로 옆 칸 쪽으로 80° 쓰러짐)은 쓰러지는 방향과 끝난 자리(제자리)가 맞지 않았다. 이제 상자 2개를 **빨간 고무끈(X자)**으로 묶어 세워 두고, 잠들면 끈이 「툭」 풀리며 **수레 칸 안에서** 흐트러진다. 시안 v3 A 카드 「흐트러지는 움직임」에서 반복 재생.
- 수레 타일이 조각 6개로 나뉜다: `frame`(틀·손잡이) · `b1`(아래 상자) · `b2`(위 상자) · `tag`(짐표) · `strap`(X자 끈) · `loose`(바닥에 풀린 끈). 바퀴·그림자는 고정.
- 흐트러진 자세 = `CART_POSE`(렌더러에서 내보냄): frame `translateY(43.5px) scaleY(.25)`(기준 0,0 — 뒤로 누워 정면에선 납작) · b1 `translate(-10px,3px) rotate(-7deg)`(기준 32,57) · b2 `translate(14px,24px) rotate(16deg)`(기준 32,33.5) · tag `translate(2px,39px) rotate(66deg)`(기준 40,4). `st: 'down'` 그림이 곧 이 자세라 움직임 끝 = 정지 그림.
- 움직임: `tile('cart', { st: 'up', anim: { 조각: CSS animation } })` — 06 참고.
- 바뀐 그림: `tile_cart_{up,down}_tag1..4`, `small/tile_cart_{up,down}_s`, `line_icon_05_cart`(+ 작은 칸). 짐수레 **승객** 그림과 다른 그림은 그대로(17,306가지 비교, 차이 0).

## v4.2 (2026-10-18) — 쩍벌 다리를 정면 V자로 · 좌석 앞턱 없앰

- **좌석 앞턱 없앰(모든 좌석)** — 승객은 완전 정면 모습이라 칸 아래쪽은 앉는 면이 아니다. 02 참고. v3·v4 시안 판도 고쳤다. 렌더러 그림은 그대로(앞턱은 앱 판에서 그리던 것).

## v4.1 (2026-10-18) — 쩍벌 승객을 두 칸 가운데로
몸이 왼쪽 칸에 있던 것을 **두 칸 가운데**로 옮기고, 다리·팔을 양옆으로 대칭으로 벌렸다. 손·신발은 두 칸 안쪽에만(이웃 칸으로 안 넘어감). 바뀐 그림: `spread_*` 16장, `line_icon_23_spread`(+ 작은 칸). 다른 그림 그대로.

## 렌더러 API 추가
| 호출 | 설명 |
|---|---|
| `P({ kind: 'V' })` | 스피커 (기본 외형 a 4) |
| `P({ kind: 'Q' })` | 쩍벌 — **128×64 그림**(두 칸). 방향 d·u만 |
| `P({ kind: 'F' })` | 치킨 (a 1) |
| `P({ kind: 'L', left })` | 스피커폰 통화 (a 5). `left` 1·2 = 머리 위 남은 박자 배지 |
| `P({ kind: 'Z' })` | 대머리 — 새 외형 `BALD`(a 무시) |
| `P({ kind: 'R', walk, step })` | 순찰 — 선 몸 + 단소 (a 3). 걷기 `walk` 0·1, 서 있음 2 |
| `P({ kind: 'U', a })` | 호통 — 새 외형 `KING[a % 2]`. 상태 `st: 'shout'` 추가 |
| `FX(type, o)` | 효과 레이어. 원점 = 빌런 칸, 이웃 칸 ±64. `music` `noteMark` `smell` `sniff` `call` `shine` `whistle` `shout` `watch` |

## 지킨 것
- 특정 영상 속 인물·게임 캐릭터 복제 없음: 왕관은 뾰족 5개짜리 일반 장난감 왕관, 갑옷은 어깨 덮개 + 가슴판뿐(투구·창·용 문양 없음). 호통 외형 2가지(짧은 머리 / 단발), 노인 얼굴 아님.
- 단소는 입에 대거나 손에 늘어뜨리기만 한다(휘두르기·겨누기 없음).
- 빌런 외형은 기존 6종과 새 인물을 섞었다: 스피커 대학생 · 쩍벌 직장인 · 치킨 학생 · 통화 아이 엄마 · 순찰 등산복 아저씨 · 대머리/호통 새 인물. 할머니·아기는 빌런으로 쓰지 않았다. `a`로 바꿀 수 있다.
- 술·흉기·폭력·이모지·실제 노선 색 없음. 「버럭!」 「!」은 Gaegu 글씨.
