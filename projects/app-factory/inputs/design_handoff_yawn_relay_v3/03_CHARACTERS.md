# 03 캐릭터 — v3.3 짐수레 끄는 택배 아저씨 (짝 표식)

v1 부품 체계(64×64 그리드) 안. 렌더러 `P({ kind: 'H', dir, st, f, tag })` + 앞 칸 `tile('cart', { st, tag })`. 외형은 등산복 아저씨(a 3).

## 한눈에
- 깨어 있음: 상자 두 개를 쌓은 손수레를 **바로 앞 칸에 세워 둔다.** 팔은 뻗지 않는다 — 평소 자세 그대로 수레를 바라본다. 키 큰 상자 탑 = 막음.
- 짝: 주인 **어깨의 동그란 표**와 수레 **손잡이의 짐표**가 같은 색. 색 4개(노랑·민트·분홍·하늘)를 판 안에서 돌려 쓴다. 기본 읽기는 「주인이 보는 바로 앞 칸」이라는 위치, 색은 수레가 여럿 붙어 있을 때 확인용.
- 잠듦: 수레가 넘어가 상자가 **바닥에 납작하게 흩어진다**(짐표도 상자에 붙은 채). 칸 아래쪽에만 남음 = 통과.
- 깸(코골이·알람): 화들짝 + 수레가 다시 선다.

## 부품
| 부품 | 어디 | 그림 |
|---|---|---|
| 어깨 표 | 승객 칸 | 끈 `M45 42 L48 46` 1.2 + 원 (48.5, 50) r4.4 짐표 색, 외곽 1.6. 앞·뒤·옆 모든 방향에서 같은 자리(어깨) — 뒷모습에서도 보임. 작은 칸 ×1.15 |
| 짐표 (서 있음) | 수레 타일 | 손잡이 (40,4)에 매달림, 14° 기울어짐: 끈 3 + 8×11 rx1.5 + 구멍 r1.1. 작은 칸 ×1.2 |
| 짐표 (넘어짐) | 수레 타일 | 넘어진 위 상자에 붙음 (22,38), −70° |
| 수레 틀 | 수레 타일 | 기둥 2개 (21,4)–(21,58), (43,4)–(43,58) 외곽 4.2 + `#9AA0AB` 2.2 · 바닥판 (17–47, 58) · 손잡이 막대 (17,1) 30×4.8 `#3A3F4A` · 바퀴 r3.8 (17,60)(47,60) + 축 r1.4 |
| 상자 2단 | 수레 타일 | 아래 (14,33) 36×24 `#C99A66` · 위 (18,14) 28×19.5 `#D9AE78` · 테이프 `#EAD6AD` · 라벨 (18,45) 9×6 `#F6F1E4`(글자 없음) |
| 넘어진 수레 | 수레 타일 | 틀이 바닥에 누움 (4–52, 57) + 바퀴 하나 (56,55) · 상자 2개 −6° / +8°, 칸 아래쪽 y 41–58에만 · 먼지 선 2 · 그림자 rx26 |
- 수레 타일은 **방향과 상관없이 같은 그림**(상자는 늘 똑바로 섬). 주인이 어느 쪽에 있든 그대로 쓴다.
- 짐표 색: `TAG_COLORS = ['#FFCF5A', '#7FD1C0', '#F2A7C3', '#9FC0FF']`, `tag`는 번호(0–3) 또는 hex. 생성기가 판의 짐수레 승객에게 0, 1, 2, 3, 0 … 순서로 준다.
