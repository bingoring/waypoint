# 02 컴포넌트 — v3 추가분

## 수레 막힘 끝 표시
- 수레 칸에 닿은 시선선은 **수레 칸 가운데에서 0.62칸 앞**(칸 경계 바로 앞)에서 끝나고, 끝에 진행 방향과 수직인 짧은 가로막대: 길이 12dp(큰 판 10dp) · 2.4dp · `#E9E6DD`. 기둥 세 번째 막힘과 같은 모양.
- 끝 점(동그라미) 없음 — 막대가 곧 끝.
- 옆으로 지나가던 시선도 같다(수레 칸은 방향 상관없이 막음). 기둥에서 갈라진 선이 수레에 닿아도 같다.
- 수레가 넘어가면(주인 잠듦) 막대가 사라지고 선이 수레 칸을 그대로 지나간다(넘어진 상자는 칸 아래쪽 1/3에만 있어 선과 겹치지 않음).
- 짐수레 승객 자신에게서는 시선선이 나오지 않는다(휴대폰·커피와 같은 목록).

## 크기 단계 (lod)
| 단계 | 칸 | 렌더러 |
|---|---|---|
| 기본 | 64–72dp | `lod` 없음 — v2.2와 같은 그림 |
| 작은 칸 `'s'` | 44–56dp | 아래 표 |

| 작은 칸에서 | 무엇 |
|---|---|
| 굵게 | 모든 외곽선·선 ×1.3 (`LW`) |
| 키움 | 깨어 있는 눈 2.2×2.7 → 2.6×3.2 · 말똥말똥/두리번 배지 ×1.3 · 숫자 배지(출입문·알람·터널) ×1.3 · 브로치 2.2 → 2.8 · 짐수레 어깨 표 ×1.15 · 수레 짐표 ×1.2 |
| 하나로 | 잠든 z 두 개 → 큰 z 하나(18) |
| 뺌 | 커피 김 · 이어폰 음표 · 브로치 여밈선 · 후드끈 · 기둥 반짝임 · 수레 바퀴 축 · 상자 라벨 · 넘어질 때 먼지 선 |
| 그대로 | 실루엣을 만드는 소품 — 휴대폰, 컵, 헤드폰, 안경, 마스크, 수레·상자, 모자, 손잡이, 아기 |
판 그리기는 칸 56 이하이면 자동으로 `'s'`.

## 좌석 (작은 칸)
- 칸 < 56: 좌석 안쪽 여백 5 → 3, 모서리 12 → 9, 앞턱 8 → 6.
- 짐수레 승객 칸에도 앞턱을 그린다(v3.3부터 팔을 뻗지 않음).

## 시선선 — 큰 판(30–45명)
| | v2 | v3 큰 판 (`dense`) |
|---|---|---|
| 평소 | 1.6dp · 34% 점선 1.5-5 | **1.3dp · 30%** 점선 1.5-4.5 |
| 교차 | — | 선마다 아래에 **어두운 테두리** `#20242E` 4dp · 90%. 나중에 그린 선의 테두리가 먼저 그린 선을 끊어, 교차점에서 어느 선이 이어지는지 보인다 |
| 끝 점 | r2.2 | r1.7 |
| 빛남(전파) | 3dp 노랑 | 2.6dp 노랑 + glow (테두리 없음) |
| 같은 칸 쌍 비켜 그리기 | 3dp | 2.4dp |
판이 5×6보다 크면 `dense`.

## 누른 칸 강조 (제안 — 44dp 탭 실수 줄이기)
손가락이 칸에 닿아 있는 동안(떼기 전):
- 누른 칸: 노란 테두리 2.5dp `#FFCF5A` + 채움 14%, 모서리 = 좌석 모서리 + 2.
- 그 사람이 **보는 선**과 그 사람을 **보는 선**만 흰 실선 2.2dp. 나머지 선은 12%로 흐림.
- 보는 대상 칸: 흰 점선 테두리 1.5dp(70%).
- 손을 떼면 툭. 누른 칸 밖으로 밀어서 떼면 취소(강조만 사라짐).
