## 이번에 고친 것 (오너 확인 2026-10-19)
- 개통만으로는 앞 노선이 늘지 않는다 — 5호선은 환승역에서 끝나고 6호선만 생긴다(시안 A 예시 수정). 앞 노선 줄은 그 노선을 골라 더 탈 때만 는다(C).
- 다음 노선·순환선으로 가는 연결선을 줄 꺾임과 같은 둥근 모서리로(곧게 떨어뜨리지 않음). 고리를 넓혀 양 끝 x 34 / 346 = 줄 꺾임 x.
- 미리 보기 판 칸 = min(40, ⌊(폭 − 40) ÷ 열⌋, ⌊330 ÷ 행⌋): 5×7 → 40, 7×11 → 30.

## 결정이 필요한 것
1. 모서리 A2 둥근(추천) / A1 직각.
2. 미리 보기 판 그림: 모두 잠든 마지막 모습(추천) / 처음 모습.
3. 접기를 2줄씩(보이는 줄 3~4) — 첫 보이는 줄이 연결선 쪽에서 시작하도록. 1줄씩 접으면 접힐 때마다 아래 줄 방향이 모두 뒤집힌다.
4. 섞기 장 머리를 고리 안에 둠.
