- **런 시드·하위 스트림 RNG:** `map`, `loot`, `combat`, `event`.

## 1. 사다리 원정 (사다리타기 로그라이크)

### 1.1 핵심 루프
층마다 세로줄 N개(초안 4~6)짜리 사다리가 있다. 위에는 내 일행(초안 3명), 아래에는 결과 칸(전투, 상자, 회복, 상점, 정예, 함정)이 있다.
플레이어는 손패의 **가로줄 카드**를 사다리에 놓은 뒤 「출발」을 누른다. 일행이 동시에 내려가며 각자 도착한 칸을 처리한다. 줄 하나가 모든 경로를 바꾸므로 **세 명을 동시에 원하는 칸으로 보내는 퍼즐**이 된다.

### 1.2 레벨(층) 디자인
- **층 구성:** 기존 가로줄(고정) + 내가 놓는 가로줄 + 결과 칸 배치.
- **풀이 보장:** 층 생성 직후 풀이기가 「손패로 도달 가능한 결과 배정」을 전수 계산한다. 최소 하나는 「나쁘지 않은 결과」(전멸 칸 회피)가 가능해야 한다. 사다리는 순열이라(가로줄 = 인접 원소 교환) 상태 공간이 작아 전수 탐색이 가능하다 [추정].
- **난이도 축:** 세로줄 수, 기존 가로줄 밀도, 결과 칸 중 위험 칸 비율, 손패 크기, 특수 가로줄 등장.
- **곡선:** 막(Act) 3개 × 층 8~10 + 보스. 막마다 새 규칙 하나(예: 2막 = 끊어진 줄, 3막 = 움직이는 결과 칸). 롤러코스터 곡선(쉬운 층 사이에 어려운 층).
- **레벨 지표 (시뮬레이션):** 층별 「최선 결과 기대값」과 「무작위 배치 기대값」의 차이 = 퍼즐 기여도. 차이가 작은 층은 운 게임이므로 버린다.

### 1.3 맵(런) 생성 알고리즘
- **노드 맵:** 층 위에 막 단위 갈래 지도(Slay the Spire식 층 DAG). 층마다 다음 노드 2~3개 중 선택한다.
- **생성 절차 (초안):**
  1. 막당 7행 × 열 4~5 격자에서 시작점 여러 개부터 위로 경로를 무작위로 낸다(경로 교차 금지).
  2. 노드 종류를 규칙으로 배정한다: 첫 행은 전투만, 보스 직전은 휴식, 정예는 4행 이후, 상점은 연속 금지, 같은 종류 연속 3회 금지.
  3. 막마다 종류별 개수 범위를 검사하고, 어기면 다시 생성한다.
- **검증:** 생성기 속성 테스트 1만 회 — 모든 경로에서 보스 도달 가능, 경로마다 회복 기회 ≥ 1, 종류 분포가 목표 범위 안.

### 1.4 아이템 (가로줄 카드 + 유물)
- **가로줄 카드 (덱):**

  | 카드 | 효과 |
  |---|---|
  | 기본 줄 | 인접 두 줄을 연결 |
  | 긴 줄 | 한 칸 건너뛰어 연결 |
  | 금빛 줄 | 이 줄을 지난 동료의 보상 2배 |
  | 일방통행 줄 | 한 방향으로만 건넘 |
  | 지우개 | 기존 줄 하나 제거 |
  | 순간이동 줄 | 다른 높이로 이동 |
  | 덫 줄 | 적 전용 경로 변경 |

  덱 빌딩: 층 보상으로 카드를 추가·강화·삭제한다.
- **유물 (패시브):** 「첫 가로줄은 무료」, 「상자 칸에 도착한 동료 회복」, 「같은 칸에 둘이 도착하면 협공」 등. **시너지 태그**(금·길·덫·회복)를 붙여 빌드 방향을 만든다.
- **희귀도·풀:** 일반/희귀/전설 가중치, 막이 오를수록 희귀 확률 상승. 같은 유물 중복 금지. 천장: 희귀 이상이 N회 연속 안 나오면 보장.
- **채택률 지표:** 제시 대비 선택 비율. 너무 높으면 너프, 너무 낮으면 버프 또는 재설계.

### 1.5 일행·몬스터
- **일행:** 3명, 직업(검사·궁수·사제 등), 직업마다 결과 칸 처리 방식이 다르다(사제가 상자에 도착하면 축복 등). 동료가 쓰러지면 그 줄은 빈 줄이 된다 → 난이도 자동 상승.
- **몬스터:** 결과 칸의 전투는 **자동 전투 + 의도 표시**로 짧게(5초 이내). 적은 다음 층 행동(돌진: 같은 줄 아래로 내려옴, 저주: 가로줄 하나 봉인)을 예고해, 퍼즐 단계에서 피하거나 맞설 계획을 세우게 한다.
- **원형(archetype):** 탱커, 돌격, 소환, 방해(사다리 조작), 도둑(카드 훔침). 막마다 원형 조합을 바꾼다.
- **정예·보스:** 사다리 규칙 자체를 비튼다(보스가 매 턴 가로줄 2개를 무작위로 추가하는 등). 보스는 막마다 2종 중 무작위.
- **수치 곡선:** 적 체력·공격력 = 기본 × (1 + 층 계수) — 시뮬레이션으로 보정.

### 1.6 메타 진행
- 직업·카드·유물 해금(런 결과 경험치), 난이도 단계(승천식 단계마다 규칙 하나씩 불리하게), **일일 사다리**(같은 시드, 점수 공유).

### 1.7 위험
- 사다리 경로를 눈으로 따라가는 피로 → 놓기 전에 **경로 미리보기**(줄을 끌면 세 경로가 실시간으로 갱신)가 필수다. 프로토타입 1순위 확인 항목.
- 화면 크기: 세로줄 6개가 휴대폰 폭의 한계다 [추정].

## 2. 딱지왕 (딱지치기 로그라이크)

### 2.1 핵심 루프
동네 지도를 따라 아이들과 딱지 대결을 하며 골목 대장 → 학교 → 문방구 사장님(보스)까지 올라간다. 대결은 턴제다. 내 차례에 **스와이프 한 번**(내려치는 위치·세기·각도)으로 상대 딱지를 뒤집거나 선 밖으로 밀어내면 그 딱지를 딴다.

### 2.2 물리·판정 모델 (가장 큰 기술 위험)
- **완전한 3D 강체 물리는 쓰지 않는다**(1-3 A6 순수 Flutter, 리서치 §5 「강체 물리 핵심은 피함」).
- 대신 **반해석적 모델**(초안):
  1. 입력: 타격 지점(상대 딱지 가장자리와의 거리), 세기(스와이프 속도), 각도.
  2. 딱지 속성: 무게, 크기, 휨(접힘 상태), 바닥 마찰.
  3. 계산: 가장자리 아래로 들어가는 공기 압력 근사 → 회전 토크 → 뒤집힘 여부와 밀려난 거리.
  4. 결과에 소량의 결정적 잡음(시드)을 섞는다.
- **연출:** 2D 의사 3D(스케일·기울기 트윈, 그림자). 결과를 먼저 계산하고 연출이 따라간다(판정과 연출 분리).
- **검증:** 입력 공간 격자 스캔으로 「뒤집힘 확률 지도」를 그린다. 숙련 입력이 운보다 확실히 유리한지(기술 표현력)와, 무게·크기 업그레이드가 체감되는지 측정한다.

### 2.3 맵 생성
- 사다리 원정과 같은 노드 맵 생성기(§1.3)를 동네 테마로 쓴다.
- 노드 종류: 대결, 연습, 문방구(상점), 딱지 접기(제작), 비밀 장소(이벤트), 대장(정예), 보스.
- **이벤트:** 짧은 선택지 이야기(비 오는 날 = 젖은 딱지는 무겁지만 약함 등). 데이터 주도로 수십 개를 순환한다.

### 2.4 아이템
- **재료 → 딱지 제작:** 신문지(가벼움·흔함), 우유곽(무거움·코팅), 달력(크고 튼튼), 두꺼운 종이, 은박지(희귀) 등. 두 장을 골라 접으면 속성이 합성된다. 접는 방식(기본, 이중, 각진)이 추가 보정을 준다.
- **스티커 (유물):** 「첫 공격 세기 +」, 「뒤집히면 한 번 버팀」, 「비 오는 날 강화」 등. 시너지 태그(무게·속도·내구·운).
- **소모품:** 침 바르기(1회 무게 증가), 고무줄(밀려남 방지) — 대결당 사용 제한.
- **내 딱지 덱:** 여러 장을 들고 다니며 대결마다 출전 순서를 정한다. 잃은 딱지는 그 런에서 사라진다(로그라이크 긴장감).

### 2.5 상대(몬스터) 설계
- **AI 성향:** 힘센 형(세기 높음·정확도 낮음), 정밀형, 무거운 딱지 수집가, 반칙꾼(선을 몰래 옮김 → 이벤트성).
- **AI 구현:** 같은 판정 모델로 후보 입력 K개를 평가하고, 성향별 오차를 더해 고른다. 난이도는 K와 오차 크기로 조절한다.
- **대장·보스:** 고유 규칙(보스 딱지는 두 번 뒤집어야 짐, 바람 부는 골목 등).

### 2.6 메타 진행
- 딱지 도감(재료·접기 조합 수집), 해금 재료, 일일 동네(같은 시드), 난이도 단계.

### 2.7 위험
- **손맛이 전부다.** 프로토타입에서 「내려치는 감각」(햅틱, 소리, 화면 흔들림)과 판정 모델을 먼저 검증한다.
- 오징어 게임 연상: 그 작품의 이미지(정장 남성, 붉은·푸른 딱지 구도)와 문구를 쓰지 않는다. 딱지는 전통 놀이이므로 일반 모티프는 사용 가능하다 [추정, 출시 전 확인].

## 3. Build Spec에서 반드시 채울 항목 (체크리스트)

- [ ] 결정적 RNG 하위 스트림 설계와 저장 포맷(시드 + 결정 로그)
- [ ] 콘텐츠 JSON 스키마(카드·유물·적·이벤트·층 규칙)와 원격 설정 덮어쓰기 규칙
- [ ] 맵 생성기 제약 목록과 속성 테스트(1만 회)
- [ ] 층·대결 생성기 + 풀이기/판정 스캔 — 풀이 보장 또는 기술 표현력 증명
- [ ] 아이템 희귀도 가중치, 천장, 시너지 태그, 채택률 목표 범위
- [ ] 적 원형·의도 표시·수치 곡선과 보스 고유 규칙
- [ ] 시뮬레이션 봇 정책(무작위·탐욕·탐색) 3종과 목표 지표: 1막 승률, 전체 승률, 평균 런 길이, 사망 원인 분포
- [ ] 메타 진행(해금, 난이도 단계, 일일 시드)
- [ ] 광고 지점(부활, 보상 선택지 추가)과 런당 한도
- [ ] 아트 목록(이모지 금지): 캐릭터·적·아이템 아이콘·맵 타일·효과
