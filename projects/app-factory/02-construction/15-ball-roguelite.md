## 1. 웹 프로토타입 1차 (2026-10-21, 메인 `67edc55`)

`prototypes/ball-roguelite/index.html` — 버려도 되는 실험. 그림은 코드로 그린 임시 픽셀.

| 항목 | 내용 |
|---|---|
| 화면 | 세로 180×320 논리 픽셀(픽셀 아트 기준), 위 적 구역 · 가운데 판 · 아래 플리퍼 |
| 한 발 | 판을 눌러 끌면 조준선(첫 튕김까지, 같은 물리로 미리 계산) → 떼면 발사 → 구슬이 도는 동안 화면 왼쪽/오른쪽을 누르면 그쪽 플리퍼(구슬마다 3회) |
| 페그 | 일반 · 크리티컬(이번 발 피해를 크리 수치로, 2개) · 리프레시(맞히면 사라진 페그 부활, 1개) · 폭탄(두 번 맞히면 적 모두 25, 2개). 크리·리프레시 위치는 쏠 때마다 다시 뽑음 |
| 피해 | 맞힌 페그 수 × 구슬 피해. 구슬이 빠지면 맨 앞 적에게. **플리퍼로 다시 띄울 때마다 배수 +0.5**(살린 뒤 맞힌 페그부터) |
| 적 | 공격까지 남은 턴을 점으로 표시, 0이 되면 공격 |
| 런 | 4전투(숲 1~3 + 보스), 승리마다 구슬 2 + 유물 1 중 하나. 구슬 6종(돌·단검·쇳덩이·고무공·쌍둥이·불씨), 유물 7종 |
| 결정성 | 고정 간격 1/240초 + 시드 난수(판·크리 위치·보상), 플리퍼 입력은 단계 번호로 기록 → `selfTest()`: 같은 입력이면 같은 결과, 각도 0.0001 차이면 다른 결과 |

### 봇 시험 (조준은 각도를 훑어 가장 많이 맞히는 방향, 「사람」은 ±0.15rad 오차)

| 봇 | 런 클리어 | 평균 피해 |
|---|---|---|
| 완벽 조준, 플리퍼 없음 | 4/4 | 68~88 |
| 완벽 조준, 플리퍼 | 4/4 | 91~115 |
| 사람 조준, 플리퍼 없음 | **0/4** (3번째 전투·보스에서 사망) | 20~33 |
| 사람 조준, 플리퍼 | **4/4** (남은 체력 2~42, 런마다 23~29번 살림) | 53~77 |

- 1차에서는 플리퍼가 쓸모없었다(살려도 이번 발에 이미 맞힌 페그만 다시 맞아 페그 0~3개 증가). 「살릴 때마다 배수」를 넣어 플리퍼가 실력 축이 됐다.
- 남은 문제: 첫 전투를 한두 발에 끝냄(판이 가득 찬 첫 발이 가장 셈), 봇의 플리퍼 타이밍은 완벽해서 사람은 더 어려울 수 있음 → 오너 플레이로 확인.

## 2. PixelLab 시험 (2026-10-21)

| 시험 | 결과 | 비용 |
|---|---|---|
| `create_character`로 슬라임 (32px, 옆모습) | **실패** — 사람형 골격 템플릿이라 팔다리 달린 초록 인형이 나옴 | 1회 |
| `create_image_pixflux`로 슬라임 한 장 (48×48, 투명 배경, 왼쪽 향함, 검은 외곽선) | 성공 — 둥근 젤리 몸·큰 눈 | 1회 |
| `animate_image_pixminimax`로 대기 4프레임 | 성공 — 말랑하게 눌렸다 늘어남, 프로토타입 적 구역(높이 78)에 48×48이 잘 맞음 | 1회 |

- **제작 규칙:** 사람형 주인공·인간형 적 = `create_character`(방향 + 템플릿 애니메이션) / 사람형이 아닌 몬스터 = 그림 한 장(`create_image_pixflux`) → 움직임(`animate_image_pixminimax`, 대기 4·공격 8프레임). 몬스터 하나에 2~3회.
- 체험판 잔여: 생성 40회 중 3회 사용(하루 보너스 +5). 몬스터 10~20종이면 30~60회 — 유료 플랜 필요.
- 에셋 위치: `prototypes/ball-roguelite/assets/`(가로 스프라이트 시트).

## 3. 웹 프로토타입 2차 (2026-10-21, 메인 `532af53`) — 오너 피드백 반영

오너 피드백: 플리퍼 배수는 좋다. 페그가 너무 적고, 후반에 독특한 기믹이 필요하다. 맞힌 페그가 그대로 남아 있어 플리퍼로 쳐 올려도 높이 못 올라간다 → 즉시 없애자(Peglin은 어떻게?).

| 변경 | 내용 |
|---|---|
| **맞힌 페그 즉시 제거** | Peglin 방식(맞힌 페그는 사라지고 리프레시로 부활). 1차는 Peggle 방식(불만 켜졌다가 발이 끝나면 제거)이었다. 폭탄은 두 번째에 그 자리에서 터지고, 갑옷 페그는 한 번 막은 뒤 두 번째에 깨진다. 판에 12개 미만이 남으면 다음 발 전에 다시 돋는다 |
| 판 밀도 | 무늬 4종(촘촘한 격자·고리·물결·뭉치), 간격 9 → 8. 판마다 102~228개(1차 44~77) |
| **지역별 핀볼 장치** | 숲: 멀티볼 구멍(들어가면 다음 발에 구슬 +1, 최대 3) / 동굴: 범퍼(세게 튕기며 맞을 때마다 피해, 한 발 최대 15)·스피너(지나가는 속도만큼 돌며 피해, 단가 절반) / 보스: 좌우로 움직이는 페그 줄·갑옷 페그·범퍼 |
| **시너지 유물 5종** | 불꽃 심지(한 발에 세 번 살리면 페그를 튕기지 않고 뚫음) · 갈라지는 별(살릴 때마다 분열, 최대 4) · 기억하는 종(배수 보너스 절반이 다음 발로) · 씨앗 주머니(살릴 때마다 위쪽에 새 페그) · 자석 반지(가까운 크리티컬 쪽으로 끌림). 보상 = 구슬 1 + 시너지 유물 1 + 유물 1 |
| 런 | 5전투(숲 2·동굴 2·보스), 지역이 바뀌면 보상 화면에 새 장치 예고 |

봇(사람 수준 조준 ±0.15rad, 시드 3): 플리퍼 없음 0/3(모두 보스에서 짐) · 플리퍼 1/3 · 플리퍼 + 시너지 유물 2/3. 결정성 시험(일반·동굴 + 시너지·보스 + 불꽃) 통과.
