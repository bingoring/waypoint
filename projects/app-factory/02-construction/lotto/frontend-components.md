# Frontend Components — 로또 (APP_DESIGN_PROMPT v1 첫 적용)

> [`../../APP_DESIGN_PROMPT.md`](../../APP_DESIGN_PROMPT.md)의 1~4단계를 따라 썼다. 1단계 조사 근거는 §1, 출처는 §8.

## 1. 실제 사용 맥락과 정체성 (프롬프트 1단계)

| 확인한 것 | 내용 | 확인 수준 |
|---|---|---|
| 여는 순간 | 금요일 오후~토요일 오전 판매점이 가장 붐빈다. 번호를 미리 만들어 저장해 두고 산다. 주말마다 연다 | 2차(기사·스토어 후기) |
| 마감·추첨 | 판매 마감 토 20:00(인터넷 기준), 추첨 토 20:35경 | 공식 |
| 용지 | 1장 최대 5게임, 1게임 1,000원 | 공식 |
| 낮은 별점 이유 | ① 오류·무한 로딩 ② 번호가 안 맞는다는 실망 ③ **번호 색 변경 뒤 눈 피로·가독성** ④ 광고 과다·깜박임 ⑤ 회차 데이터 갱신 지연 | 2차(후기 약 200건 분류) |
| 높은 별점 이유 | 쉽고 편함, 통계·옵션, 깔끔한 디자인 | 2차 |
| 상징 | **5구간 색 공**(가장 강함, 모든 경쟁 앱 공통), 추첨기 안에서 도는 45개 공, 5게임 용지 | 공식(웹 CSS 구간)·2차 |
| 정책 | 공식 기관 사칭 금지(로고·명칭·공식 표장), 확률 보장 주장 금지 | 공식(Play 정책) |

**이 앱의 상징 셋:** ① 5구간 색 공 ② 공이 하나씩 굴러 나오는 추첨 ③ 5게임 한 장(A~E 줄).
**공 색은 자체 정의한다.** 동행복권 웹 색값을 복사하지 않고 같은 다섯 색 계열(노랑·파랑·빨강·회색·초록)에서 숫자 대비를 검증해 고른다. 색은 한 번 정하면 바꾸지 않는다(③ 불만).

## 2. 한 줄 이야기와 흐름 (프롬프트 2단계)

**이야기:** "토요일 마감 전에, 추첨기에서 공이 굴러 나오듯 내 번호 한 장을 받아 두고, 일요일 아침에 맞춰 본다."

| 순간 | 화면 | 누름 수 |
|---|---|---|
| 번호 받기 | 앱 열기 → 「번호 뽑기」 | **1번** |
| 저장 | 결과 아래 「이 번호 담기」 | 2번 |
| 맞춰 보기 | 하단 「내 번호」 탭 → 회차 카드에 등수 | 1~2번 |
| 통계 | 하단 「통계」 탭 → 광고 보고 열기 → 「통계로 뽑기」 | 3번 |

화면은 3개(뽑기·내 번호·통계) + 설정. 화면마다 하나의 일만 한다. 첫 실행 소개 슬라이드·스플래시 로고 카드는 없다.

## 3. 화면별 지시 (프롬프트 3단계 형식)

### 3.1 뽑기 (홈)
「주인공은 **5게임 용지 한 장 위의 색 공**, 이 화면에서 끝나는 일은 이번 회차 번호 받기야. 첫눈에 보이는 것은 용지 카드(A~E 줄, 기본 5줄 중 선택한 수만 채워짐), 그다음은 상단의
**마감 띠**(「1246회 · 마감까지 1일 3시간」, 토 20:00 지나면 「1247회 · 다음 주 토 20:00 마감」)야. 대표 버튼은 화면 아래 엄지 자리의 큰 「번호 뽑기」이고, 누르면 용지의
줄마다 공 6개가 왼쪽 위 추첨구에서 하나씩 굴러 나와 오름차순 자리에 멈춰(공당 60ms 간격, 줄당 약 400ms). 이미 결과가 있으면 같은 버튼 이름이 「다시 뽑기」로 바뀌어.
손이 대상에 직접 닿는 조작은 ① 용지 줄 수 바꾸기: 용지 맨 아래 빈 줄(「+ 게임 추가」)을 탭하면 줄이 늘고(최대 5), 줄을 옆으로 밀면 지워져(최소 1). 별도의 숫자 입력이나 단계 버튼은 없어. ② 번호 지정: 용지 위 「번호 지정」
칩을 누르면 45개 공 판이 아래에서 올라오고, 공을 한 번 누르면 고정(공에 굵은 테두리·핀 모양), 두 번 누르면 제외(공이 흐려지고 사선), 세 번 누르면 원래대로야. 판 위에
「고정 2 · 제외 5」가 바로 바뀌어. ③ 결과 줄을 길게 누르면 그 줄만 복사.
빈 상태는 처음 연 사람에게 용지 5줄이 빈 공 자리(회색 테두리 원)로 보이고, 「번호 뽑기」 하나만 강조돼. 상징 색은 공에만 쓰고, 글자는 회차·남은 시간·버튼 이름만 보여.
광고는 맨 아래 배너(`banner_home`)이고 「번호 뽑기」와 8dp 이상 떨어져. 「다시 뽑기」 세 번마다, 새 결과가 나오기 전에 전면 광고(`interstitial_generate`)가 한 번 와.
화면에 보이는 마감 시각은 동행복권 공식 안내(토 20:00)와 같아.」

- 결과가 생기면 용지 아래에 보조 버튼 둘: 「이 번호 담기」(채워진 버튼), 「복사」(아이콘). 담으면 용지 카드가 작아지며 하단 「내 번호」 탭 아이콘으로 날아가고 탭 배지 숫자가 1 오른다.
- 용지 맨 위에 마지막 추첨 결과 한 줄(작은 공 7개, 「1245회 당첨번호」). 탭하면 「내 번호」로 가서 그 회차를 연다.

### 3.2 내 번호
「주인공은 **회차별로 묶인 내 용지들과 그 회차 당첨 공**, 이 화면에서 끝나는 일은 맞춰 보기야. 첫눈에 보이는 것은 가장 최근 회차 카드: 위에 그 회차 당첨 공 6개+보너스, 아래에
내 줄들이고, 내 줄에서 **맞은 공만 원래 색으로 채워지고 나머지는 테두리만** 남아. 줄 오른쪽 끝에 등수 배지(「5등」 글자 + 색). 추첨 전 회차는 당첨 공 자리가 비어 있고
「토 20:35 추첨」이라고만 써. 대표 행동은 화면을 여는 것 자체라 별도 버튼이 없어. 카드를 왼쪽으로 밀면 삭제(되돌리기 스낵바). 빈 상태는 「아직 담은 번호가 없어요」와
「번호 뽑으러 가기」 버튼 하나야. 광고는 맨 아래 배너(`banner_history`). 화면 맨 아래 회색 한 줄 「당첨 데이터: 1245회까지」로 데이터가 언제까지인지 보여.」

### 3.3 통계
「주인공은 **45개 공이 출현 횟수만큼 쌓인 막대**, 이 화면에서 끝나는 일은 과거 흐름을 보고 그 흐름으로 뽑기야. 잠긴 상태에서는 막대가 흐린 실루엣으로 보이고 그 위에
「광고 보고 오늘 통계 열기」 버튼(재생 아이콘 + 「오늘 자정까지」 작은 글자)이 있어. 광고 제거 구매자는 처음부터 열려 있어. 누르면 광고 뒤 실루엣이 왼쪽부터 실제 막대로
차오르며(300ms) 열려. 열린 상태의 첫눈은 「최근 100회」 막대(공 번호 순, 막대 위 공 색 점), 그다음은 「많이 나온 공 6」·「적게 나온 공 6」 두 줄이야. 대표 버튼은 아래쪽
「통계로 뽑기」이고 누르면 뽑기 화면으로 가서 용지에 공이 굴러 나와(출처 표시 「통계」 칩). 고지 「과거 출현 빈도일 뿐, 당첨 확률을 높이지 않아요」는 막대 바로 아래 한 줄로 항상
보여. 데이터가 없으면(첫 실행에 에셋도 없을 수 없지만 방어) 「당첨 데이터를 불러오지 못했어요」.」

### 3.4 설정
2-1 부품 순서: 광고 제거 · 구매 복원 · 개인정보 옵션 · 문의 · 버전. 앱 고유 행: 「당첨 데이터: 1245회까지」, 하단 안내 두 줄 「이 앱은 동행복권과 관련이 없어요」·「복권은 만 19세 이상만
살 수 있어요」. 앱 바 오른쪽 위 톱니 아이콘으로 들어간다(탭 아님).

## 4. 움직임 표

| 순간 | 움직임 | 처음 → 끝에 드러나는 것 | 길이 |
|---|---|---|---|
| 번호 뽑기 | 공이 추첨구에서 굴러 나와 자리에 멈춤 | 빈 자리 → 색 공 6개 정렬 | 줄당 ~400ms |
| 담기 | 용지 카드 축소 → 「내 번호」 탭으로 날아감, 배지 +1 | 결과 → 보관된 위치 | 350ms |
| 번호 지정 | 판이 아래서 올라옴, 공 상태 즉시 전환 | 용지 → 45개 판 | 250ms |
| 통계 열기 | 실루엣이 왼쪽부터 막대로 차오름 | 잠김 → 실제 분포 | 300ms |
| 맞춰 보기 | 맞은 공이 테두리에서 색으로 채워짐(화면 진입 시 1회) | 내 번호 → 맞은 개수 | 250ms |

「애니메이션 줄이기」 켜짐: 모든 움직임을 즉시 결과로 바꾼다. 반복·장식 애니메이션 없음.

## 5. 시각 규칙 (프롬프트 3단계)

- **공 위젯 `LottoBall`**: 원형, 구간 색 면 + 숫자. 숫자 색은 구간마다 대비 3:1 이상(큰 굵은 글자 기준)이 되도록 흰색/짙은 색 중 고른다(노랑 구간은 짙은 글자). 고정 = 굵은 바깥 링,
  제외 = 40% 투명 + 사선, 빈 자리 = 회색 테두리 원. 크기 3단계(용지 40dp · 당첨 줄 28dp · 판 44dp, 판은 터치 48dp 확보).
- **공 색(자체 정의, 구현 시 대비 테스트로 확정)**: 1~10 노랑 계열, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록.
- **테마**: `app.yaml design` — 시드 색은 공 다섯 색과 겹치지 않는 중성 계열(짙은 남색 계열 제안)로 해 공이 화면에서 가장 화려하게 한다. 모서리 16, 밀도 comfortable, 아이콘 rounded.
- 숫자는 고정폭 숫자. 글자 3단계: 공 숫자·회차(결과), 카드 제목, 본문.
- 그림자: 대표 버튼과 바텀 시트만. 용지·회차 카드는 면 색 구분.
- 색만으로 뜻 전달 금지: 등수 배지는 글자, 고정·제외는 모양(링·사선)으로도 구분.

**검사 중 고친 것:** 통계 화면 대표 버튼이 화면 가운데(엄지 밖)에 있었고 잠긴 상태의 아래 절반이 비어 있었다 → 버튼을 하단 고정, 잠긴 상태에 「많이·적게 나온 공」 빈 자리와 자물쇠를 보여 줌(05 화면).
**아직 기기에서 못 본 것:** 당첨 확인의 「맞은 공만 채워짐」·등수 배지 — 저장한 회차(1246회)가 아직 추첨 전이라 화면으로는 다음 주에 확인한다(위젯 테스트·도메인 테스트로는 검증).
