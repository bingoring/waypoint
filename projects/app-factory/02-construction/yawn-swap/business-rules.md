# Business Rules — Yawn! 자리 교환 방식

> 규칙 id 접두어 `SW-`. 기존 시선·박자 규칙(Y-SIGHT·Y-BEAT·Y2-ENG)은 그대로 유효하고, 여기서는 교환 방식이 더하거나 바꾸는 것만 적는다.

## 1. 규칙 표

### 옮기기

| id | 규칙 | SoT |
|---|---|---|
| SW-MOVE-1 | 승객 하나를 끌어 다른 칸에 놓으면, 그 칸이 빈자리면 옮기고 다른 승객이 있으면 **맞바꾼다**. | `swapMove` |
| SW-MOVE-2 | 고정 승객(자물쇠)은 끌 수 없고, 고정 승객이 앉은 칸에 놓을 수도 없다. 힌트로 고정된 승객도 같다. | `swapMove` 283·285 |
| SW-MOVE-3 | 고정 칸(짐 상자·창문·기둥·짐수레)과 판 밖에는 놓을 수 없다. 놓을 수 없는 곳에서 손을 떼면 원래 자리로 돌아가고 옮김 수는 늘지 않는다. | `swapMove` 283, `pointerup` 447 |
| SW-MOVE-4 | 제자리에 놓으면 아무 일도 없다(옮김 수 그대로). | `pointerup` 446 |
| SW-MOVE-5 | 승객은 **바라보는 방향을 지닌 채** 옮긴다. 방향을 돌리는 조작은 없다. | `b.people[i].dir` |
| SW-MOVE-6 | 옮김 횟수 제한은 없다. 옮김 수·되돌리기·시간은 측정만 한다. | DECISIONS 2026-10-21 「옮김 제한 없음」 |
| SW-MOVE-7 | 되돌리기는 바로 앞 배치로 돌아가고 **옮김 수를 1 늘린다**(되돌리기로 옮김 수를 줄일 수 없다). | `undo` 464 |
| SW-MOVE-8 | 「처음 배치」는 섞인 배치로 돌아가고 되돌리기 기록을 지운다. 옮김 수는 그대로. 힌트로 고정된 승객은 정답 자리에 그대로 둔다. | `reset` 465 |

### 연쇄와 클리어

| id | 규칙 | SoT |
|---|---|---|
| SW-CHAIN-1 | 시작 자리에 앉은 승객이 0박자에 하품한다. 시작 자리가 비어 있으면 아무도 하품하지 않는다(연결 0). | `run` 160~161 |
| SW-CHAIN-2 | 깨어 있는 승객은, 시선 갈래(창문에서 꺾이고 기둥에서 갈린 것 포함) 중 하나라도 처음 만나는 사람이 **이번 박자에 하품한 사람**이면 다음 박자에 하품하고 바로 잠든다. | `run` 170, 엔진 `need = 1` |
| SW-CHAIN-3 | 짐수레는 주인이 **이전 박자까지** 잠들었으면 넘어져 시선이 지나가고, 아니면 시선을 막는다. | `run` 169 |
| SW-CHAIN-4 | 잠든 사람도 시선을 막는다(처음 만난 사람만 본다). | `rays` 150 |
| SW-CHAIN-5 | 배치가 바뀔 때마다(끄는 중에는 손가락 아래 칸이 바뀔 때마다 「지금 놓으면」 기준으로) 연쇄를 다시 계산해 **연결 수**와 **하품이 닿은 좌석**, **하품을 옮긴 시선 갈래**를 보인다. | `draw` 323~378, DECISIONS 2026-10-27 |
| SW-CHAIN-6 | 옮긴 뒤 모든 승객이 이어지면 **출발 없이** 바로 하품 연쇄를 재생하고 클리어한다. 재생 중에는 끌 수 없다. | `pointerup` 450 |
| SW-CHAIN-7 | 클리어에 실패는 없다. 역을 나가지 않는 한 결국 깬다. | 교환 방식 |

### 판 생성

| id | 규칙 | SoT |
|---|---|---|
| SW-GEN-1 | 판은 정답부터 만든다: 시작 자리에서 뻗는 무작위 나무, 자식은 부모를 바라본다(바로 옆 / 창문을 거쳐 / 기둥 갈래로 / 짐수레 너머). | `makePuzzle` 191~227 |
| SW-GEN-2 | 나무는 앉을 수 있는 칸을 **모두** 이어야 한다. 끊기면 다시 만든다. | 228 |
| SW-GEN-3 | 빈자리는 끝 가지(아무도 그 사람을 보지 않음)를 빼서 만든다. | 229~238 |
| SW-GEN-4 | 모든 고정물(창문·기둥·짐수레)은 정답에 **반드시 쓰인다**(장식 고정물 없음). 갈래 B에서는 승객 기믹도 같다(SW-GEN-10). | 246~248 |
| SW-GEN-5 | 짐수레 너머 연결은 부모의 깊이가 1 이상일 때만 만든다. 주인은 그 수레를 건너는 연결의 부모들 중 가장 얕은 깊이보다 **얕은** 승객 중에서 고른다(주인이 먼저 잠들어야 이어짐). 고를 수 없으면 다시 만든다. | 199~204, 249~258 |
| SW-GEN-6 | 정답 배치로 연쇄를 돌려 모두 잠들어야 한다(`run(solved).ok`). | 259 |
| SW-GEN-7 | 고정 승객은 정답 자리에 둔 채 잠근다. 시작 자리 승객은 잠그지 않는다. | 260~263 |
| SW-GEN-8 | 섞기는 고정되지 않은 승객끼리, 또는 빈자리와 맞바꾸기로 한다. 목표 횟수 = max(2, round(움직일 승객 × 0.9)), 시도 최대 400번. | 264~273 |
| SW-GEN-9 | 섞인 배치가 이미 풀려 있으면 버린다(`run(scrambled).ok`면 다시). | 274 |
| SW-GEN-10 | (갈래 B) 승객 기믹 장식 검사: 기믹 승객을 기본 승객으로 바꿔도 정답 배치가 그대로 풀리면 그 기믹은 장식이다 → 그 판을 버린다. | 2-16 §3 |
| SW-GEN-11 | 같은 씨앗이면 같은 판이다. 난수는 실험판과 같은 LCG(`s = s × 1664525 + 1013904223 mod 2^32`)를 쓴다(JS와 글자 단위 대조). | `rng` 125 |
| SW-GEN-12 | 판 하나에 시도 200번(`t < 200`) 안에 못 만들면 씨앗을 바꿔 최대 8번 다시 시도한다. 그래도 못 만들면 한 단계 작은 설계 값(승객 −1)으로 만든다. | `newPuzzle` 304 + 앱 대체 |

### 노선 진행

| id | 규칙 | SoT |
|---|---|---|
| SW-LINE-1 | 승객 수 = min(cap(L), 3 + ⌊(n − 1) × rate(L)⌋), 5n번째 역은 1명 적게(최소 3). cap(L) = round(12 + 34 × (L − 1) / 27), rate(L) = 0.8 + 1.2 × (L − 1) / 27, L = 호선(1~28). | `lineCount`, DECISIONS 2026-10-26 |
| SW-LINE-2 | n = 이 노선에서 지금 계단 높이(1부터). 계단은 기존 노선 길이 적응(2-13 `LineMastery`)이 올린다. | Y2-ROW · 2-13 |
| SW-LINE-3 | 노선 첫 두 역(n ≤ 2)은 짐 상자·자물쇠 없이 그 노선의 기믹 하나만 둔다. 고정물 노선이면 고정물 하나. | `lineSpec` 109~118, DECISIONS 2026-11-09 |
| SW-LINE-4 | 짐 상자 수 = 1 + ⌊N / 8⌋ (첫 두 역 0). 노선 고정물 수 = 1 + ⌊N / 12⌋ (짐수레는 ⌊N / 14⌋), 앞 노선 고정물이 섞이면 ⌊N / 18⌋. | `lineSpec` 110~118 |
| SW-LINE-5 | 판 = `GRIDS`(2×3 → 11×7) 중 승객 + 빈자리 + 고정 칸이 들어가는 가장 작은 판. 열은 최대 7. | `lineSpec` 119~120 |
| SW-LINE-6 | 고정 비율: 첫 두 역 0, 그 뒤 0.18 (원격 설정 `swap_lock_ratio`). 빈자리 비율 0 (원격 설정 `swap_empty_ratio`). | `LOCK[1]`, `EMPTY[0]` — 실험판 기본값 |
| SW-LINE-7 | 한 노선의 판에는 그 노선까지 열린 기믹이 섞일 수 있다(노선 기믹은 반드시 하나 이상). 섞는 비율은 갈래 B 재설계 뒤 정한다. v1 뼈대는 노선 기믹만. | Y2-ROW-3 |

## 4. 불변식

- I-1 `Rider.id`는 판이 끝날 때까지 바뀌지 않는다. 엔진 번호는 화면·저장·분석에 나가지 않는다.
- I-2 고정 승객의 칸은 늘 정답 칸과 같다(힌트로 고정된 승객 포함). 따라서 지금 배치에서도 정답 배치는 늘 도달할 수 있다.
- I-3 `solved`는 늘 풀린 배치다(`run(solved).ok`).
- I-4 같은 (씨앗, 설계 값) → 같은 `SwapPuzzle`(기기·실행과 무관).
- I-5 옮김 수는 줄지 않는다.
- I-6 연결 수 ≤ 승객 수, 연결 수 = 승객 수 ⇔ 클리어.

## 5. 엣지케이스 · 에러 매핑

| 상황 | 처리 |
|---|---|
| 끄는 중 앱이 백그라운드로 감 | 끌기 취소(원래 자리), 시간 멈춤 |
| 끄는 중 손가락이 판 밖 | 미리 보기 없음(지금 배치 기준 표시), 떼면 취소 |
| 시작 자리를 비움(빈자리와 맞바꿈) | 연결 0, 시작 배지와 노란 테두리는 그대로 |
| 힌트 광고 실패·취소 | 기존 정책대로: 실패면 보상 지급(1-2 결정 「보상형 실패 시 보상 지급」), 취소면 아무 일 없음 |
| 생성기가 판을 못 만듦 | SW-GEN-12 대체, 그래도 실패면 오류 기록(non-fatal) + 그 노선 첫 역 판 |
| 클리어 재생 중 되돌리기 누름 | 버튼 비활성 |
