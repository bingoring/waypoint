# Frontend Components — Yawn! 자리 교환 방식

> 디자인 SoT: 교환 방식 화면에는 아직 핸드오프가 없다. 판 위 요소는 실험판 `arrange.html` `draw()`(316~394)·`person()`(397~422)의 배치와 의미를 따르고, 승객·좌석·창문·기둥·짐수레 그림은 핸드오프 v5 렌더러(`ui/character/`)를 그대로 쓴다. 새 요소(시작 배지·자물쇠·짐표·짐 상자·끄는 상태·숫자 막대)는 **디자인 요청서 v6**로 디자이너에게 보내고, 받기 전에는 실험판 모양을 렌더러 선 굵기·색 토큰에 맞춰 임시로 그린다.

## 1. 컴포넌트 트리

```
CarPage (기존 변경)
├─ _StationSign (기존: 노선 색·역 번호·어려운 역 별)
├─ SwapStatsBar (신규: 옮김 n · 연결 n/N)
├─ SwapBoardView (신규, BoardView 대체)
│   ├─ GestureDetector (끌기 + 두 번 눌러 바꾸기)
│   └─ CustomPaint(SwapBoardPainter)
│        ├─ 바닥·좌석 (기존 BoardPainter 좌석 그림)
│        ├─ 고정 칸: 짐 상자 · 창문 · 기둥 · 짐수레(서 있음/넘어짐 + 짐표)
│        ├─ 하품 닿은 좌석 테두리 (노랑, 시작 자리와 같은 굵기)
│        ├─ 시선 (SightPainter — 기존 _shape/_sights에서 떼어 냄): 점선 / 하품 옮긴 갈래 노란 실선
│        ├─ 승객 (기존 캐릭터 렌더러, 외형 = Rider.id) + 짐표 + 자물쇠
│        ├─ 끄는 승객 (손가락 위치, 들린 그림자) · 원래 자리 흐린 자국 · 놓을 칸 표시
│        └─ 시작 배지 (시작 자리 왼쪽 위 모서리, 승객 위에)
├─ SwapActionBar (신규: 되돌리기 · 처음 배치 · 힌트)
└─ ArrivalSheet (기존 변경: 옮김 n · 걸린 시간)
```

## 2. 컴포넌트 상세

### `ArrangeController` (신규, `RunController` 대체, `ChangeNotifier`)

| 항목 | 내용 |
|---|---|
| 상태 | `SwapSession`, `phase`(`arranging`/`dragging`/`playing`/`cleared`/`paused`), `drag`(id, 손가락 위치, 미리 보기 배치), `selected`(두 번 눌러 바꾸기의 첫 승객), `live: ChainResult`, `play`(재생 시작 시각) |
| 메서드 | `startDrag(id, pos)`, `moveDrag(pos)` — 칸이 바뀔 때만 미리 보기 다시 계산, `endDrag(pos)`, `cancelDrag()`, `tapCell(cell)`, `undo()`, `reset()`, `applyHint()`, `pause()`/`resume()` |
| 시간 | `Stopwatch` — `paused`·`playing`·`cleared`에서 멈춤 |
| 출력 | `onCleared(SwapSession)` 콜백 → `CarPage`가 `Kit.won` 호출 |

### `SwapBoardView`

| 항목 | 내용 |
|---|---|
| props | `controller`, `layout`(기존 `BoardLayout` — 칸 크기 44dp 이상, 7×11까지) |
| 끌기 | `onPanStart`: 손가락 아래 승객이 있고 고정이 아니면 끌기 시작(가벼운 햅틱). `onPanUpdate`: `layout.hit()`로 칸 계산. `onPanEnd`: 놓기 |
| 두 번 눌러 바꾸기 | 승객을 누르면 선택(테두리), 다른 칸을 누르면 그 칸과 바꾸기(같은 규칙 SW-MOVE-1~4). 같은 승객을 다시 누르면 선택 해제. 작은 칸·접근성용 대체 입력 (AI 결정) |
| 다시 그리기 | `controller` 알림마다. 끄는 동안은 손가락 위치만 바뀌면 승객 층만 다시 그린다(미리 보기 연쇄는 칸이 바뀔 때만) |
| 접근성 | 칸마다 `Semantics`: 「승객, 오른쪽을 봄, 하품 연결됨, 고정」 / 「빈자리」 / 「창문」 등. 두 번 눌러 바꾸기로 화면 낭독기 사용자도 풀 수 있다 |

### `SwapBoardPainter`

| 층 (아래 → 위) | 그림 | SoT |
|---|---|---|
| 1 바닥·좌석 | 기존 좌석 그림 | v5 렌더러 |
| 2 고정 칸 | 짐 상자(테마 물건, 지하철 = 종이 상자), 창문(기울기 선), 기둥(장식 기호 없음 — 오너 2026-10-21), 짐수레(서 있음: 상자 더미 + 짐표 / 넘어짐: 납작 + 짐표, 투명도 0.75) | 실험판 333~360 |
| 3 좌석 테두리 | 시작 자리와 하품 닿은 좌석: 노란 둥근 테두리, 같은 굵기 (오너 2026-10-27) | 361 |
| 4 시선 | 갈래마다 꺾이는 선. 기본 점선(`sight` 색), 하품을 옮긴 갈래(`litRays`)는 노란 실선 | 364~380 |
| 5 승객 | 캐릭터 렌더러, 외형 씨앗 = `Rider.id`. 상태: 깨어 있음(방향 표시) / 연결됨 / 하품 / 잠듦(z). 짐수레 주인은 짐표, 고정 승객은 자물쇠 | 381~387, 397~422 |
| 6 끄는 승객 | 손가락 위치(살짝 위로 띄움), 1.08배, 그림자. 원래 자리에는 흐린 자국. 놓을 수 있는 칸은 얇은 흰 테두리, 놓을 수 없는 칸은 표시 없음 | 실험판 383 + AI |
| 7 시작 배지 | 시작 자리 왼쪽 위 모서리의 하품 얼굴 원(노랑) — 승객 위에 그려 늘 보인다 | 388~393 |

짐수레 넘어짐 표시는 실시간 경로 기준이다: 지금 배치에서 주인이 잠드는 수레는 넘어진 모양으로 그린다(실험판 `openNow`).

### `SwapStatsBar`

| 항목 | 내용 |
|---|---|
| 보이는 값 | 「옮김 12」, 「연결 8/11」 |
| 시간 | 판 화면에는 보이지 않는다. 도착 안내에만 보인다 (AI 결정 — 시간 제한이 없어 시계가 압박만 준다) |
| 바뀔 때 | 연결 수가 오르면 숫자를 살짝 키웠다 줄인다(애니메이션 끔 설정이면 없음) |

### `SwapActionBar`

| 버튼 | 활성 조건 | 동작 |
|---|---|---|
| 되돌리기 | `history`가 있고 `arranging` | `undo()` |
| 처음 배치 | 섞인 배치와 다르고 `arranging` | `reset()` |
| 힌트 | SW-HINT-3 조건 충족, 정답과 다른 승객이 있음 | 보상형 광고 → `applyHint()` → 옮겨지는 승객을 짧게 이동 애니메이션 |

### `ArrivalSheet` (기존 변경)

- 「모두 잠들었어요」 + 「옮김 n · m:ss」. 탭 방식의 툭 수·니어미스 문구는 없앤다.
- 다음 역 버튼, 노선도 버튼은 그대로.

## 3. 전역 · 공유 상태

| 상태 | 소유 | 비고 |
|---|---|---|
| `Kit` | Riverpod (기존) | 다음 역 판 미리 만들기를 `generateSwap` isolate로 |
| 진행 저장 | `ProgressStore` (기존 변경) | v3 형식, 진행 중 역 |
| 광고 | `rewardGateProvider` (기존) | `rewarded_hint`만 |

## 4. 화면 상태

| 상태 | 화면 |
|---|---|
| 판 준비 중 | 기존 로딩(판 자리 흐린 좌석) — 미리 만들어 두므로 보통 보이지 않음 |
| 배치 중 | 판 + 실시간 경로 + 숫자 막대 + 버튼 |
| 끄는 중 | 「지금 놓으면」 기준 실시간 경로 |
| 연쇄 재생 | 박자대로 하품 → 잠듦, 버튼 비활성 |
| 도착 | 도착 안내 시트 |
| 판 못 만듦 | 기존 오류 대체(그 노선 첫 역 판) |
| 다크 · 글자 130% · 애니메이션 끔 | 기존 기준 그대로 (Y 화면 검사 절차) |

## 5. 상호작용 · 네비게이션

- 노선도 → 역 미리 보기 카드 → 판 화면(기존). 미리 보기 카드의 「사람 수」·기믹 아이콘은 `SwapSpec`에서.
- 판 화면에서 뒤로 가기 → 진행 중 역 저장 → 노선도. 다시 들어오면 이어서(`ResumeStation`).
- 도착 → 다음 역(2역마다 전면 광고, 기존) 또는 노선도.
