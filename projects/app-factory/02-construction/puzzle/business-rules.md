# Business Rules — Game Kit + 조각보 블록 퍼즐

> 근거: [`research-genre-2026-10-15.md`](research-genre-2026-10-15.md), DECISIONS 2026-10-15(장르·범위·효과음·레벨·이어하기·오늘의 판).

## 게임 규칙 (앱)

| ID | 규칙 |
|---|---|
| P-BOARD-1 | 판 8×8. 놓기 = 조각의 모든 칸이 판 안이고 비어 있음 |
| P-PIECE-1 | 조각은 DE §3의 37개. 사용자는 회전하지 않는다 |
| P-DEAL-1 | 배분: 가중치로 3개를 뽑는다. **지금 판에 놓일 수 있는 조각이 하나도 없으면**, 놓일 수 있는 조각들 중 가중치로 하나를 골라 무작위 한 칸을 바꾼다(1회, 반복 없음). 조각 표 전체에서 놓일 조각이 없으면 그 자리에서 게임 끝 |
| P-DEAL-2 | 세 칸을 모두 놓아야 다음 배분. 「적어도 하나 보장」은 배분 순간의 성질이다 — 첫 조각을 놓은 뒤 나머지가 못 놓이는 것은 실력의 결과다 |
| P-CLEAR-1 | 놓은 직후 가득 찬 가로줄·세로줄을 **동시에** 찾아 함께 지운다(겹친 칸은 한 번) |
| P-SCORE-1 | 점수 = 놓은 칸 수 + 줄 점수. 줄 점수 `L(k) = 20·k²`(k = 지운 가로+세로 줄 수) |
| P-SCORE-2 | 연속(combo) `c`: 줄을 지운 놓기마다 +1, 줄을 못 지운 놓기에서 0. 줄 점수 × `(c+1)/2`(정수 나눗셈, `c ≤ 7` → 최대 ×4) |
| P-SCORE-3 | 지운 뒤 판이 완전히 비면 +200 (판 비우기) |
| P-OVER-1 | 게임 끝 = 트레이에 남은 조각 중 어느 것도 판 어디에도 놓일 수 없음 |
| P-CONT-1 | 이어하기(보상형 `rewarded_continue`): 클래식·레벨에서 한 판 1회. 가로·세로 중 가장 많이 찬 줄 3개를 비운다(같은 수면 가로줄 먼저, 그다음 위·왼쪽 줄 먼저, 점수 없음). 매듭 칸은 지우지 않는다(매듭 모으기 레벨을 깰 수 없게 되는 것을 막음). 레벨에서 조각 수를 다 써서 끝난 판은 이어하기를 줄 수 없다. 그래도 남은 조각이 하나도 못 놓이면 남은 칸을 P-DEAL-1로 새로 받는다 |
| P-REFR-1 | 조각 다시 받기(보상형 `rewarded_refresh`): 클래식·레벨에서 한 판 3회까지. 남은 칸을 P-DEAL-1로 새로 받는다 |
| P-DAILY-1 | 오늘의 판: 시드 = `dailySeed(현지 날짜, salt)`. 같은 시작·같은 난수 — 수가 갈리면 조각도 갈린다 |
| P-DAILY-2 | 오늘의 판에는 이어하기·다시 받기가 없다. 그날 **첫 판의 끝 점수**만 기록, 이후 판은 「연습」 표시 |
| P-DAILY-3 | 공유 = 날짜·점수·마지막 판 8×8 이모지 격자(빈칸 ⬜, 채움은 색 5종 이모지, 매듭 없음) |
| P-LEVEL-1 | 레벨 목표: ① `lines`: 조각 `maxPieces`개 안에 줄 `target`개 ② `knots`: 미리 놓인 매듭 칸 `target`개를 줄로 지워 모으기(조각 수 제한 `maxPieces`) ③ `score`: 조각 `maxPieces`개 안에 `target`점 |
| P-LEVEL-2 | 레벨 순서·수치·미리 채운 판·시드는 `assets/levels.json`에 고정. 런타임은 생성하지 않는다 |
| P-LEVEL-3 | 각 레벨은 도구의 자동 플레이 봇이 그 시드로 클리어한 기록(`botResult`)이 있어야 매니페스트에 들어간다 |
| P-LEVEL-4 | 미리 채운 판에는 가득 찬 줄이 없고, 판 비우기 경로가 존재할 필요는 없다. 매듭은 미리 채운 칸 위에만 둔다 |
| P-LEVEL-5 | 레벨 깨면 다음 레벨이 열린다. 실패하면 같은 레벨 다시(같은 시드) |
| P-SAVE-1 | 놓을 때마다 `GameState`를 저장, 앱을 다시 열면 그 판으로 돌아간다(오늘의 판도) |
| P-UI-1 | 조각 색은 장식이며 규칙에 쓰지 않는다(색약 대응). 매듭은 모양(매듭 무늬)으로 구분 |

## 광고 (앱 × 코어)

| ID | 규칙 |
|---|---|
| P-ADS-1 | `banner_menu`는 메뉴 화면에만. 게임판·결과 화면에는 배너가 없다 |

## 코어 `factory_game_kit`

| ID | 규칙 |
|---|---|
| K-RNG-1 | `SplitMix64`의 출력은 명세된 상수(0x9E3779B97F4A7C15 등)로 고정하고, 알려진 시드의 처음 5개 값을 골든 테스트로 고정한다 |
| K-SAVE-1 | 저장 형식에 `v`(버전). 모르는 버전·깨진 JSON은 버리고 새 판 |
| K-ADS-1 | `RoundAds`는 결과 화면의 다음 판 진입에서만 부른다(게임 끝 순간이 아님) |
| K-FB-1 | 효과음은 설정을 따르고 기본 켜짐. 진동은 시스템 설정을 따른다. 「애니메이션 줄이기」는 소리와 무관 |
| K-DEP-1 | `factory_game_kit`은 `factory_core`·`factory_runtime`만 의존(앱·`factory_ads` 구현 의존 금지). `tool/check_deps.dart`에 규칙 추가 |
