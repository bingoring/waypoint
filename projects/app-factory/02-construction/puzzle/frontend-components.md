# Frontend Components — 조각보 블록 퍼즐 (APP_DESIGN_PROMPT v1)

> 1단계 근거: [`research-genre-2026-10-15.md`](research-genre-2026-10-15.md)(이하 「조사」).

## 1. 실제 사용 맥락과 정체성 (프롬프트 1단계)

| 확인한 것 | 내용 | 확인 수준 |
|---|---|---|
| 여는 순간 | 이동·대기·쉬는 시간에 몇 분, 오프라인에서도 | 조사 §4(5점 리뷰: 휴식·시간 때우기·오프라인) |
| 낮은 별점 이유 | ① 광고 과다·긴 부활 광고·판마다 광고 ② 업데이트 뒤 테마 강제 변경 ③ **'풀 수 없는 조각' 조작 의심** ④ 미리 채워진 시작판 ⑤ 광고 제거 구매 뒤에도 보상 광고 강요 | 조사 §4 [공식 리뷰, 분류는 근사] |
| 높은 별점 이유 | 재미·중독성, 두뇌, 휴식, 일일 도전, 깔끔함 | 조사 §4 |
| 상징 | **조각보**: 남은 천 조각을 이어 붙인 보자기 — 색면 조각과 바느질 솔기, 가운데 매듭 | 일반 지식 `추론`(경쟁 블록 퍼즐은 나무·보석·네온 블록) |
| 정책 | 특정 게임의 외형·구성 조합 복제 금지(대법원 2017다212095), Tetris·Blockudoku 명칭 금지, 어린이 대상처럼 보이는 캐릭터 금지(1-2 §4) | 조사 §3 |

**이 앱의 상징 셋:** ① 솔기로 이어진 천 조각(블록) ② 줄이 완성되면 바늘땀이 줄을 따라 달리고 천이 접혀 사라짐 ③ 레벨 지도 = 깨면 한 칸씩 색이 채워지는 큰 조각보 한 장.
**색은 장식일 뿐이다(P-UI-1).** 쪽빛·홍화·치자·쑥·자초 다섯 천연 염료 색을 조각에 돌려 쓰고, 규칙은 모양으로만 읽힌다.

## 2. 한 줄 이야기와 흐름

**이야기:** "자투리 천을 맞춰 한 줄을 채우면 바늘땀이 지나가며 조각보가 완성된다 — 언제나 놓을 자리가 있는 조각을 받는다."

| 순간 | 화면 | 누름 수 |
|---|---|---|
| 바로 한 판 | 앱 열기 → 메뉴의 큰 「이어서 하기」 또는 「클래식」 | 1번 (진행 중인 판이 있으면 그 판) |
| 오늘의 판 | 메뉴 맨 위 오늘 카드 → 「시작」 | 1번 |
| 레벨 | 메뉴 「레벨」 → 조각보 지도의 다음 칸 | 2번 |
| 공유 | 오늘의 판 결과 → 「공유」 | 1번 |

화면: 메뉴 · 게임판 · 결과(시트) · 레벨 지도 · 설정. 첫 실행 튜토리얼 슬라이드 없음 — 첫 판의 첫 배분에서 손가락 모양 힌트가 조각 하나를 판으로 끌어 보여 주고 사라진다(1회).

## 3. 화면별 지시

### 3.1 게임판
「주인공은 **8×8 판 위의 천 조각들**, 이 화면에서 끝나는 일은 조각을 놓아 줄을 채우기야. 첫눈에 보이는 것은 화면 가운데 큰 판(모시 빛 바탕에 칸마다 옅은 솔기 선), 그다음은 아래 엄지 자리의 트레이 세 칸이야. 위쪽에는 점수(큰 고정폭 숫자)와 최고점·모드 표시(오늘의 판이면 날짜, 레벨이면 목표 진척 「줄 4/12 · 조각 18 남음」). 조작은 손가락이 조각에 직접 닿는 끌어 놓기 하나야: 트레이 조각을 누르면 조각이 판 칸 크기로 커지며 손가락 위 1.5칸 높이로 떠올라(엄지가 가리지 않게), 판 위를 지나면 놓일 자리에 옅은 그림자가 보이고, 그 자리로 줄이 완성되면 그 줄이 미리 밝아져. 놓을 수 없는 곳에서 놓으면 조각이 트레이로 미끄러져 돌아가. 놓으면 짧은 진동과 「톡」 소리, 줄이 지워지면 바늘땀이 줄을 따라 왼쪽→오른쪽(세로줄은 위→아래)으로 달리고 천이 안쪽으로 접혀 사라지며(300ms) 얻은 점수가 그 줄 위에 떠올라. 연속이면 「연속 ×2」가 판 위에 잠깐. 트레이에서 지금 판에 놓일 곳이 없는 조각은 옅게 보여. 게임판에는 배너가 없어. 오른쪽 위 일시정지(설정·메뉴로). 보상형 버튼 「광고 보고 조각 다시 받기 (2/3)」는 트레이 옆 작은 버튼이고 오늘의 판에서는 없어.」

### 3.2 결과 (아래 시트)
「주인공은 **이번 판 점수와 완성된 판**. 시트 위쪽에 점수(아주 크게)와 「최고점!」(신기록이면), 그 아래 마지막 판의 작은 그림. 클래식·레벨에서 이어하기가 남았으면 첫 버튼이 「광고 보고 이어하기 (가장 많이 찬 줄 3개 비우기)」 — 보상이 버튼에 적혀 있어. 그다음 「다시 하기」(레벨이면 성공 시 「다음 레벨」), 「메뉴로」. 오늘의 판이면 「공유」가 대표 버튼이고 「연습 판 하기」가 보조. 전면 광고는 「다시 하기」·「다음 레벨」을 누른 뒤에만, 두 번에 한 번(P-ADS-2).」

### 3.3 메뉴 (홈)
「주인공은 **오늘의 판 카드와 진행 중인 판**. 맨 위 오늘 카드: 날짜와 작은 조각보 무늬, 아직 안 했으면 「시작」, 했으면 내 점수와 「공유」. 그 아래 큰 버튼 「이어서 하기」(진행 중인 판이 있을 때, 판 미리보기) 또는 「클래식」, 그 아래 「레벨 23」(지도 미리보기 띠). 최고점은 클래식 버튼 안에 작게. 광고는 맨 아래 배너(`banner_menu`)이고 버튼과 8dp 이상 떨어져.」

### 3.4 레벨 지도
「주인공은 **100칸짜리 큰 조각보 한 장**(10×10 패치). 깬 레벨은 염료 색으로 채워지고, 다음 레벨은 바늘 무늬와 진한 테두리, 잠긴 레벨은 모시 빛이야. 칸마다 레벨 번호와 목표 아이콘(줄·매듭·별점). 누르면 목표 한 줄과 「시작」. 지도를 다 채우면 완성된 조각보 그림이 남아.」

### 3.5 설정
2-1 부품 + 효과음 스위치(기본 켜짐) + 진동 스위치 + 「조각은 항상 판에 놓일 수 있는 것을 하나 이상 줘요」 안내 한 줄.

## 4. 움직임 표

| 순간 | 움직임 | 처음 → 끝 | 길이 |
|---|---|---|---|
| 조각 집기 | 트레이 크기 → 판 칸 크기로 커지며 손가락 위로 | 트레이 → 손 | 120ms |
| 놓기 | 그림자 자리로 착 붙음 | 손 → 판 | 80ms |
| 놓을 수 없음 | 트레이로 미끄러져 돌아감 | 손 → 트레이 | 200ms |
| 줄 지우기 | 바늘땀이 줄을 달리고 천이 접혀 사라짐, 점수 떠오름 | 가득 찬 줄 → 빈 줄 | 300ms |
| 판 비우기 | 판 전체에 솔기 무늬가 한 번 퍼짐 | 빈 판 강조 | 400ms |
| 새 배분 | 세 조각이 트레이 아래에서 차례로 올라옴 | 빈 트레이 → 새 조각 | 60ms 간격 |
| 레벨 깸 | 지도에서 그 칸이 염료 색으로 물듦 | 모시 → 색 | 400ms |

「애니메이션 줄이기」: 위 움직임을 즉시 결과로(소리·진동은 설정대로).

## 5. 시각 규칙

- `BoardPainter`(판·솔기·조각·매듭 무늬 한 번에 그림, 조각 집는 동안은 그림자·밝아지는 줄만 따로 그림), `PieceWidget`(트레이·드래그), `QuiltMap`(레벨 지도).
- 조각 색 5종(상수, 라이트·다크 각각): 쪽빛·홍화·치자·쑥·자초. 칸 안쪽 2dp 솔기 선과 아주 옅은 위쪽 빛(평면 + 한 방향 빛, 프롬프트 3단계). 금속·네온·보석 질감 없음.
- 시드 색 **#A8432A**(홍화, 11.9°): 로또 223°·연봉 160°·소음 253.6°와 각각 148°·148°·118° 떨어짐, 흰 글자 대비 6.0:1.
- 숫자 고정폭, 글자 3단계(점수 · 버튼·제목 · 본문). 캐릭터·마스코트 없음(대상 연령 1-2 §4).
- 터치 영역: 트레이 조각 칸은 각 1/3 너비 × 96dp 이상, 버튼 48dp 이상.

## 6. 광고 자리

`banner_menu`(메뉴만) · `interstitial_round_end`(결과에서 다음 판으로, 2번에 1번) · `rewarded_continue`(결과 시트, 한 판 1회) · `rewarded_refresh`(게임판 트레이 옆, 한 판 3회). 오늘의 판은 보상형 없음.

## 9. 프롬프트 5단계 검사 결과 (2026-10-15, API 36 에뮬레이터 `-gpu host` · 프로파일 빌드)

스크린숏: [`screens/`](screens/) — 01 메뉴 · 02 클래식 첫 판(힌트, 영어) · 02b 첫 조각 놓음 · 03 레벨 게임판(목표·남은 조각) · 04 레벨 지도 · 04b 레벨 목표 대화상자 · 05 설정 · 06 메뉴 다크·글자 130% · 07 게임판 다크·130% · 08 결과 시트 다크·130% · 08b 이어하기 뒤 · 09 비행기 모드

| 검사 | 결과 |
|---|---|
| 이름을 가려도 무슨 앱인지 아는가 | ✅ 모시 빛 8×8 판과 솔기 선, 염료 색 천 조각, 메뉴의 날마다 다른 조각보 무늬 |
| 설명을 가려도 대표 조작을 찾고 결과를 짐작하는가 | ✅ 엄지 자리 트레이 세 조각 → 끌기 하나. 놓일 칸 그림자와 지워질 줄이 미리 밝아진다. 놓을 곳이 없는 조각은 옅게 |
| 결과까지 누른 횟수 | ✅ 클래식·오늘의 판 1번, 레벨 2번(지도 → 시작), 이어서 하기 1번 |
| 다른 앱에 옮겨도 똑같을 요소 | ✅ 없음 (설정 부품 제외). 바늘땀 지우기·조각보 지도·공정 배분 안내는 경쟁작에 없음 |
| 움직임이 무엇이 어디로 가는지 보여 주는가, 꺼도 되는가 | ✅ 바늘땀이 줄을 달리고 천이 접힘(300ms), 점수가 그 줄에서 떠오름, 못 놓으면 트레이로 미끄러짐(200ms), 새 조각 60ms 간격. 애니메이션 줄이기면 즉시 |
| 광고가 주인공·대표 버튼을 가리는가 | ✅ 아니다. 배너는 메뉴 맨 아래에만, 게임판·결과에는 없음. 보상형은 버튼에 보상을 적고(「광고 보고 이어하기 / 가장 많이 찬 줄 3개를 비워요」), 전면은 「다시 하기」에서만(위젯 테스트) |
| 사실·문구가 출처와 같고 남의 상표가 없는가 | ✅ 경쟁 게임 이름·외형 없음, 캐릭터 없음. 스토어 문구의 광고 횟수(두 번에 한 번 이하)는 `everyN 2`와 같음 |
| 다크 · 글자 130% · 영어 | ✅ 염료가 다크에서 밝아지고 판은 어두운 삼베 빛, 잘림 없음. 영어 문구 확인 |
| 예외 상태가 빈 화면이 아닌가 | ✅ 게임 끝: 결과 시트(점수·최고점!·마지막 판·이어하기). 비행기 모드에서도 모든 모드 동작(배너만 빈 자리) |

**검사 중 고친 것:** ① 「클래식」을 눌러도 게임판으로 넘어가지 않음(판이 생기며 메뉴 본문이 다시 만들어져 기다리던 context가 사라짐) → Navigator를 먼저 잡고 트리 모양 유지 ② 효과음 준비가 끝나야 메뉴가 떠서 첫 화면이 10초 넘게 막힘 → 키트가 미리 불러오기를 기다리지 않음 ③ 힌트가 사라질 때 판이 위로 움직임 → 자리 고정 ④ 글자 130%에서 이어하기 버튼이 「3 / 개」로 끊김 → 행동·보상 두 줄 ⑤ (릴리스) R8 전체 모드가 WorkManager의 Room 구현 생성자를 지워 시작 직후 종료 → 템플릿·모든 앱 proguard keep 규칙.
**확인한 동작:** 끌어 놓기·트레이 복귀, 줄 지우기, 게임 끝 → 이어하기(테스트 광고가 준비되지 않아 D3 기본 지급, 1·2행과 6열이 비워짐), 레벨 시작·목표 표시, 언어 바꾸기, 강제 종료 뒤 「이어서 하기」로 복원, 비행기 모드.
**에뮬레이터에서 볼 수 없는 것:** 드래그 손맛·프레임(Flutter 자체 표면이라 `gfxinfo`에 안 잡힘), 효과음 지연·진동 → 3-1 실기기. 릴리스 빌드는 테스트 광고 단위로는 시작하지 않아(R-ADS-3) 콜드 스타트·PSS는 AdMob 단위 등록 뒤.
