# Business Logic Model — Game Kit + 조각보 블록 퍼즐

## 1. 한 수 (`lib/domain/game.dart`, 순수 Dart)

```
drag 놓기(slot, x, y)
 → canPlace? (P-BOARD-1)
 → 칸 채우기, score += 칸 수
 → 가득 찬 가로·세로 동시 탐색 → 지우기 (P-CLEAR-1)
 → combo 갱신, 줄 점수·판 비우기 (P-SCORE-1~3)
 → 매듭 수집(레벨)
 → 트레이가 비면 배분 (P-DEAL-1·2)
 → 게임 끝 판정 (P-OVER-1), 레벨 목표·조각 수 판정
 → 저장 (P-SAVE-1)
```
- 판은 `Uint8List(64)`, 가득 찬 줄 검사는 줄마다 8칸(최대 16줄) — 한 수에 수 μs.
- 「놓일 수 있는가」 = 조각 × 64 위치 시험. 배분·게임 끝 판정에서만 부른다(최대 37 × 64 × 9 칸 비교, 1ms 미만).

### 1.1 배분 (P-DEAL-1)
1. `rng`로 가중치 3회 뽑기.
2. 셋 중 지금 판에 놓일 조각이 있으면 끝.
3. 없으면 `fit = 조각 표 중 지금 놓일 수 있는 것`. `fit`이 비면 → 게임 끝. 아니면 `fit`에서 가중치로 하나, `rng`로 0~2 칸 하나를 골라 바꾼다.
- 난수 소비 순서를 고정한다(오늘의 판 결정성).

### 1.2 이어하기 (P-CONT-1)
가로 8줄·세로 8줄의 찬 칸 수로 정렬(동률: 가로 먼저, 위·왼쪽 먼저) → 상위 3줄 비우기 → 남은 조각 중 놓일 것이 없으면 남은 칸만 배분.

### 1.3 골든 테스트
| 판·조각 | 기대 |
|---|---|
| 가로 2줄 + 세로 1줄이 한 수로 동시에 참 | 3줄, 교차 2칸은 한 번, `L(3)=180` |
| 모서리 한 칸만 비고 1×1이 트레이에 있음 | 놓임, 다른 조각은 못 놓임 |
| 판 비우기 | +200 |
| combo 1→2→3→0 | 배율 ×1, ×1.5, ×2, 초기화 |
| 같은 시드·같은 수 | 같은 배분 (오늘의 판) |
| 속성 테스트: 무작위 판 1,000개 × 배분 | 조각 표 중 하나라도 놓이면 배분에도 하나 이상 |

## 2. 레벨 (`tool/build_levels.dart` — 오프라인)

1. 레벨 `n`(1~100)의 목표 종류: `n % 3` 기반 순환 + 10단위마다 섞기. 수치 곡선 예: `lines` target 3→18, `knots` 2→10, `score` 300→2,500, `maxPieces`는 여유 배율 2.0→1.15로 줄인다.
2. 미리 채운 판: 조각보 문양(좌우·상하 대칭 무늬 사전 8종 × 밀도) — 가득 찬 줄 없음(P-LEVEL-4). `knots`는 채운 칸 위에.
3. 시드 `level·salt`. 봇: 트레이 세 조각의 순서 3! × 모든 위치를 빔 탐색(폭 8)으로 시험하고, 중간 단계는 (줄 지움·매듭·구멍·경계)로, 잎은 여기에 「놓일 수 있는 조각 가중치 합」을 더해 매긴다. 빈 판 생존 중앙값 256조각(1-ply 탐욕 봇은 65조각이라 기각). 난이도 추정: 평가에 작은 흔들림을 넣어 5회 두고 3회 이상 깨면 채택, `maxPieces = max(중앙값+2, ⌈중앙값 × 여유 배율⌉)`, 마지막으로 흔들림 없는 봇이 그 제한 안에 깬 기록을 `botResult = {pieces, score}`로 남긴다. 기준을 못 넘으면 목표를 15% 낮추고 시드를 바꿔 최대 5회 → 그래도 못 깨면 도구 실패(곡선을 고친다).
   - **구현 중 조정(2026-10-15):** 점수 곡선 300→2,500 대신 **300→1,500**. 봇 기준 2,000점 이상 레벨이 120조각(사람 기준 5분 이상)을 넘어 한 레벨로 너무 길었다. 줄·매듭 곡선과 여유 배율 2.0→1.15는 예시 그대로.
4. 결과 `assets/levels.json`(100개). 테스트는 매니페스트 ↔ 생성기 결정성 + 몇 레벨에서 봇 재현(CI 1분 이내).

## 3. 게임 키트 연결

| 순간 | 키트 |

## 4. 효과음 (`tool/gen_sfx.dart`)

직접 합성한 짧은 WAV 5개(놓기·줄 지우기·combo·판 비우기·게임 끝, 각 < 20KB, 44.1 kHz mono 16비트) — 라이선스 문제가 없고 다시 만들 수 있다. `audioplayers` 6.8.1(2026-06-27) 정확히 고정, 저지연(`PlayerMode.lowLatency`).
