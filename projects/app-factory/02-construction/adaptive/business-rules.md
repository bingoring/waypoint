# Business Rules — 공통 적응형 난이도 `factory_adaptive`

> 근거: [`research-2026-10-16.md`](research-2026-10-16.md)(이하 「조사」), DECISIONS 2026-10-16(익명 보정, 알리고 끌 수 있게, 기믹 간격, 노선 선택).

## 1. 원칙 (어떤 설정으로도 바꿀 수 없음)

| ID | 규칙 |
|---|---|
| A-ETH-1 | 목표 난이도 계산에 **광고 시청·구매 여부, 광고 제거 여부, 매출 지표를 입력으로 쓰지 않는다** (EU CPC 공동성명 2026-09-30, 조사 ④) |
| A-ETH-2 | 니어미스 지표는 보상형 광고 「제안 위치」에만 쓰고 결제 유도 화면과 연결하지 않는다 |
| A-SOLV-1 | 게임의 `measure`가 `solvable = true`라고 확인한 판만 낸다. 예외 없음 |
| A-PRIV-1 | 실력 점수·상황 신호는 기기 밖으로 보내지 않는다. 보내는 것은 §6의 판 결과뿐 |
| A-OFF-1 | 스위치를 끄면 실력 점수와 상황 신호를 쓰지 않는다. 기믹 순서·생성·검증은 그대로이고, 목표는 기본 곡선 `T0(played)`만 따른다 |

## 2. 기믹 커리큘럼

| ID | 규칙 | 근거 |
|---|---|---|
| A-CUR-1 | 후보 판에 들어가는 **못 익힌 기믹은 최대 1개** | Sarkar & Cooper AIIDE 2020 (조사 ②) |
| A-CUR-2 | 「익힘」 = 그 기믹이 든 판을 2번 이기고, 그중 1번은 도움 없이(힌트·한 번 더 툭 없이) | 위와 같음, 도움 의존 방지 |
| A-CUR-3 | 새 기믹은 게임이 준비한 **사람이 만든 소개 판**으로만 처음 나온다 | 하품 릴레이 프로토타입: 소개 역 이기는 시작점 ≥ 2 |
| A-CUR-4 | 다음 기믹 소개 조건: 직전 기믹 익힘 **그리고** `played − lastIntroAt ≥ spacing[i]`. 실력이 높아도 건너뛰지 않는다 | 오너 요구(빨리 깼다고 어려운 기믹을 열지 않음), King 단계적 방해물 |
| A-CUR-5 | 노선(장)을 플레이어가 고르면, 그 노선의 기믹 묶음 안에서만 `allowed`를 만든다. 노선 해금은 A-CUR-4와 같다 | DECISIONS 2026-10-16 노선 선택 |

## 3. 판 난이도 예측 (A-PRED)

| ID | 규칙 |
|---|---|
| A-PRED-1 | 예측 패배 확률 `p = σ(bias + Σ w_i · f_i)` (f = 게임 지표, 로지스틱). 가중치는 `model.json` → 원격 설정이 덮어씀 |
| A-PRED-2 | 판 점수(레이팅 척도) `R_L = 1500 + 400·log10(p / (1 − p))` — 실력 1500인 사람에게 패배 확률 p가 되는 점수 |
| A-PRED-3 | 실력 r인 사람의 기대 패배 확률 `p(r) = 1 / (1 + 10^((r − R_L)/400))` |
| A-PRED-4 | 초기 가중치는 가상 플레이어 시뮬레이션(BLM §5)으로 맞추고, 출시 뒤 익명 결과로 다시 맞춘다(오프라인 도구, BLM §6) |

## 4. 실력 (Glicko-2)

| ID | 규칙 | 근거 |
|---|---|---|
| A-RATE-1 | 판 하나 = 한 경기. 상대는 그 판(`R_L`, RD 고정 50). 결과 점수: 도움 없이 이김 1.0 / 도움 받고 이김 0.75 / 짐 0 | Sarkar & Cooper 2020 |
| A-RATE-2 | 시도 수는 결과 점수를 줄인다: 이김이어도 `attempts ≥ 3`이면 0.75, `≥ 5`면 0.5 | AIIDE 2025 다지표 |
| A-RATE-3 | 판 하나로 바뀌는 `rating` 폭 ≤ `rating_delta_cap`(60), `rd` 하한 60 | King 「실력 파악에 몇 주~몇 달」 (조사 ①) |
| A-RATE-4 | 풀이 시간·가만히 있던 시간은 실력 점수에 넣지 않는다(기록만). 시간 단독 지표의 체감이 가장 낮았다 | AIIDE 2025 (조사 ②) |
| A-RATE-5 | 깨지 않고 나간 판(`abandoned`)은 짐(0)으로 센다 |

## 5. 목표 난이도

| ID | 규칙 |
|---|---|
| A-TGT-1 | 기본 곡선 `T0 = target_min + (target_max − target_min) · min(1, played / target_ramp)` |
| A-TGT-2 | 톱니: `T = T0 + sawtooth[played % len]`, 범위 `[target_min, target_max]`로 자름 |
| A-TGT-3 | **진 직후에는 목표를 올리지 않는다**: 직전 판이 짐이면 `T ≤ 직전 T` |
| A-TGT-4 | **2연패면** `T −= loss_step_down`, 3연패 이상이면 `target_min`. 이기면 원래 곡선으로 돌아간다 |
| A-TGT-5 | 소개 판과 처음 3판은 목표 계산 없이 쉬운 판(소개 판 그대로, 첫 3판은 `target_min`) |

## 6. 상황 신호 (켬일 때만)

| ID | 규칙 |
|---|---|
| A-CTX-1 | `commute` 또는 `cellular`이면 크기 예산을 한 단계 줄인다(짧은 판). **목표 난이도는 바꾸지 않는다** |
| A-CTX-2 | `longSession`이면 `breather_every`판마다 쉬어 가는 판(`T = target_min`, 작은 판) |
| A-CTX-3 | 상황 신호의 효과는 출시 뒤 A/B(원격 설정 on/off)로 확인한다. 근거 사례가 없다(조사 ⑤) |

## 7. 생성·대체

| ID | 규칙 |
|---|---|
| A-GEN-1 | 생성은 백그라운드 isolate에서, 이전 판을 하는 동안 미리 한다. 시간 예산 `gen_budget_ms` 안에 후보 `gen_candidates`개 |
| A-GEN-2 | 후보 중 `|p(r) − T|`가 가장 작은 판. 같으면 기믹 다양성(최근 5판에 덜 나온 기믹)을 우선 |
| A-GEN-3 | 예산 안에 풀리는 후보가 없으면 `pool.json`에서 같은 기믹 묶음·가장 가까운 판을 고른다. 그것도 없으면 그 노선의 소개 판 |
| A-GEN-4 | 같은 판(같은 시드·같은 상태)은 같은 결과 — 버그 재현용으로 판마다 `seed`를 기록 |
