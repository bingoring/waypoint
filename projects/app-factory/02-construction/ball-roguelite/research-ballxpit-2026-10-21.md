# BALL x PIT 조사 — 공 특수 능력 설계 참고

> 오너 요청(2026-10-21): 공에 특수 기능을 더하는 게임으로 BALL x PIT을 확인하고 설계에 반영. 출처는 나무위키 본문·하위 문서(볼·패시브·캐릭터·뉴 볼빌론·원정), ballxpit.wiki.gg, Steam, 리뷰. 표기 [확인]/[추정].

## 0. 개요
Kenny Sun 개발, Devolver 유통, 2025-10-15 PC·콘솔, 모바일 2026-03-12. 벽돌깨기 + 서바이버 로그라이트 + 도시 건설. 볼 60종+, 건물 70종+, Steam 95% [확인]. 전 플랫폼 200만 장(10개월) [확인, 앞선 조사].

## 1. 런 코어 루프
- 수동 조준(가이드라인) 또는 자동 발사. 공은 벽·적에 튕길 때마다 빨라짐. 하단 벽에 닿으면 강화가 풀리고 쿨다운 뒤 재발사 — **캐릭터를 움직여 직접 받으면 즉시 재장전**(숙련 요소) [확인].
- 적은 웨이브로 내려옴. 화면 전멸 시 풀클리어 보너스 골드 + 다음 웨이브 즉시 [확인].
- 레벨업마다 아이템 하나 선택(리롤 유료·비용 상승, 건물로 할인·무료·제거) [확인].
- 스탯: 체력·힘(공 피해)·지능(베이비볼·상태이상)·통솔(베이비볼 수)·속도·민첩(크리) [확인].
- 스테이지 3페이즈(중간보스) + 최종보스, 일반 15분 [확인]. 8스테이지, 보스 첫 클리어 기어로 다음 스테이지 해금, 엔딩은 서로 다른 캐릭터 8명으로 최종 스테이지 클리어 [확인].

## 2. 특수 볼 (기본 21종, 런 안에서 L1~L3) [확인]
출혈(중첩, 공에 맞을 때마다 중첩만큼) · 화상(지속·중첩 DoT) · 중독(지속·중첩) · 냉동(확률, 받는 피해 +25%) · 번개(주변 3→5명 연쇄) · 바람(관통·둔화, 피해 −25%) · 빛(실명) · 어둠(3→5배 피해, 적중 시 소멸, 쿨다운) · 시간(적중 시 소멸, 시간 덫) · 무쇠(2배 피해, 느림) · 돌(첫 타 300→400%, 감쇠) · 살점(튕길 때마다 속도 +25→40%) · 귀신(관통) · 지진(3×3→4×4) · 레이저 수평/수직(행·열 전체) · 무리어미(확률로 베이비볼) · 알주머니(폭발하며 베이비볼 2~5) · 세포(적중 시 분열) · 흡혈귀(확률 회복) · 매혹(적이 아군 공격).
**상태이상 규칙:** 출혈·맹독·방사능은 지속시간 없이 중첩으로 쌓임(턴제와 잘 맞음). 저주 = 5회 피격 후 큰 폭발, 과다성장 = 3중첩 소모 폭발, 질병 = 전염 [확인].

## 3. 진화·융합 [확인]
L3 볼 2개 + 희소한 **융합 원자로** 1개 → 셋 중 선택: 분열(아이템 레벨 랜덤 상승) · **융합**(아무 L3 두 개, 특성 합산, 종착점) · **진화**(정해진 레시피, L1부터 재육성, 진화끼리 다시 진화 가능). 진화 69종, 융합 조합 약 7,921개.
- 융합 결과 규칙: 범위 + 상태이상 → 범위 전체에 상태이상 / 생성형 + 상태이상 → 생성된 볼이 상태이상 상속 / 같은 계열 → 중첩 상한 조정.
- 대표 진화: 폭탄 = 화상 + 무쇠 · 태양 = 화상 + 빛 · 불지옥 = 화상 + 바람(화상 무제한) · 거머리 = 무리어미 + 출혈 · 구더기 = 세포 + 무리어미(적이 죽을 때 베이비볼) · 산탄총 = 무쇠 + 알주머니(벽 충돌 시 베이비볼) · 강철 = 돌 + 무쇠(적중마다 피해 누적) · 신성 레이저 = 수평 + 수직 · 폭풍 = 번개 + 바람 · 핵폭탄 = 폭탄 + 중독 · 블랙홀 = 태양 + 어둠.
- [추정] 설계 논리: 원자로가 희소해 「진화냐 융합이냐」가 결정이 되고, 융합이 하한을 보장해 버려지는 원자로가 없으며, 규칙 기반 융합이라 수천 조합을 손으로 만들 필요가 없다.

## 4. 패시브 [확인]
기본 54종 + 패시브 진화 17종. 슬롯 볼 4 + 패시브 4(건물로 +1씩). 계열: 바운스 스케일(튕길수록 가속, 벽 반사 후 다음 타격 +70%) · 첫 타 집중 · 위치 조건(상단 벽 반사 후 +100%) · 크리(단검 4종 → 크리 +100%) · 관통 · 물량(베이비볼 수만큼 피해 증가) · 처치 연쇄(적이 죽을 때 폭탄 볼) · 소환.

## 5. 캐릭터 = 규칙 변경 [확인]
연사 2배·부정확 / 벽까지 관통 / 업그레이드 자동 선택 / 반대편 거울 발사(50%) / 공 하나 반복 투척 / 화면 상단에서 발사 / 방패로 받아칠 때마다 피해 +100% / 직접 피해 0·범위·상태이상 ×4 / 공이 하단에서 튕겨 올라감 / 포물선 투척 / **턴제(지략가)** / 부채꼴 동시 발사 / 공이 상단으로 끌림 / 상하 화면 연결 / 볼 슬롯 2배·패시브 0 등 22종. 2인 동시 출전(규칙 합산).

## 6. 메타: 뉴 볼빌론 [확인]
수확도 벽돌깨기(일꾼을 쏘아 자원 타일·건물에 맞힘). 땅 확장, 설계도로 건물 해금. 건물 = 스탯 배율·고정치·시작 볼 레벨·출전 전 선택·슬롯 +1·경험치·골드·선택지 증가·리롤 할인·캐릭터 해금.

## 7. 평가 [확인]
호평: 화면이 공으로 가득 차는 쾌감, 조합 발견, 운보다 전략, 배치 퍼즐 기지. 혹평: 그라인드 위주 성장, 빌드 응집력 부족·숫자만 올림, 약한 캐릭터 반복 육성, 핵심 조각이 안 나옴, 마을 관리가 흐름을 끊음, 후반 너무 강해 최종보스가 쉬움. 빌드가 터지는 순간: 단검 4종 + 관통 + 벽 반사, 과다성장 × 레이저(한 판 200만 피해), 구더기가 레이저·핵폭탄 상속.

## 8. 핀볼 × 페그 게임에 옮길 교훈 [추정]
**잘 옮겨짐:** ① 튕길수록 강해짐 ↔ 플리퍼·범퍼 랠리 ② 벽·장치 충돌 시 분산탄 ↔ 범퍼·특정 페그에서 멀티볼 ③ 적중 시 소멸하는 고위력 볼 ↔ 일회성 구슬(N턴 뒤 복귀) ④ 지속시간 없는 중첩 ↔ 페그로 쌓고 다음 턴에 터뜨림, 「페그 N개 맞히면 발동」 ⑤ 규칙 기반 융합 표 ⑥ 융합(하한) + 진화(상한) + 희소 재료 ⑦ 숙련 보상(직접 받기 ↔ 플리퍼로 살리기) ⑧ 캐릭터 = 판 물리 규칙 변경.
**잘 안 옮겨짐:** 관통(페그 상대로는 의미 없음 → 「페그를 소모하지 않음」으로 재정의) · 행/열 레이저(→ 페그 가로줄) · 실시간 요소(전진·회피·매혹) · 물량은 한 발 구조에서 따로 확보해야 함(분열·멀티볼 필수) · 핵심 조각이 안 나오는 문제와 메타 그라인드는 피함(보장 장치, 짧은 메타).
