# 공 물리 신작 조사 — 하이퍼캐주얼인가, 로그라이크인가

> 오너 요청(2026-10-21): Yawn!과 병렬로 새 게임을 개발한다. 페글린(Peglin) 시스템이 인상적이고, 핀볼(첨부 이미지 1)과 페글린을 섞거나 페글린을 변형하면 재밌을 것 같다. 오너가 가져온 기획안 「파칭코 디펜스: 잭팟 러시」(연사 → 핀 → 잭팟 홀 → 슬롯 7-7-7 피버 → 바닥 좀비 웨이브 타격)도 참고. **장기적으로 하이퍼캐주얼로 갈지 로그라이크로 갈지 조사.**
> 조사 방법: 세 갈래 병렬 조사(페글린 심층 · 비슷한 게임 15종 · 모바일 시장/정책). 스토어 수치는 2026-10-21 직접 조회.
> 표기: **[확인]** 출처 원문 · **[2차]** 컨설팅·요약 기사 · **[추정]** 판단.

## 결론

**하이브리드캐주얼 틀 + 가벼운 로그라이트 런.** 순수 하이퍼캐주얼도, 페글린 같은 본격 로그라이크도 아니다.

| 근거 | 내용 |
|---|---|
| 하이퍼캐주얼은 이 장르에서 돈이 안 된다 | 핀볼·벽돌깨기 서브장르(2012~2023-11): 다운로드 9.48억 중 하이퍼캐주얼 62%인데 **매출 $296M 중 하이퍼캐주얼은 8%**, 하이브리드 63% [확인, Sensor Tower] |
| 광고로 크게 번 공 게임은 전부 하이브리드 쪽 | Ball Blast(Play 5,000만+, 지금은 퍼크·장비를 고르는 하이브리드로 진화), Ballz 1,000만+, Bricks Ball Crusher [확인] |
| 광고만으로 번 1인 로그라이크는 선례가 없다 | 1인·소규모 성공작(Balatro, Peglin, BALL x PIT)은 모두 유료 해금 [확인]. 광고형 성공 사례 Vampire Survivors는 PC 메가 히트의 이식 |
| 그 빈자리가 기회 | 광고 수익형 페글린류는 사실상 비어 있다 — 광고형 로그라이크 벽돌깨기는 Bricks Breaker RPG·Brick Dungeon(각 Play 5만+)이 최대, 파칭코·디펜스형 모바일은 평가 수십 개 이하 [확인] |
| 로그라이트 런은 보상형 광고 자리가 많다 | 부활(런당 1회), 런 종료 보상 2배, 유물 선택지 하나 더, 구슬 버리기 — Vampire Survivors의 배치가 직접 선례 [확인] |

**하지 말 것 — Peggle Blast의 실패:** 같은 IP를 무료+결제로 바꿔 다운로드 1,000만+인데 평점 2.5~2.7★. 「패배 직전 결제 유도」와 「6시간 대기」 때문 [확인]. **광고는 결과(실패)가 아니라 보상에 붙인다.**

## 1. 페글린 — 무엇을 가져오고 무엇을 덜어낼까

| 항목 | 내용 |
|---|---|
| 정체 | Red Nexus Games(캐나다 인디), 게임잼 「Goblin Drop」(2019) → PC 앞서 해보기 2022, 1.0 2024, 2.0(4막) 2026-03. 영감: Peggle × Slay the Spire [확인] |
| 성과 | Steam 17,764개 84%, 앞서 해보기 첫해 약 40만 장, Steam 추정 약 38만 장·$4.6M [확인/제3자 추정] |

| 전투 한 번 | 각도만 정해 구슬 발사 → 발사 뒤 조작 불가 → 맞힌 페그마다 데미지 누적(맞힌 페그는 사라짐) → 구슬이 바닥으로 빠지면 누적 데미지로 적 공격 → 적 턴. 구슬 가방을 다 쓰면 재장전 턴 [확인] |
| 특수 페그 | **크리티컬**(데미지를 크리 수치로, 소급), **리프레시**(사라진 페그 부활), **폭탄**(2번 맞히면 적 전체 50) — 이 셋만으로 「어디를 노릴까」가 생긴다 [확인] |
| 런 | 슬레이 더 스파이어식 노드 지도(전투·미니보스·보스·?·상자·상점), 숲 → 성 → 광산 → 4막. **지도 갈림길도 구슬을 쏴서 고른다**. 클리어 1회 40~90분 [확인/추정] |
| 성장 | 구슬(=덱) 약 110종·Lv1~3, 유물 약 180종, 직업 4종, 크루시볼 20단계. 영구 성장은 약함 [확인] |
| 불만 | 운이 전략을 압도, 런 초반 지루함, 보드 반복, 초보에게 배수·아이템 설명 불친절 [확인] |

**가져올 것:** 「한 발 쏘고 지켜보는」 손맛(조작은 각도 하나 — 캐주얼 친화), 특수 페그 3종, 맞힐 때마다 숫자가 쌓이는 연출, 지도도 구슬로 고르기.
**덜어낼 것:** 런 길이(40~90분 → 전투 1~3분 × 노드 몇 개, 중간 저장), 콘텐츠 양(구슬 15~20종·유물 30~40종으로 시작, 효과는 「×2」「+5」처럼 바로 보이게), 운 체감(첫 바운스 몇 번 궤적 미리 보기), 물리 대기(기본 배속↑·스킵), 메타 성장 부재(영구 업그레이드·일일 시드 런).
**핀볼과 섞는 이유 [추정]:** 페글린의 가장 큰 불만은 「발사 뒤엔 아무것도 못 한다 → 운」이다. **플리퍼로 구슬을 살려 더 맞히게** 하면 그 불만을 직접 풀고, 첨부 이미지 1의 핀볼 손맛과도 이어진다.

## 5. 방향 후보 (AI 제안 — 오너 결정)

## 6. 첫 플레이어블에서 확인할 것 (웹 프로토타입 먼저 — Yawn!과 같은 방식)

1. **손맛:** 조준 미리보기, 튕김 소리·햅틱, (A) 플리퍼 타이밍이 텍스트 튜토리얼 없이 첫 판에 통하는가.
2. **결정적 물리:** 고정 타임스텝 + 시드로 같은 발사가 같은 결과를 내는가(로그라이크 원칙 R2 — 리플레이·일일 시드·봇 밸런스). Flutter에서 구슬 1개(A) / 수백 개(B)의 프레임.
3. **한 판 더:** 짧은 런과 유물 3택 1이 「한 판 더」를 만드는가.
4. **보상형 의향:** 부활·런 종료 2배를 누르는 비율.
5. **연출 등급:** 슬롯 대체 연출이 「시뮬레이션 도박 가끔」 이하인가.
6. **지표 관문(출시 뒤):** D1 45%+, D7 15~20%+ — 넘으면 메타 진행 확장.

## 7. 오너 결정이 필요한 것

- [ ] 장르: **하이브리드캐주얼 + 가벼운 로그라이트**로 가는가? (AI 추천)
- [ ] 방향: A(핀볼 × 페글린) / B(파칭코 디펜스) / 둘을 각각 웹 프로토타입으로 만들어 비교
- [ ] 수익: 무료 + 보상형·전면 광고 + 광고 제거 IAP로 시작. Peglin식 일회성 전체 해금 IAP를 함께 둘지
- [ ] 슬롯·잭팟: 판타지 연출(룬·제단)로 바꾸는 데 동의하는가
- [ ] 개발 세션: 이 게임은 별도 세션에서 병렬로 진행(Yawn!과 공용 패키지 충돌 주의 — 아래 「병렬 작업 메모」)

## 병렬 작업 메모 (새 세션용)

- 저장소 규칙: 작업 시작·푸시 전 `git pull --rebase`, 커밋 트레일러 금지, 문서는 `docs/dlc` 먼저 푸시 → 서브모듈 포인터.
- 새 게임은 `apps/<새 게임>`·`prototypes/<새 게임>`·이 폴더(`02-construction/ball-roguelite/`)에서 작업한다.
- Yawn!이 쓰는 공용 패키지: `factory_adaptive`(적응형 난이도·노선 판정), `factory_game_kit`(RNG 등), `factory_ui`, `factory_ads`. 고칠 때는 저장소 전체 테스트(`apps/yawn` 포함)를 돌린다.
- 로그라이크 공통 원칙과 모듈 후보는 [`../roguelike/design-direction-2026-10-16.md`](../roguelike/design-direction-2026-10-16.md) §0(R1~R8, `factory_roguelike`)을 그대로 쓴다.
