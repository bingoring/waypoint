# 핸드오프 v4.5 확인 — 빌런 승객 7종 · 모든 승객 몸 아래 끝

요청서 v4([`design-brief-v4-2026-10-18.md`](design-brief-v4-2026-10-18.md))에 대한 답. 렌더러로 앱의 기준 그림 164장을 다시 뽑아 비교하고, 빌런 그림 33장을 한 장에 모아 요청서와 견줬다.

## 1. 기존 그림 — 「몸 경로만 바뀜」 주장 확인

v4.5에서 **모든 승객의 몸 아래 끝이 둥근 모서리**로 바뀌었다(앉은 몸·까치발 아이·선 몸 경로 3개).

| 비교 | 결과 |
|---|---|
| v3.4 → v4.5, 앱 기준 그림 164장 | **140장 바뀜**, 타일·고양이는 그대로 |
| v4.5 렌더러에서 몸 경로 3개만 이전 값으로 되돌림 → v3.4와 비교 | **0장 다름** — 디자이너 설명(몸 경로만 다름) 그대로 |

v2.1 렌더러와 직접 못 견줬다는 README 주석: 앱의 v2.1 기준 그림과 v3.4 비교(17장 = 의도된 뒷모습·선 몸)는 v3.4 확인 때 끝났으므로, v2.1 → v4.5 차이 = 그 17장 + 몸 경로 변경이다.

그 밖의 바뀐 것: 좌석 앞턱 없앰(모든 좌석, 앱 판 그리기), 짐수레 「넘어짐」 → 「빨간 고무끈이 풀려 칸 안에서 흐트러짐」(v4.3, 조각 6개 움직임), 쩍벌 다리 정면 V자·두 칸 가운데(v4.1~4.4).

## 4. 호통 승객 규칙 바뀜 → 추가 요청 (v4.1)

오너 지적(2026-10-18): 마지막 28호선 기믹인데 「먼저 툭 해서 재우면 끝」이라 단순하다. 규칙을 바꿨다(2-14 §4.7):
- **갑옷이라 툭이 안 통한다.**
- **깨어 있는 동안 박자마다 시계 방향으로 고개를 돌린다.**
- 보고 있는 사람이 하품하면 버럭 해서 깨운다(그대로).
- 잠드는 길은 하나: **바로 옆(상하좌우) 사람이 하품할 때 그쪽을 보고 있지 않으면** 졸음이 옮아 하품하고 잠든다.

그래서 필요한 그림 — [`design-brief-v4.1-2026-10-18.md`](design-brief-v4.1-2026-10-18.md).
