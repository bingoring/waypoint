# 핸드오프 v3.3 확인 — 짐수레 승객 · 큰 판 7×11 · 노선 21개

요청서 v3([`design-brief-v3-2026-10-18.md`](design-brief-v3-2026-10-18.md))에 대한 답을 확인했다. 시안(`Yawn Handoff v3.dc.html`)을 브라우저로 열어 A·B1·B2 카드를 보고, 렌더러를 앱의 기준 그림 164장과 비교했다.

## 1. 바뀐 결정 — 신문 → 짐수레 (오너)

신문 펼친 승객은 디자인이 어색해 **「짐수레 끄는 택배 아저씨」**로 바뀌었다. **규칙은 신문과 같다**: 바로 앞 칸에 세운 수레가 시선을 막고(옆으로 지나는 시선도), 주인도 아무도 못 보며, 주인이 잠들면 수레가 넘어져 시선이 지나가고, 코골이·알람에 깨면 다시 선다. 엔진·생성기 규칙은 그대로 두고 이름만 바꿨다 — 기믹 `news` → `cart`, 승객 `reader` → `porter`, 판 문자 `N.` → `C.`(프로토타입). 바꾼 뒤 엔진 대조·생성기 대조 모두 같음, 5호선 판도 이전과 같은 판.

짝 표시: 주인 어깨의 동그란 표 = 수레 손잡이 짐표(같은 색 4가지). 생성기가 판의 짐수레 승객에게 0,1,2,3,0… 순서로 색을 준다(Build Spec에 반영).

## 2. 앱(렌더러 v2.1 이식본)과 달라진 그림 — 「좌석에 맞게」 수정

v3 렌더러로 앱의 기준 그림 164장을 다시 뽑아 비교했다(v2.1 → v3.3). **바뀐 그림 20장**:

| 묶음 | 그림 | 무엇이 바뀌었나 |
|---|---|---|
| 뒷모습(위를 볼 때) 7장 | `office·student·grandma·hiker·college·parent·earphone _awake_u` | 앞쪽 옷 장식(넥타이·지퍼·브로치·후드끈)을 숨기고 등에서 보이는 것만 — 등산복 아저씨 배낭, 대학생 후드, 아이 엄마 가방끈 방향, 깃 |
| 서서 가는 승객 10장 | `standing_*` | 앉은 몸보다 좁고 곧은 **선 몸**(허리 63), 늘어뜨린 왼팔, 다리 시작 높이 44 → 42 |
| 출입문 3장 | `tile_door_1·3·open` | **렌더러 버그로 비어 있음** (§3) |

나머지 144장은 같다. 신발 좌표 버그(v2.1, 앱 쪽에서 고쳐 그렸던 것)는 v3 렌더러에서 디자이너가 고쳤다.

**새로 생긴 것:** 짐수레 승객(kind `H`) 27그림 + 수레 타일 2상태 × 짐표 4색, **작은 칸 단계 `lod: 's'`**(44–56dp: 선 ×1.3, 눈·배지·표 키움, z 하나, 김·음표·여밈선·라벨 뺌), 큰 판 좌석 여백(칸 < 56: 안쪽 여백 3, 모서리 9, 앞턱 6), 큰 판 시선선(`dense`: 1.3dp·30%, 아래 어두운 테두리로 교차 구분), 누른 칸 강조, 노선 21색(21번 강철색 `#3F4F60`/`#98ADC4`)과 아이콘 번호 변경.

## 3. 발견한 문제 — 디자이너에게 정정 요청

**출입문 타일이 그려지지 않는다.** `yawn-render.js` 414행에 `} else if (type === 'door') {`가 세 번 이어 붙어 있어, 첫 번째 가지가 빈 채로 끝나고 실제 문 그리는 코드가 실행되지 않는다(편집 중 붙여넣기 실수로 보임). README의 「기존 그림 차이 0」 비교는 v2.2 렌더러와 견준 것이라, v2.2에도 같은 줄이 있었다면 비교에서 드러나지 않았을 수 있다.
→ 앱 이식은 v2.1의 문 그림(문 표시 레이어)을 기준으로 하고, 디자이너에게 정정을 요청한다. 정정 요청 문구:

> `yawn-render.js` `tile0()`의 출입문 가지가 `} else if (type === 'door') {`로 세 번 반복되어 문 표시가 비어 나옵니다(`tile('door', { n: 3 })`, `{ st: 'open' }` 모두). 한 번만 남겨 주시고, 기준 그림 비교를 v2.1 렌더러와도 한 번 돌려 주세요.

### 3.1 v3.4 정정 확인 (2026-10-18)

오너가 가져온 v3.4에서 출입문 가지가 한 줄로 고쳐졌다(v2 폴더 사본도). v3.4 렌더러로 기준 그림 164장을 다시 뽑아 비교: **문 3장 포함 타일은 앱 그림과 모두 같고**, 바뀐 그림은 의도된 17장(뒷모습 7·선 몸 10)뿐. 앱 이식 기준은 **v3.4**.

## 5. 앱 반영 (2-12 Build Spec 항목)

- 렌더러 이식 v2.1 → v3.3: 뒷모습 분기, 선 몸, `lod`(칸 56 이하 자동), 짐수레 승객·수레 타일, 좌석 여백, `dense` 시선선, 누른 칸 강조.
