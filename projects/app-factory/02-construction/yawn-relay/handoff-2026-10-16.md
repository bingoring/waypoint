## 2. 이번 세션의 오너 결정 (DECISIONS에 기록됨)

- 앱 이름 「Yawn!」, 스토어 제목 「Yawn! 하품 전염 퍼즐」 / 「Yawn! Contagious Yawn Puzzle」
- 시안과 다른 규칙은 프로토타입 엔진 유지(말똥말똥 첫 하품도 옮음, 두리번 매 박자, 연쇄 중에도 입력)
- **노선·역 이름 없음** — 노선은 번호 + 색(12색), 역은 번호만. 장소 테마가 바뀌어도 같은 규칙
- **화면 글자 최소화** — 객차 설명 줄 없음(첫 역은 손가락 안내만), 패배 카드 부제 없음, 노선 머리는 번호 칩 + 새 승객 얼굴만, 예고 노선은 실루엣만
- 적응형: 알리고 끌 수 있게(설정 스위치), 판 결과 익명 전송으로 보정, 초기 수치 10% → 35%

AI가 구현 중 정한 것(오너 확인 대기): FC §7.2 **D10~D18** — 특히 D10(창문 = 4호선, 노선 6개), D14(전면 광고는 깬 역 합계 6개부터), **D17(6열 판 칸 56dp < 64dp — 그대로 둘지, 5열로 제한할지)**, D18(「한 번 더 툭」은 시도마다 1회).

## 5. 이번에 밟은 함정 (다시 밟지 않게)

- **누수 검사:** 위젯 테스트는 leak_tracker가 켜져 있다. 그림 글자에 `TextPainter`를 캐시하거나 만들고 버리면 실패한다 → `lib/ui/labels.dart`의 `ui.Paragraph` 캐시를 쓴다.
- **`Isolate.run` 클로저:** State 메서드 안 클로저는 화면 객체(Ticker 등)를 붙잡아 보낼 수 없다 → 최상위 함수로(`firstTap`).
- **`pumpAndSettle` 금지:** 노선도·객차는 늘 움직인다. 흐름 테스트의 `_settle(until:)`처럼 조건이 나올 때까지 `runAsync` + `pump`.
- **한국어 줄바꿈:** `keepAll()`(theme.dart)이 단어 결합자 U+2060을 넣는다. 테스트에서 문구를 찾을 때도 `keepAll('…')`로 감싼다. `**굵게**` 같은 표시가 있으면 나눈 뒤에 적용.
- **고정폭 숫자 글꼴에 한글 없음:** Mono 스타일에는 `fontFamilyFallback: [sans]`.
- **파이썬 euc-kr 코덱**은 2,350자 밖 한글도 받아 준다 → KS X 1001 판정은 cp949 바이트 범위로.
- **에뮬레이터 성능 측정 조건**(메모리): `-gpu host`, 부하 < 2, 기준 앱과 같은 부팅에서 3회씩. 이번 세션은 부하 8~12라 못 했다.
