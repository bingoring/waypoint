## 2-1. 시안 코드(`trace`)와 엔진 규칙 대조 — 어긋남 2건 (2차 확인)

시안 HTML의 판 그리기 함수에 시선 계산(`trace`)이 들어 있어 엔진 규칙과 직접 비교했다.

| 항목 | 시안 | 엔진(프로토타입 기록 §4.1·§5.1) | 처리 |
|---|---|---|---|
| **출입문** | 문은 **별도 타일**이고 **시선을 막는다**(`x.t === 'door' → null`). 열리면 새 승객이 앉는다 | 문은 **승객이 앉은 칸**이다. 그 승객은 남이 보고·하품하고·재울 수 있고, 박자 `k % N == N-1`에 깨어 있는 새 승객(같은 종류·처음 방향)으로 바뀐다 | **엔진 기준.** 문은 승객 칸 위에 얹는 표시(테두리·배지·열림 연출)로 그리고, 시선을 막지 않는다. 디자이너에게 정정 요청 |
| **기둥 갈림 단계** | 갈라진 시선이 **두 번째 기둥에 닿으면 막힘** | 갈림은 **2단계까지**(첫 기둥 → 갈림, 갈라진 선이 또 기둥 → 다시 갈림), **세 번째 기둥에서 막힘** | **엔진 기준.** 「막힘」 그림(`tile_pole_blocked`)은 3단계째에 쓴다. 카드 문구 정정 요청 |
| 알람 칸 시선 | 통과(카드 「시선은 통과」, `trace`도 지나감) | 통과 | ✅ 일치 — §4의 「알람 시선 명시 없음」 메모는 해소 |
| 근시·까치발·마스크·고양이·휴대폰·커피 | 근시 앞 칸만, 까치발 첫 사람 건너뜀, 마스크 하품 흐림, 고양이·휴대폰·커피 시선 없음 | 같음 | ✅ |
| 터널 | 터널 중 시선선 꺼짐 | 그 박자 시선 판정 생략 | ✅ |

## 3. 구현 전 정해야 할 것 (오너)

1. **노선 색:** v2는 1~20을 새 체계로 다시 정했다(1호선 `#3F8A86` → `#007570` 등). 앱은 지금 12색(v1 5색 + 구현 때 AI가 고른 7색)을 쓴다. → **v2 20색으로 통일 권장**(대비·이웃 색 차이·실제 노선 회피를 맞춰 설계됨). v1 1~5를 유지하려면 05 표에서 1~5만 되돌린다.
2. **툭 표시 글자:** v2 객차 화면은 「툭」 글자 없이 숫자 「2 / 3」만. 앱은 지금 「툭 1 / 2」. → 화면 글자 최소화(D19)와 맞추려면 **숫자만 권장**.
3. **새 8종 출시 포함:** 그림은 다 왔다. 프로토타입 판정(기록 §5.3)이 아직 빈칸이다.
4. **시안 정정 요청 여부(§2-1):** 출입문·기둥 2건은 엔진 규칙을 따르는 것이 맞다. 디자이너에게 정정을 요청할지, 구현 때 우리가 맞춰 그릴지(그림 부품은 그대로 쓸 수 있음).

## 4. 구현 때 처리할 기술 메모

- **SVG 직접 사용 금지, 렌더러 이식:** SVG마다 C2PA 서명 메타데이터(약 10KB)가 붙어 있고, 변형을 SVG 속성이 아니라 CSS `style="transform:…"`로 적어 Flutter SVG 라이브러리에서 그대로 쓰기 어렵다. v1과 같이 **`yawn-render.js`(부품 조합 렌더러 v2)를 Dart 페인터로 옮기고**, SVG는 골든 테스트 기준 그림(브라우저로 래스터화)으로만 쓴다.
- **보관:** 구현 착수 때 문서·`line-colors.json`·`yawn-render.js`·시안 HTML을 `inputs/design-handoff-yawn-relay_v2/`에 원문 보관(v1 `_SOURCE.md` 방식). SVG 220개는 메타데이터를 뺀 기준 그림만.
- **기믹 이름 대응:** 핸드오프 `wide`·`looker`·`pole`·`standing` = 엔진 `stubborn`·`rot`·`pillar`·`walker`. `kind` 글자도 다르다(핸드오프 M·S·W·O·J·E·G vs 엔진 토큰 s·r·w·g·x·i·k) — 대응표를 렌더러 이식 때 한곳에 둔다.
- **새 기믹의 부릅뜸(패배 카드):** SVG 목록에 새 8종 `glare`가 없다. 렌더러 `st: 'glare'`가 모든 종류에 동작하는지 이식 때 확인한다.
- **깜빡임:** 요청은 방향 4 × 깜빡임 2였고, 결과는 깜빡임 프레임 1장(정면). 방향별 깜빡임은 눈만 닫는 변형이라 렌더러에서 만든다.
- 노선 21번 이후는 1~20 색을 돌려 쓰고 아이콘으로 구별한다(05).
