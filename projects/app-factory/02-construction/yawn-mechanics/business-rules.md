# Business Rules — Yawn! 기믹 확장

> **SoT:** 프로토타입 `#engine` `step`·`sights`·`sightsOf`·`neighbors`·`blocked`(메인 `729b286`). 기존 규칙 Y-SIGHT·Y-BEAT·Y-TAP·Y-WIN·Y-LOSE는 2-9 [`../yawn-relay/business-rules.md`](../yawn-relay/business-rules.md) 그대로이고, 아래는 **추가·변경분**이다. 판정 규칙은 바꾸지 않는다.

## 1. 출시 확정 6종 (엔진에는 이미 있음 — 규칙을 여기 정식으로 적는다)

| ID | 규칙 | 출처 |
|---|---|---|
| Y-SNORE-1 | 코골이 승객은 잠든 뒤, 잠든 박자를 0으로 세어 2·4·6… 박자마다 코를 골아 **상하좌우 이웃 중 잠든 사람**을 깨운다(하품 횟수 0으로) | `step` (8) |
| Y-BABY-1 | 아기는 깨어 있는 동안 박자 `k % 4 == 3`에 울어 상하좌우 이웃 중 잠든 사람을 깨운다 | `step` (8) |
| Y-TALK-1 | 잠꼬대 승객이 잠드는 박자 끝에, 바라보는 방향 **바로 옆 칸**의 깨어 있는 승객(커피 제외)이 다음 박자 하품에 예약된다(시선 아님) | `step` (7) |
| Y-MASK-1 | 마스크 승객도 남의 하품을 보고 하품하고 잠든다. 마스크 승객의 하품은 **아무에게도 옮지 않는다**(시선 판정에서 제외). 시선은 가린다 | `step` (2) |
| Y-PILLAR-1 | 시선이 기둥에 닿으면 진행 방향의 양옆 두 갈래로 계속 간다. 갈림은 2단계까지, 세 번째 기둥은 시선을 막는다 | `sights` |
| Y-DOOR-1 | 문 칸에는 승객이 앉아 있다. 박자 `k % N == N-1`에 그 칸 승객이 깨어 있는 새 승객(같은 종류·처음 방향)으로 바뀌고 예약된 하품도 지워진다. 문은 시선을 막지 않는다 | `step` (9) |

## 2. 새 8종

| ID | 규칙 | 출처 |
|---|---|---|
| Y-CAT-1 | 고양이는 아무도 보지 않는다(볼 수 있는 사람이 아님). 탭으로 하품시킬 수 있다 | `canSee` |
| Y-CAT-2 | 고양이가 하품한 박자에, **상하좌우 이웃 중 깨어 있고 커피가 아닌 사람 모두**가 다음 박자 하품에 예약된다. 시선이 아니므로 **터널 박자에도 된다** | `step` (2b) |
| Y-WALK-1 | 서서 가는 승객은 깨어 있는 동안 박자 처리 ⑥에서 바라보는 방향으로 한 칸 걷는다. 다음 칸이 판 밖·사람·창문·기둥·알람이면 반대 방향으로 돌아서 한 칸 걷는다. 두 방향 모두 막히면 제자리에 있고 방향도 그대로다. 잠들면 멈춘다 | `step` (4b), `blocked` |
| Y-WALK-2 | 시선 판정(①)은 이동(⑥) **전** 위치·방향으로 한다. 이번 박자에 본 것이 다음 박자 하품을 정한다 | `step` 순서 |
| Y-COUPLE-1 | 커플 한 명이 잠드는 박자에 짝이 깨어 있으면, 짝도 **같은 박자에 하품 없이** 잠든다(하품 횟수 = 필요 횟수). 하품하지 않았으므로 짝을 보던 사람에게는 옮지 않고, 짝에게 예약된 하품도 지운다 | `step` (3b) |
| Y-MYOPIC-1 | 근시 승객은 바라보는 방향 **바로 앞 칸**만 본다. 그 칸이 비었거나 창문·기둥이면 아무도 못 본다(꺾임·갈림 없음) | `sights` `range` |
| Y-TIPTOE-1 | 까치발 아이는 시선 방향에서 **처음 만나는 사람을 건너뛰고 두 번째 사람**을 본다. 창문 꺾임·기둥 갈림은 그대로 따른다(갈래마다 첫 사람 건너뜀) | `sights` `skip` |
| Y-EAR-1 | 이어폰 승객은 코골이·아기 울음·알람에 **깨지 않는다**. 나머지는 기본 승객과 같다 | `step` (8)(8b) |
| Y-TUNNEL-1 | 역 설정 `tunnelEvery` = N이면 박자 `k % N == N-1`은 터널 박자다. 그 박자에는 **시선 판정을 하지 않는다**(아무도 못 봄). 고양이·잠꼬대는 시선이 아니라 그대로 된다 | `isDark`, `step` (1) |
| Y-ALARM-1 | 알람은 박자 `k == alarmAt` 처리 때 **한 번** 울려, 알람 칸 주변 8칸(대각 포함)의 잠든 사람을 깨운다(이어폰 제외). 알람 칸은 사람이 없고 **시선이 통과**하며, 서서 가는 승객은 들어갈 수 없다 | `step` (8b) |

## 3. 박자 처리 순서 (Y-BEAT-2 확장)

① 시선(터널이면 생략, 마스크 하품 제외, 근시·까치발 반영) ② 고양이 이웃 예약 ③ 하품·잠 ④ 커플 기대어 잠듦 ⑤ 두리번 회전 ⑥ 서서 가는 승객 이동 ⑦ 예약에서 잠든 사람 제외 ⑧ 잠꼬대 예약 ⑨ 코골이·울음 깨움(이어폰 제외) ⑩ 알람(이어폰 제외) ⑪ 문 → 승리 판정 (Y-WIN-1).

## 5. 생성·진행

| ID | 규칙 |
|---|---|
| Y-GEN-1 | 생성 판의 기믹은 **노선 기믹 + 이전 기믹 최대 2개**(기본 승객 제외). 지금 생성기는 열린 기믹마다 25% 확률로 넣어 노선 20에서 평균 5개가 섞인다 → 고를 때 무작위 순서로 최대 2개까지만 |
| Y-GEN-2 | 생성 판 자르기(DECISIONS 2026-10-17)는 서서 가는 승객이 있으면 걷는 줄·칸의 빈칸을 남긴다(걷기 공간), 알람이 있으면 알람 주변 8칸을 남긴다. 자르기는 사람·알람·창문·기둥을 모두 담는 범위로 한다 |
| Y-GEN-3 | 고양이는 이웃이 2명 이상인 자리에만 넣는다(이웃이 없으면 효과가 안 보임). 커플은 붙은 두 사람을 함께 바꾼다. 이어폰은 코골이·아기·알람 중 하나가 판에 있을 때만 넣는다(없으면 효과 없음) |
| Y-LV-8 | 노선 7~20의 소개 판은 사람이 만든 역(stations 8~35 중 DE §5)이다. 모든 소개 판은 풀이기로 이기는 시작점 ≥ 1, 기믹 효과(도움 또는 함정) > 0을 확인했다(프로토타입 기록 §4.3·§5.2) |

## 6. 예외·경계

| 상황 | 처리 |
|---|---|
| 커플 짝이 커피거나 이미 잠듦 | 커플은 커플끼리만 짝지으므로 커피일 수 없다. 이미 잠들었으면 아무 일 없음 |
| 커플 한 명이 코골이·알람에 깸 | 짝은 잠든 채로 남는다(깨움은 짝에게 번지지 않는다) |
| 서서 가는 승객이 문 칸에 들어감 | 문 칸이 비어 있지 않으므로 들어가지 못한다(문 칸에는 늘 승객이 있음) |
| 서서 가는 승객과 커플 | 커플은 생성기가 서서 가는 승객으로 만들지 않는다(토큰이 하나뿐) |
| 터널 박자에 고양이 하품 | 이웃 예약은 된다(Y-TUNNEL-1) |
| 알람 박자에 판이 이미 승리 | 승리 판정이 박자 끝이라, 알람이 같은 박자에 깨우면 그 박자는 승리가 아니다 |
