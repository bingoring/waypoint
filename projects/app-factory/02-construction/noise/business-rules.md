# Business Rules — 소음 측정기

> 수치 근거는 [`research-2026-10-14.md`](research-2026-10-14.md).

| ID | 규칙 | 위반 시 |
|---|---|---|
| N-DSP-1 | 입력 = PCM16 mono 48 kHz. A가중 = IEC 61672 아날로그 극점을 쌍일차 변환한 IIR. 블록 = 125 ms(6,000샘플) RMS. 청크 크기와 무관하게 같은 블록을 만든다 | — |
| N-DSP-2 | `dB = 20·log10(RMS/32768) + sourceOffset + calibration`. `sourceOffset`: UNPROCESSED +130.0, VOICE_RECOGNITION +112.35 (Android 16 CDD 도출, 상수에 출처 주석) | — |
| N-DSP-3 | Leq = 10·log10(평균(10^(Li/10))) — 블록 에너지 평균. 산술평균 금지. Lmax = 블록 최댓값, min = 블록 최솟값 | — |
| N-DSP-4 | 블록 안에 \|샘플\| ≥ 32,000이 있으면 `clipped` → 화면에 「측정 상한」 (값을 멈춘 채 보여 주지 않음) | — |
| N-DSP-5 | 권한이 있는데 1초 이상 모든 샘플이 0이면 `silent` → 「다른 앱이 마이크를 쓰고 있어요」 (Android 10+ 무음 처리). 0 dB로 표시하지 않음 | — |
| N-SRC-1 | `unprocessed`를 먼저 열고, 지원하지 않거나 1초 동안 전부 0이면 `voiceRecognition`. AGC·잡음 제거·에코 제거는 끈다 | — |
| N-CAL-1 | 보정 = 사용자 오프셋 −20~+20 dB, 0.5 단위, 기본 0. 바꾸면 다음 블록부터 반영, 기록에 당시 오프셋을 남긴다 | 입력 UI가 막는다 |
| N-RUN-1 | 측정은 화면이 보일 때만: 앱이 뒤로 가거나, 측정 화면이 숨거나(`Visibility`·`TickerMode`), 앱 오프닝 광고가 떠 있으면 마이크를 닫는다 | — |
| N-RUN-2 | 측정 중에는 화면 꺼짐을 막는다(window `FLAG_KEEP_SCREEN_ON`, 권한 없음). 멈추면 해제 | — |
| N-FLOOR-1 | 층간소음 모드는 **ko 로케일에서만** 보인다 (DECISIONS 2026-10-15) | — |
| N-FLOOR-2 | 기준(dB(A)): 직접충격 1분 Leq 주간 39·야간 34, Lmax 57·52 / 공기전달 5분 Leq 45·40. 주간 06:00~22:00(기기 현지 시각). `pre2005` 켜면 직접충격만 +2 (기본 끔) | — |
| N-FLOOR-3 | 창 Leq: 측정 시작부터 1분(또는 5분) 단위로 끊어 계산하고, 결과는 그중 **가장 높은 값**(별표 비고 4). 끝나지 않은 창은 진행률로만 보인다 | — |
| N-FLOOR-4 | Lmax 초과 사건 = 기준을 넘는 블록이 이어진 한 덩어리(1초 이상 아래로 내려가면 다음 사건). 지난 60분 사건이 **3회 이상**이면 Lmax 초과(비고 5) | — |
| N-FLOOR-5 | 판정은 「기준 넘음 / 기준 이하 / 측정 중(창 미완성)」 세 가지. 주간·야간은 창이 시작한 시각 기준 | — |
| N-FLOOR-6 | 결과 바로 아래 한 줄 고지: 「참고용 기록이에요. 공식 측정은 층간소음 이웃사이센터(1661-2642)에 문의하세요」 | — |
| N-REC-1 | 측정을 멈추면(10초 이상) 기록 저장을 제안한다. 저장은 사용자 확인 후. 최근 500개만 보관 | — |
| N-REC-2 | 내보내기: 선택한 기록들(기본 전체)을 CSV(UTF-8 BOM, 열: 시작·끝·모드·종류·Leq·Lmax·최소·최고 창 Leq·Lmax 초과 횟수·판정·주야·보정·메모)로 만들어 공유 시트. 파일은 앱 캐시에 쓰고 공유 뒤 지운다 | — |
| N-PRIV-1 | 소리를 녹음·저장·전송하지 않는다. 분석 이벤트에 dB 값을 넣지 않는다 | 리뷰 체크 |
| N-PERM-1 | 권한 요청 전 같은 자리에 한 줄: 「소리 크기만 재고, 녹음하거나 보내지 않아요」. 영구 거부면 버튼이 앱 설정을 연다. 거부 상태도 빈 화면이 아니다 | — |
| N-ADS-1 | `banner_home`(측정 화면 하단), `app_open`(코어 정책). 전면·보상형 없음 | — |
| N-KEY-1 | `measure_noise` 이벤트: 연속 10초 이상 측정했을 때 세션당 1회 (1-2 §10) | — |
| N-RATE-1 | `positiveMoment()`: 기록을 저장할 때 | — |
| N-REF-1 | 예시 눈금은 출처가 있는 값만: 한국환경공단(NIOSH) 표와 WHO 안전 청취 (조사 §2). 청력 기준선 85 dBA (NIOSH) | — |
| N-DEV-1 | `DEMO_AUDIO` dart-define은 합성 PCM(정현파·계단·무음 시나리오)을 같은 인터페이스로 넣는다. 개발·검사용이며 `validate --release`가 켜져 있으면 실패 | 릴리스 차단 |
| N-UI-1 | 앱 이름·문구에 공식 기관 명칭으로 오인될 표현을 쓰지 않는다. 「측정 결과는 참고용」을 설정·스토어에 둔다 | 리뷰 체크 |
