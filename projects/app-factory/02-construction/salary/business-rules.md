# Business Rules — 연봉 실수령액 계산기

> 수치 근거는 [`research-2026-10-14.md`](research-2026-10-14.md). 끝수와 보험료 공식은 공식 모의계산(조사 §8)으로 확정했다(2026-10-14). 모든 공제는 **10원 미만 버림**이다.

| ID | 규칙 | 위반 시 |
|---|---|---|
| S-PAY-1 | 월 지급액 = 연봉 ÷ 12 (퇴직금 포함이면 ÷ 13), 원 미만 버림 | — |
| S-PAY-2 | 과세 월급여 = 월 지급액 − 비과세 월액 (0 미만이면 0). 비과세 기본 200,000원(식대), 0~1,000,000 범위 | 입력 UI가 막는다 |
| S-PAY-3 | 연봉 입력은 만 원 단위, 0 ~ 100억 원. 부양가족 1~11명, 자녀 0 ~ 부양가족−1명. 11명 초과 산식은 1.0 범위 밖 | 입력 UI가 막는다 |
| S-INS-1 | 국민연금 = clamp(과세 월급여를 천 원 미만 버림, 410,000, 6,590,000) × 4.75% → 10원 미만 버림 | — |
| S-INS-2 | 보수월액 = clamp(과세 월급여, 280,528, 127,725,730). 건강보험 = 보수월액 × 3.595% → 10원 미만 버림 | — |
| S-INS-3 | 장기요양 = 보수월액 × 0.4724%(0.9448%의 절반) → 10원 미만 버림. 건강보험료에서 다시 곱하지 않는다 (13.14% 상수 금지) | — |
| S-INS-4 | 고용보험 = 과세 월급여 × 0.9% → 10원 미만 버림 (상·하한 없음) | — |
| S-TAX-1 | 소득세 표 조회: 과세 월급여를 천 원 단위로 버린 값 x에 대해 `lo ≤ x < hi`인 행, 열 = 부양가족 수. x < 770 → 0원, x = 10,000 → `at10000` | — |
| S-TAX-2 | 자녀 차감: 1명 20,830, 2명 45,830, 3명 이상 45,830 + (자녀−2) × 33,330. 결과가 음수면 0 | — |
| S-TAX-3 | 과세 월급여 > 1,000만 원: `at10000[가족]` + 6구간 산식(별표2 원문, 초과분은 원 단위) → 자녀 차감 | — |
| S-TAX-4 | 100% 세액을 10원 미만 버린 뒤 원천징수 비율 80·100·120%를 곱하고 다시 10원 미만 버림 (홈택스 조회 순서, 예: 2,009,577 → 2,009,570 → 80% 1,607,650) | — |
| S-TAX-5 | 지방소득세 = 원천징수 비율을 적용한 소득세 × 10% → 10원 미만 버림 | — |
| S-TAX-6 | 계산 순서는 S-TAX-1 → 3 → 2 → 4 → 5로 고정하고, 금액은 처음부터 끝까지 `int` | — |
| S-RATE-1 | 요율·세액표는 「기준일」(기본: 오늘)에 해당하는 기간 행을 쓴다. 기준일보다 늦게 시작하는 행은 쓰지 않는다 | 가장 이른 행 |
| S-RATE-2 | 결과에 적용 기준을 한 줄로 보인다: 「2026.7 4대보험 · 2026.3 세액표 기준」 | — |
| S-DATA-1 | 입력값·근무 설정은 기기에만 저장하고 서버로 보내지 않는다. 분석 이벤트에 금액·연봉 구간을 넣지 않는다 | 리뷰 체크 |
| S-DATA-2 | 핵심 계산은 원격 값 없이 동작한다 (에셋 내장). 원격 조회 실패는 화면에 오류로 보이지 않는다 | — |
| S-DATA-3 | 원격 `app_salary_rates_v1`(기본 `""`)이 형식 검사(DE 필드·세액표 구조·단조성)를 통과하고 기간 시작일이 에셋보다 늦을 때만 그 기간 행을 더한다. 실패하면 버리고 비치명 오류 기록 | 에셋만 사용 |
| S-LIVE-1 | 실시간 수입은 누적 카운터가 아니라 `now`의 순수 함수다: 기간 실수령 × (기간 시작~now 근무 초 ÷ 기간 전체 근무 초) | — |
| S-LIVE-2 | 근무 초 = 근무 요일 × [시작, 끝) − 점심. 공휴일은 1.0에서 반영하지 않고 화면에 「공휴일은 반영하지 않아요」를 표시 | — |
| S-LIVE-3 | 실제 월급날 = 설정일(말일·31일은 그달 마지막 날)이 주말이면 직전 금요일. 기간 = [직전 실제 월급날, 다음 실제 월급날) | — |
| S-LIVE-4 | 「오늘」 = 오늘 근무 초 × 기간 초당 금액. 「올해」 = 1월 1일 00:00~now와 겹치는 모든 기간에 S-LIVE-1을 적용한 합 | — |
| S-LIVE-5 | 기준 금액은 계산 화면의 월 실수령액이다. 연봉을 바꾸면 즉시 반영한다 (과거 기간도 현재 금액으로 계산, 1.0 단순화로 화면에 명시하지 않음) | — |
| S-LIVE-6 | 갱신은 1초마다, 화면이 보이고(`Visibility`·`TickerMode`) 앱이 앞에 있을 때만. 근무 시간 밖이면 타이머를 멈추고 다음 근무 시작 시각에 한 번 깨운다 | — |
| S-ADS-1 | `interstitial_compare`(everyN 3): 비교 결과를 본 뒤 다른 연봉으로 다시 비교할 때 `onTransition`. 계산·실시간 화면에는 전면 광고가 없다 | — |
| S-ADS-2 | 배너: `banner_home`(계산), `banner_live`(지금). 비교 화면은 배너 없음 (두 영수증 공간) | — |
| S-RATE-UX-1 | `positiveMoment()`: 실시간 수입 설정을 처음 마칠 때 | — |
| S-UI-1 | 「정확한 금액은 회사 급여명세서를 확인하세요. 간이세액표 기준 추정치이며 연말정산으로 달라질 수 있어요」를 결과 바로 아래 한 줄로 표시 | — |
| S-UI-2 | 앱 이름·스토어 문구에 「국세청」·「공식」을 쓰지 않는다 | 리뷰 체크 |
