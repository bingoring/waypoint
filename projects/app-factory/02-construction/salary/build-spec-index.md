# Build Spec — 연봉 실수령액 계산기

## §0. 개요 & 범위
- **목표(한 줄):** 연봉 → 급여명세서형 월 실수령액 + 연봉 인상 비교 + 근무 시간에 초 단위로 쌓이는 실시간 수입 앱 `apps/salary`.
- **SoT:** 1-1 §7(연봉), 1-2 §10(매핑), DECISIONS 2026-10-14(기능 범위·입력 기본값·근무 기본값·전면 광고 자리).
- **규모/제약:** 오프라인 동작(요율 에셋 내장), 서버 0원, 권한 추가 없음, 한국어 전용, 다운로드 ≤ 15MB. 입력값은 기기 밖으로 나가지 않는다.
- **깊이 티어 & 사유:** `standard` + frontend-components. 세금 계산은 규칙이 많아 BR·BLM에 계산 순서와 끝수를 고정한다.

- [x] 위젯 테스트: 연봉 입력 → 명세서 갱신, 설정 → 지금 화면 증가, 숨은 탭·퇴근 후 타이머 정지. 비교 3회 → 전면 광고는 에뮬레이터에서 확인(테스트 전면 광고 표시)
- [x] 에뮬레이터: 전 화면 스크린숏, 프롬프트 5단계 검사(FC §9)
- [x] 크기 ≤ 15MB ✅ 11.21MB · 콜드 스타트 ≤ 1.5초 ⚠️ 판정 보류 · PSS ≤ 200MB ❌ 219~237MB · 「지금」 1분 유지 시 메모리 증가 없음 ✅(+1.9MB, 탭 왕복 4회에도 240MB 근처에서 멈춤)
  - **측정 절차(DECISIONS 2026-10-14 제안):** 같은 부팅(`-gpu host`)에서 기준 앱·로또·연봉 3회씩, 첫 화면 15초 뒤와 탭 순회 뒤.
  - PSS(KB): 기준 앱 173,073 / 191,244 / 198,364 · 로또 첫 화면 200,696 / 205,308 / 205,439, 탭 뒤 215,038 / 224,521 / 224,608 · 연봉 첫 화면 222,922 / 220,321 / 218,627, 탭 뒤 236,723 / 235,510 / 234,194.
    → 연봉은 로또보다 +12~15MB, 기준 앱 중앙값 대비 첫 화면 +29MB · 탭 뒤 +44MB(코어·UI 40MB 초과). 로또도 탭 뒤 절대값 215~225MB로 200MB를 넘는다(2-3 측정 195MB는 첫 화면만, 다른 부팅).
  - Dart 힙(GC 뒤): 연봉 15.7MB, 로또 11.6MB. 차이 4.1MB는 대부분 코드 객체(Code·Function, 쓰는 Material 위젯 종류가 많음)이고 데이터 보유(누수)가 아니다. 굴림 숫자를 끈 실험 빌드도 PSS가 같았다.
  - 콜드 스타트: 기기가 안정된 시점 1.30~1.49초(TotalTime, 로또와 같은 수준). 같은 실행에서 기준 앱도 1.2~6.2초로 흔들려 오늘 수치로는 판정하지 않는다. 부팅 직후·소프트웨어 렌더링에서는 8~20초.
  - 프레임: 소프트웨어 렌더링(SwiftShader)에서만 측정되어(중앙값 40ms) 판정 근거가 아니다. 실기기 확인은 1.1/3-1에서.
