## AI 제안 (AI Proposal)

> ⚠️ 이 섹션은 AI가 작성합니다. 사람이 직접 수정하지 마세요.

### 한 줄 정의
Claude Code 사용량이 **왜** 줄었는지 원인별로 보여주고, 캐시가 만료되기 직전에 알려 주는 오픈소스 macOS 메뉴 막대 앱.

### 문제와 대상
- **대상:** Claude Code 구독자(Pro/Max). 특히 세션 여러 개를 오래 띄워 두고 일하는 사람.
- **문제:** 한도가 갑자기 빨리 닳는데, 원인이 자기 사용 습관인지 Anthropic 쪽 변경인지 구분할 수 없다. 일부 사용자는 캐시 유지 시간 변화나 버전별 토큰 증가를 손으로 분석해서 이슈로 올리고 있다.

- **빈틈은 가설이다.** 작은 도구가 여럿 생겼는데 모두 자리를 잡지 못한 것은 "승자가 없다"는 뜻일 수도, "이런 진단에 대한 수요가 약하다"는 뜻일 수도 있다. 3-2에서 공개 반응으로 검증한다.

### 로컬 검증 (개발자 기기 1대, 데스크톱 앱 세션)
- 검증 기간 2026-11-10 ~ 11-17(UTC), API 호출 4,133건.
- 캐시 재구축 80건이 캐시 쓰기 토큰의 65.8%를 차지했다. 메인 세션의 재구축 62건은 모두 원인이 설명되었다: 만료 50, 압축 직후 9, 모델 변경 3, 원인 불명 0.
- 만료 재구축의 캐시 쓰기 비용은 API 정가 환산 비용의 17.0%였다. 이 중 짧은 휴식(3시간 이하) 16건은 5.8%, 긴 휴식 34건은 11.2%였다. 짧은 휴식에서 줄일 수 있었던 양은 5.5%다.
- 재현 방법은 [`../inputs/design.md`](../inputs/design.md) 10장.

### 범위
- **v1 목표(G1 ~ G4):** 원인 분해, 만료 경고, 비싼 재구축 목록, 데스크톱 앱과 터미널 세션 모두 지원. 자세한 내용은 설계 입력 2장.
- **비목표:** 공식 한도 %, 버그 증거 내보내기(v2), 다른 도구 지원, Windows와 Linux, 공개 CLI, 세션 이동, 세션 모니터와 복귀 요약.
- **반목표:** 로그인 토큰·키체인·쿠키 읽기, 사용자 한도 소비, 네트워크 전송, `~/.claude` 수정, 근거 없는 "낭비" 단정.

### 성공 기준
- 사용자가 1분 안에 원인을 알아낸다. 짧은 휴식이면 만료 전에 이어 가고, 긴 휴식이면 떠나기 전 컨텍스트 크기를 보고 정리할지 판단한다.
- 외부 지표는 GitHub 별 수와 GitHub Releases 다운로드 수다.
